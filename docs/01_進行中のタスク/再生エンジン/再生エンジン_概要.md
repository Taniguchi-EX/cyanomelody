# 再生エンジン

## 概要

曲をデコードして鳴らし、再生順を制御する中核の部品を作る。

詳しい仕様は `00_現在の仕様/機能仕様.md` と `00_現在の仕様/技術仕様.md`、順番は `00_現在の仕様/開発ロードマップ.md` を参照。

## ミニロードマップ

### 実装

- [ ] 音声の出力：cpal で出力先を開き、止めているときは閉じる（試作では開いたままだった）
- [ ] デコード：Symphonia で MP3、WAV、`.m4a` を読む。読み込み口は音楽ソースから受け取る（`Read + Seek`）
- [ ] サンプルレートの変換：rubato で出力先に合わせる
- [ ] 再生順の制御：プレイリストの順、シャッフル（プレイリスト全体）、リピート（プレイリスト全体）、再生できない曲は飛ばす、一周すべて再生できなければ止める
- [ ] 操作：再生、一時停止、前の曲、次の曲、シーク、音量（WindowsとUbuntuはアプリ内の音量）
- [ ] 状態の変化を画面や Android の通知に知らせる仕組み（イベント）

### レビュー

- [ ] 差分を読み直し、仕様との食い違い、エラー処理の漏れ、不要なコードがないかを確かめる
- [ ] 指摘を直す

### テスト

- [ ] 再生順の制御の単体テスト（シャッフルで全曲が一度ずつ出る、リピート、飛ばす、一周で止まる）
- [ ] テスト用の音声データでデコードとシークの単体テスト
- [ ] Windows でテスト用の曲を鳴らす（耳での確認は後でまとめて行う）

### コミットとプッシュ

- [ ] 仕様や手順に変更があれば `00_現在の仕様/` と README に反映する
- [ ] コミットしてプッシュする
