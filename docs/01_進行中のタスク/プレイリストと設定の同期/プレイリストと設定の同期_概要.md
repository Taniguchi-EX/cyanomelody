# プレイリストと設定の同期

## 概要

プレイリストと設定を Google Drive 上の JSON に保存し、全端末で共有する。

詳しい仕様は `00_現在の仕様/機能仕様.md` と `00_現在の仕様/技術仕様.md`、順番は `00_現在の仕様/開発ロードマップ.md` を参照。

## ミニロードマップ

### 実装

- [ ] Drive のマイドライブ直下に `cyanomelody` フォルダを作り、`settings.json` と `playlists/<ID>.json` を読み書きする
- [ ] プレイリスト：作成、名前の変更、削除、曲の追加（ファイル単位、フォルダ単位）、削除、並べ替え、お気に入り
- [ ] 開いたときと編集の直前に読み直し、保存は後勝ちにする
- [ ] 設定：Drive の指定フォルダ（全端末共通）、ローカルの指定フォルダ（端末IDごと）
- [ ] ローカルの曲は追加した端末の ID を持ち、他の端末ではグレーアウトする

### レビュー

- [ ] 差分を読み直し、仕様との食い違い、エラー処理の漏れ、不要なコードがないかを確かめる
- [ ] 指摘を直す

### テスト

- [ ] JSON の読み書きの単体テスト（形式の互換性を含む）
- [ ] Drive を模したテスト用のサーバで、読み直しと後勝ちの単体テスト
- [ ] 本物の Drive に作って読み直す（開発PCで実行）

### コミットとプッシュ

- [ ] 仕様や手順に変更があれば `00_現在の仕様/` と README に反映する
- [ ] コミットしてプッシュする
- [ ] このフォルダに連番を付けて `02_完了したタスク/` に移す
