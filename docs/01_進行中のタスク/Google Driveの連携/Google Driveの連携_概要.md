# Google Driveの連携

## 概要

Google Drive にログインし、指定フォルダの曲を音楽ソースとして読めるようにする。

詳しい仕様は `00_現在の仕様/機能仕様.md` と `00_現在の仕様/技術仕様.md`、順番は `00_現在の仕様/開発ロードマップ.md` を参照。

## ミニロードマップ

### 実装

- [ ] デスクトップのログイン：ブラウザで同意し、ループバックで受け取る（PKCE 付き）。リフレッシュトークンを OS の資格情報の保管庫に保存する
- [ ] Drive の音楽ソース：フォルダ ID でたどって一覧にする。曲は Range 指定の部分取得と先読み（最大 4MB）で読む
- [ ] MP3 のシークの改善：ビットレートや Xing ヘッダから位置を見積もって読み始める
- [ ] タグの並行読み込み：8 件ずつ並行して読み、SQLite に保存する
- [ ] 通信できないときの扱い（エラーを音楽ソースの外に正しく伝える）

### レビュー

- [ ] 差分を読み直し、仕様との食い違い、エラー処理の漏れ、不要なコードがないかを確かめる
- [ ] 指摘を直す

### テスト

- [ ] Drive の応答を模したテスト用のサーバで、一覧、部分取得、先読みの単体テスト

- [ ] 本物の Drive で `music/cyanomelody_test` を読む（開発PCで実行）
