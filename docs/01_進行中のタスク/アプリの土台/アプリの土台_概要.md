# アプリの土台

## 概要

Tauri 2 ＋ React の雛形と、Rust のワークスペースを作り、以降の作業の土台にする。

詳しい仕様は `00_現在の仕様/機能仕様.md` と `00_現在の仕様/技術仕様.md`、順番は `00_現在の仕様/開発ロードマップ.md` を参照。

## ミニロードマップ

### 実装

- [ ] `app/` に Tauri 2 ＋ React ＋ TypeScript ＋ Vite のアプリを作る（アプリの ID は `dev.cyanomelody.app`）
- [ ] Rust のワークスペースにする。OS に依存しない中核のクレート（`app/crates/core`）と、Tauri のアプリ（`app/src-tauri`）に分ける
- [ ] 検査の手順をまとめたスクリプトを作る（`cargo fmt --check`、`cargo clippy`、`cargo test`、`tsc`）
- [ ] Android 向けのプロジェクトを生成し、Docker でビルドできるようにする（`prototypes/android_env` のイメージを使う）
- [ ] README に、開発の始め方とビルドの手順を書く

### レビュー

- [ ] 差分を読み直し、仕様との食い違い、エラー処理の漏れ、不要なコードがないかを確かめる
- [ ] 指摘を直す

### テスト

- [ ] Windows でアプリが起動し、画面が表示される
- [ ] 検査のスクリプトがすべて通る
- [ ] Docker で Android 17 向けの APK がビルドできる

### コミットとプッシュ
