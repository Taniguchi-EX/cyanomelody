# 曲のキャッシュとオフライン

## 概要

Google Drive の曲を再生しながら端末に保存し、オフラインでも再生できるようにする。

詳しい仕様は `00_現在の仕様/機能仕様.md` と `00_現在の仕様/技術仕様.md`、順番は `00_現在の仕様/開発ロードマップ.md` を参照。

## ミニロードマップ

### 実装

- [ ] 再生しながら同じデータをキャッシュ領域に保存する。途中までのものは使わない
- [ ] 最大容量の設定（既定値 2GB）と、最後に再生されてから最も時間がたった曲から消す処理
- [ ] キャッシュの索引を SQLite に保存する
- [ ] オフラインの判定と、オフライン時の動き（Drive の曲はキャッシュ済みのものだけ再生、プレイリストは編集できない）

### レビュー

- [ ] 差分を読み直し、仕様との食い違い、エラー処理の漏れ、不要なコードがないかを確かめる
- [ ] 指摘を直す

### テスト

- [ ] 容量の上限を超えたときの削除順の単体テスト
- [ ] 通信を切った状態でキャッシュ済みの曲だけ再生されるテスト

### コミットとプッシュ
