# 画面

## 概要

React で画面を作り、中核とつなぐ。

詳しい仕様は `00_現在の仕様/機能仕様.md` と `00_現在の仕様/技術仕様.md`、順番は `00_現在の仕様/開発ロードマップ.md` を参照。

## ミニロードマップ

### 実装

- [ ] プレイリスト一覧（お気に入りを上に表示）
- [ ] プレイリストの編集（追加、削除、並べ替え、名前の変更、お気に入り）
- [ ] フォルダをたどって曲を選ぶ画面（ファイル単位、フォルダ単位）
- [ ] 再生画面（再生、一時停止、前、次、シークバー、音量、シャッフル、リピート）
- [ ] 設定画面（指定フォルダ、キャッシュの最大容量、ログイン）
- [ ] グレーアウトとオフラインの表示

### レビュー

- [ ] 差分を読み直し、仕様との食い違い、エラー処理の漏れ、不要なコードがないかを確かめる
- [ ] 指摘を直す

### テスト

- [ ] 型の検査（`tsc`）
- [ ] Windows で画面を操作して一通り動く（自動での画面操作のテストは対象外）

### コミットとプッシュ

- [ ] 仕様や手順に変更があれば `00_現在の仕様/` と README に反映する
- [ ] コミットしてプッシュする
- [ ] このフォルダに連番を付けて `02_完了したタスク/` に移す

## 資料マップ
