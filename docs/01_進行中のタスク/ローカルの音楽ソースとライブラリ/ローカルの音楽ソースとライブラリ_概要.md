# ローカルの音楽ソースとライブラリ

## 概要

音楽ソースの共通の窓口と、ローカルのフォルダの曲の読み込み、曲の一覧のキャッシュを作る。

詳しい仕様は `00_現在の仕様/機能仕様.md` と `00_現在の仕様/技術仕様.md`、順番は `00_現在の仕様/開発ロードマップ.md` を参照。

## ミニロードマップ

### 実装

- [ ] 音楽ソースの共通の窓口（曲の一覧、タグの読み込み、曲を開く）を決める
- [ ] ローカルの音楽ソース：指定フォルダとサブフォルダから MP3、WAV、`.m4a` を探し、タグを読む。タグがなければファイル名を曲名にする
- [ ] 曲の一覧とタグ情報を SQLite に保存する。手動更新で読み直し、見つからなくなった曲に印を付ける
- [ ] 端末ID：初回起動時に発行し、アプリのデータ領域に保存する

### レビュー

- [ ] 差分を読み直し、仕様との食い違い、エラー処理の漏れ、不要なコードがないかを確かめる
- [ ] 指摘を直す

### テスト

- [ ] 日本語の名前とサブフォルダを含むテスト用のフォルダで、一覧とタグの単体テスト
- [ ] 手動更新で曲が増えた、消えた場合の単体テスト
- [ ] 端末IDが再起動後も同じになるテスト

### コミットとプッシュ

- [ ] 仕様や手順に変更があれば `00_現在の仕様/` と README に反映する
- [ ] コミットしてプッシュする
- [ ] このフォルダに連番を付けて `02_完了したタスク/` に移す
