# テスト手順書

`00_現在の仕様/機能仕様.md` の項目ごとに、実機で確かめる手順。結果は各項目の「結果」に、OS ごとに ○（できた）、×（できない）、－（対象外）と、気づいたことを書く。

## 準備

- [ ] Google Cloud に、アプリの ID `dev.cyanomelody.app` 用の Android の OAuth クライアントを作る
  - デバッグ版用：SHA-1 `7F:66:97:27:8E:18:85:E4:85:CE:F5:67:9A:A9:CD:17:19:48:09:F2`
  - リリース版用：SHA-1 `25:55:AB:54:B3:23:6C:31:16:6A:63:1B:04:BF:18:1A:CB:93:CC:BB`
- [ ] 各 OS にアプリを入れる（作り方は `app/README.md` の「配布用のビルド」）
  - Windows：`cyanomelody_<版>_x64-setup.exe` を実行する
  - Ubuntu：`sudo apt install ./cyanomelody_<版>_amd64.deb`
  - Android：`adb install cyanomelody-<版>-release.apk`（スキル `cyanomelody-android-test` の手順で、PC とつないで行う）
- [ ] テスト用の曲を用意する
  - Google Drive：`music/cyanomelody_test`（MP3、WAV、`.m4a`）
  - 各端末のローカル：日本語の名前のフォルダとサブフォルダに、MP3、WAV、`.m4a` を 1 曲ずつ

## 1. ログイン

| 手順 | 期待する結果 | 結果（Win / Ubuntu / Android） |
|---|---|---|
| 設定のタブで「ブラウザでログイン」（Android は「ログイン」）を押し、同意する | 「〜でログイン中」と出る | |
| アプリを閉じて開き直す | ログインしたまま | |
| ログアウトしてから、もう一度ログインする | ログインできる | |

## 2. 指定フォルダと手動更新

| 手順 | 期待する結果 | 結果 |
|---|---|---|
| Drive の指定フォルダで `music/cyanomelody_test` を選ぶ | ほかの端末の設定のタブにも同じフォルダが出る（全端末で共通） | |
| この端末のフォルダを選ぶ（Android はパスを入力） | この端末にだけ設定される（ほかの端末には出ない） | |
| Android で初めて開いたとき | 音楽ファイルを読む権限を求められ、許可できる | |
| 「曲の一覧を更新」を押す | 進み具合が出て、Drive とこの端末の曲数が出る | |
| タグのない曲 | ファイル名が曲名になる | |
| フォルダに曲を足して、もう一度更新する | 追加の数が増える | |
| フォルダから曲を消して、もう一度更新する | 見つからない数が増え、その曲はプレイリストでグレーアウトする | |

## 3. プレイリスト

| 手順 | 期待する結果 | 結果 |
|---|---|---|
| プレイリストを作る | 一覧に出る。ほかの端末でも「更新」で出る | |
| 「曲を追加」で、Drive とこの端末の曲を 1 曲ずつ追加する | 追加される | |
| フォルダごと追加する（サブフォルダのあるフォルダ） | サブフォルダの中の曲も追加される | |
| 同じ曲をもう一度追加する | 2 回入る | |
| 上下の並べ替え、プレイリストから外す、名前の変更 | 反映され、ほかの端末でも同じになる | |
| お気に入りにする | 一覧で上に★付きで出る。ほかの端末でも同じ | |
| ほかの端末で追加したローカルの曲 | グレーアウトして表示される | |
| プレイリストを削除する | 一覧から消え、Drive のゴミ箱に入る | |

## 4. 再生

| 手順 | 期待する結果 | 結果 |
|---|---|---|
| 「最初から再生」「ここから再生」 | 音が出る（MP3、WAV、`.m4a` のそれぞれ） | |
| 一時停止、再開、前の曲、次の曲 | そのとおりに動く。前の曲は、3 秒より後なら曲の頭に戻る | |
| シークバーを動かす | その位置から鳴る（Drive の MP3 でも数秒以内） | |
| シャッフル、リピート | プレイリスト全体で動く。リピートなら最後の次は最初に戻る | |
| 音量（Windows、Ubuntu） | アプリ内の音量が変わる | |
| 音量（Android） | 本体の音量ボタンで変わる | |
| グレーアウトした曲の順番が来る | 再生を試し、だめなら知らせずに次の曲へ飛ばす | |
| 全曲が再生できないプレイリスト（オフラインでキャッシュなし、など） | 一周したら止まる | |
| 再生中に別のプレイリストを開いて戻る、再生バーの曲名を押す | 再生中のプレイリストが開く | |

## 5. キャッシュとオフライン

| 手順 | 期待する結果 | 結果 |
|---|---|---|
| Drive の曲を一度再生したあと、もう一度再生する | 2 回目はすぐに音が出る | |
| 設定のタブのキャッシュの使用量 | 再生した曲のぶん増える | |
| 最大容量を小さくする | 使用量が最大容量以下になる | |
| 通信を切る（機内モードなど） | 上に「オフライン」と出て、プレイリストを編集できない | |
| 通信を切ったまま再生する | ローカルの曲とキャッシュ済みの Drive の曲だけ鳴る | |
