# ロードマップ

## 全体ロードマップ

アプリ全体の作業の一覧と順番。各作業の詳しいロードマップは、それぞれの作業フォルダの`02_ロードマップ.md`に書く。
作業が完了したらチェックを入れる。

### 最初の版（Windowsのみ）
- [ ] 1. 初期概要検討（この作業）
  - アプリ全体の方針を決め、`01_現在の機能/00_全体/`に反映する。
- [ ] 2. 音声のタグ管理
  - 試作：Tauri 2・React・SQLiteの構成を作り、数万ファイルのフォルダをスキャンする時間を測る。
  - 本実装：ライブラリにするフォルダの登録とスキャン、音声ファイルへのタグの付け外し、タグでの絞り込み、試聴。
  - ひも付けが切れたファイル（スキャンで見つからなくなったファイル）に印を付ける。
- [ ] 3. タグ自体の管理
  - タグの作成・名前変更・削除。タグの分類（階層など）はこの作業の概要検討で決める。
- [ ] 4. ハッシュ値を使った機能
  - 試作：各形式（MP3、WAV、FLAC、OGG、M4A）から、タグ情報を除いた音声データの部分を取り出す。数万ファイルでハッシュ値を計算する時間を測る。
  - 本実装：ハッシュ値の計算と保存、重複チェック、ハッシュ値での検索、ひも付けが切れたファイルの見つけ直し。
