# 初期概要検討

## アプリの概要

ローカルにある音声ファイルにタグ付けして管理するアプリ。
メインとなる音声管理機能のほか、補助的に以下の機能も実装する。
- タグ自体の管理
- 出典とライセンスの管理
- ハッシュ値による検索と重複チェック
- ノーマライズ
- エフェクトセットの作成と付与

## 動作環境
Windows11 / Linux / Android

## アーキテクチャや実装方式
- 内部処理はRust、画面表示はReactで作成する。
- タグやハッシュ値などのメタデータは複数のファイル分をまとめた形式で保存する
- ハッシュ値はファイル名などを除いた部分を元に生成する
