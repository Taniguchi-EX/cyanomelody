# タグとプレイリストへのイメージカラーとジャケット設定機能

状態：作業概要（仮判断で作成。ユーザーのレビュー待ちのまま進める）

ユーザーの離席中に、全体ロードマップの「タグとプレイリストへのイメージカラーとジャケット設定機能」（タグとプレイリストに、イメージカラーとジャケット（画像）を設定する）を、仮判断で作業概要にしたもの。仮に決めた所は「仮判断」と書く。

## 目的
タグとプレイリストに、そのものを表す色（イメージカラー）と画像（ジャケット）を付けられるようにし、左の欄・中央の一覧のグリッド・プレイリストを選んだときの見出しに出して、見分けやすくする。

## 範囲

### 付けるもの
- イメージカラー：色1つ（`#rrggbb`）。
  - 仮判断：タグには今の「背景色・文字色」（チップの色）があるので、タグのイメージカラーは新しく作らず、今の背景色を使う。新しく付けられるようにするのは、プレイリストのイメージカラーだけ。
- ジャケット：画像1枚（PNG・JPEG・WebP・GIF）。タグとプレイリストの両方に付けられる。
  - 選んだ画像は、アプリのデータ領域の `jackets` フォルダに写して持つ（元の画像を動かしても消えない）。
  - 仮判断：大きい画像は、長い辺 512px に縮めて PNG で持つ（データ領域が大きくならないように）。

### 付け方
- タグ：タグの詳細画面に「ジャケット」の欄を加える（「画像を選ぶ…」「外す」と見本）。「保存」で保存する（ほかの欄と同じ）。
- プレイリスト：編集画面の上の行の名前の左に、ジャケットの見本（なければイメージカラーの四角、どちらもなければ空の枠）を出し、押すと「イメージカラー」「ジャケット」の欄を出す。決めるとすぐ保存する。
  - 仮判断：プレイリストのイメージカラーは「色を付ける」のチェックと色の選択（タグの詳細画面と同じ形）。

### 出す所
- 左の欄：タグ・プレイリストの行の名前の左に、ジャケットの小さい見本（16px 角）。ジャケットがなくイメージカラーがあれば、その色の小さい四角。
- 中央の一覧の見出し：プレイリストを選んでいるとき、名前の左にそのプレイリストのジャケット（なければイメージカラーの四角）。
- グリッド（作業「グリッドビューの追加」）のタイル：
  - 仮判断：プレイリストを選んでいるときは、その曲が来た項目（直下の項目）のジャケット → 選んだプレイリストのジャケットの順に、あるものをタイルの背景に薄く出す。選んでいないときは、その曲に付いているタグのうち、ジャケットのあるもの（タグの一覧の順で最初）を出す。
  - 仮判断：ジャケットがなくイメージカラーがあれば、タイルの左端に色の帯を出す。

### データ
- tags に `jacket`（データ領域の中のファイル名。NULL はなし）を加える。
- playlists に `color`（`#rrggbb`。NULL はなし）と `jacket` を加える。
- データのエクスポート・インポート：仮判断として、色は「タグ」「プレイリストとエフェクト」の項目に含め、ジャケットの画像は含めない（JSON に画像を入れると大きくなるため）。取り込んだ側ではジャケットはなし。
- タグ・プレイリストを削除したとき、ほかから使われていないジャケットの画像のファイルも消す。

## やらないこと
- ファイル（曲）ごとのジャケット。音声ファイルの中のアートワーク（ID3 の画像など）を読むこと。
- 画像を切り抜く・回す操作。
- エクスポートの JSON にジャケットの画像を含めること。

## 未決事項（ユーザーに見てもらいたい点）
- タグのイメージカラーを、今の背景色と分けて持つべきか（今は同じものとして扱う仮判断）。
- グリッドのタイルに出すジャケットの選び方。
- エクスポートにジャケットを含めないことでよいか。
