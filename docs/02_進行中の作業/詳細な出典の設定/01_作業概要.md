# 詳細な出典の設定機能

状態：作業概要（仮判断で作成。ユーザーのレビュー待ち。中身の決め方にユーザーの考えが大きく関わるので、実装はレビューの後に行う）

ユーザーの離席中に、全体ロードマップの「詳細な出典の設定機能」（今の出典（名前・URL・メモ）より詳しく、出典を設定できるようにする）を、仮判断で作業概要にしたもの。

## 目的
効果音・音楽を人に渡したり作品に使ったりするときに必要な、クレジット表記の材料（作者・作品名・入手日など）を、出典ごと・ファイルごとに残せるようにする。

## 範囲（仮判断）

### 出典に加える項目
- 作者（制作者・サークル名など）
- 配布元のサイト名（URL とは別に、表記に使う名前）
- 入手日（年月日。入れなくてもよい）
- クレジット表記の文（例：「効果音：{作者}（{サイト名}）」。`{作者}` などの差し込みを使える）

### ファイルごとに加える項目
- 出典の中での場所（素材の番号・ページの URL など。1つの文字列）
- 仮判断：ファイルごとの「作品名」（曲名）は、今の曲名（タグ情報のタイトル）を使い、別には持たない。

### 出す所
- 出典のフォーム（左の欄の「＋」「✎」）に上の項目を加える。
- 右の欄の出典の欄に、作者・サイト名・入手日と、そのファイルの「出典の中での場所」の入力欄を出す。
- 右の欄（と一括操作の欄）に「クレジット表記をコピー」：選んでいるファイル（チェックしたファイル）のクレジット表記の文を、出典ごとにまとめてクリップボードに写す。

### データ
- sources に `author`・`site_name`・`obtained_on`・`credit_template` を加える。
- audio_files に `source_detail` を加える。
- データのエクスポート・インポートの「出典・ライセンスと設定」に含める。

## やらないこと
- 出典の情報をネットから自動で取ってくること。
- ライセンスの項目を増やすこと。

## 未決事項（ユーザーに決めてもらいたい点）
- 「詳しく」したい中身は何か（上の項目は仮）。たとえば、作品ごとの使用許諾の記録、使った作品の一覧、表記の書式など、ほかに必要なものがあるか。
- クレジット表記の文の差し込みの形と、まとめて写すときの並べ方。
