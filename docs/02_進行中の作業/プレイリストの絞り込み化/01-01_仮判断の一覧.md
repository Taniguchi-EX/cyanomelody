# 仮判断の一覧

ユーザーの離席中に、判断が必要な所を仮に決めて進めたもの。戻ったら見直してもらう。

1. 条件のチップ
   - 仮判断：選んでいるプレイリストも、ほかの条件と同じくチップ「📃 名前」を出す。✕で選択を外す。「すべての条件を外す」（名前のない ✕）でも外れる。
   - 理由：「ほかの欄と同じ絞り込みの条件にする」ため。
2. 編集画面を開いている間の再生の欄
   - 仮判断：再生の欄と一番下の行は、重ねて出す画面（編集画面・エフェクトの管理画面など）より上に出し、開いている間も操作できるようにする。編集画面の高さは、再生の欄に重ならないようにする。
   - 理由：編集画面の「▶ 再生」や項目の再生で鳴らしながら、止めたり次へ進んだりできないと困るため。
3. 選んでいるプレイリストの行のダブルクリック
   - 仮判断：選んでいる行を押したときは、すぐには選択を外さず 0.3 秒待ち、その間にダブルクリック（編集画面を開く）が来たら外さない。選んでいない行は、押してすぐ選ぶ。
   - 理由：ダブルクリックの1回目の押しで選択が外れてしまうため（作業概要の「2回目の押しは選択の切り替えに使わない」だけでは防げない）。
4. 0曲のプレイリストの編集
   - 仮判断：0曲でグレーアウトしたプレイリストも、ダブルクリックと「✎」で編集画面を開ける（押しても選べないだけ）。
   - 理由：作ったばかりの空のプレイリストに項目を加えられないと困るため。
5. 抽選し直して再生を止めたとき
   - 仮判断：一番下の行に「プレイリストを抽選し直したので、再生を止めました」と出す。
   - 理由：何もせずに止まると、不具合に見えるため。
6. 編集画面の項目の再生方法とチェック
   - 仮判断：チェックした項目の再生方法を変えると、チェックした項目すべて（タグの組み合わせ・プレイリストの項目だけ）の再生方法が変わる（fx と同じ）。
   - 理由：作業概要の「項目のチェックでできる操作は、項目を外す・fx を付ける・再生方法を変える」に合わせた。
7. 項目を左の欄に落とす操作
   - 仮判断：編集画面の項目の行を、左の欄（タグなど）へドラッグして落とす操作はなくす（行のドラッグは並べ替えだけ）。
   - 理由：編集画面は重ねて出すので、左の欄に届かないため。同じことは、プレイリストを選んだ一覧の行で行える。
