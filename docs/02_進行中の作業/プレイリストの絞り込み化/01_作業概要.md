# プレイリストの絞り込み化

状態：検討中（作業概要をまとめている段階。ロードマップは未作成）

## 目的
今の画面には、次の2つの問題がある。
- 左の欄の中で「プレイリスト」だけが絞り込みの条件になっていない。行を押すと、中央が詳細画面に切り替わる。
- ライブラリの一覧とプレイリストの詳細画面の切り替えが分かりにくい。プレイリストを開いている間も左の欄の絞り込みを操作でき、隠れているライブラリの一覧にだけ効く。戻るのは、詳細画面の左上の「＜」だけ。

プレイリストを、ほかの欄と同じ「押すと絞り込む」条件にし、中身の編集は別の画面（編集画面）に分けて、この2つを解く。

## 要件（決まったこと）

### プレイリストの選択と抽選
- 左の欄のプレイリストの行を押すと、そのプレイリストを選ぶ。選ぶと、その時点でプレイリストを1回展開し、再生する曲の並びを決める（以下「抽選」）。
  - 🎲（ランダムセレクト）の項目は、ここで1曲を選ぶ。🔀（シャッフル）の項目は、ここで順番を決める。
  - 展開の中身は今と同じ。タグの組み合わせ・子・参照の中身も含め、親のプレイリストを選んだときは子の中身も含む。見つからないファイルは除く（🎲の候補にも入れない）。
  - 同じ曲が何度出てもよく、出た回数だけ一覧に行を出す。
- プレイリストは1つしか選べない。別のプレイリストを押すと、そちらに切り替わる（抽選する）。同じ行をもう一度押すと外れる。
- 「（プレイリストなし）」の行を加える。どのプレイリストにも入っていない曲に絞り込む。プレイリストの選択とは同時に選べない。
- 抽選し直すのは、次のときだけ。
  - 同じプレイリストを選び直したとき（一度外して、また選んだとき）
  - 一覧を最後まで再生した後に、再生の欄の「▶」でもう一度再生したとき
  - プレイリストを編集したとき（中身は下の「現在の想定」の「編集で抽選し直す範囲」）
- 抽選し直さないもの
  - 途中で止めてから再生したとき
  - 最後まで再生した後に、一覧の行の「▶」で再生したとき
- 再生している最中に抽選し直したとき：鳴っている曲が🎲・🔀の項目から来た曲（抽選の結果で変わりうる曲）なら再生を止め、ファイルの項目・順に再生の項目から来た曲ならそのまま鳴らし続ける。
- 見出しの横の「🎲 引き直す」のボタンは、今回は作らない。

### 中央の一覧
- プレイリストを選んでいる間は、中央の一覧に抽選した並びを出す。見出しの「ライブラリ」は、プレイリストの名前にする。
- タグ・出典・ライセンス・その他などの絞り込みは、抽選した並びに対してかける。ほかの条件を選んだままプレイリストを選んだときは、ほかの条件は残す。
- 並び順のプルダウンは使える。「プレイリストの順」（抽選した順）を加える。並び順は、ライブラリとプレイリストで別々に覚え、プレイリストの初期値は「プレイリストの順」。
- 曲名は、ファイルの項目の別名（プレイリスト上での名前）を先に出す。タグの組み合わせなど、複数のファイルが対象になる項目から来た曲は、ファイル名のまま。
  - ファイル名の検索は、別名とファイル名のどちらかに当てはまれば出す。
  - 並び順の「ファイル名順」は、出している名前（別名を含む）で並べる。
- 各行の再生ボタンの右に、どの項目から来た曲かのアイコンを出す。
  - タグの組み合わせの項目：タグのアイコン
  - プレイリストの項目（子・参照）：プレイリストのアイコン。選んだプレイリストの直下の項目を指す。例：A（選んだもの）→ 子B → 子C の中の曲は、Bを指す。Bの中のタグの組み合わせから来た曲も、Bを指す（プレイリストのアイコン）。
  - ファイルの項目として直に入れた曲：アイコンなし
  - マウスを乗せると説明の文を出す（「タグの組み合わせ「雨 ＋ 風」（🎲 1曲）から」「プレイリスト「足音」（🔀 シャッフル）から」）。エフェクトセットの名前は添えない。
  - 押すと、選んでいるプレイリストの編集画面を開き、その項目の行を選んだ状態にする。
- 行そのものに、エフェクトがかかることを示す印は付けない。
- 一番下の行の件数は、行の数（同じ曲が2回出れば2）。
- チェックはファイルごと。同じファイルの行には、そろってチェックが付く。チェックの件数はファイルの数。

### 左の欄の件数
- プレイリストの行の件数は、そのプレイリストを通しで流したときに鳴る曲の数（🎲の項目は1曲と数える）。ほかの条件を選んでいても変えない。0曲のプレイリストだけグレーアウトする。
- 「（プレイリストなし）」の行の件数は、ほかの欄と同じく、押したときに出るファイルの数。
- プレイリストを選んでいる間の、タグなどの欄の件数は、抽選した並びの中の行の数。
- 「重複しているファイル」の条件は、今の決まり（ライブラリ全体で同じハッシュ値の曲が2件以上）のまま。同じファイルが2行出ていることは、重複とは別の扱い。

### 再生
- プレイリストを選んでいる間は、プレイリストとして再生する。中央の一覧（絞り込んだ結果を、見えている順に）を鳴らし、各曲に項目のエフェクトセットをかける。
- 行の「▶」・ダブルクリックはその行から、再生の欄の再生方法（一曲だけ・順に連続・ランダム・ランダムセレクト）は一覧の上にかける。今のライブラリの一覧と同じ。
- 編集画面にも再生ボタンを置く。押すと、そのプレイリストを選んだ状態にして（選んでいなければ選んで抽選し）、中央の一覧を頭から再生する。ほかの絞り込みがあれば、それもかかる。
- 編集画面の項目ごとの再生（種類の記号の ▶）は、今のまま残す。

### 再生の欄の曲名を押したとき
- 再生しているプレイリストを選んでいれば、中央の一覧のその行へ移り、右の欄に出す。
- 選んでいなければ、そのプレイリストの編集画面を開き、その項目の行を選ぶ（選び直すと抽選し直しになるため、選び直さない）。

### 編集画面
- プレイリストの中身（項目・再生方法・fx・別名）の編集は、編集画面で行う。中央の一覧は、いつも絞り込んだ曲の一覧になる。
- メインの画面に重ねて出す（エフェクトの管理画面と同じ形）。「閉じる」と Esc で閉じる。
- 開き方
  - 左の欄のプレイリストの行の「✎」と、行のダブルクリック（1回目の押しで選ぶので、抽選が走る）。名前の変更は、編集画面の中へ移す。
  - 右の欄のファイルの詳細の「プレイリスト」の欄の「📃 名前」のチップの名前を押したとき。そのファイルの項目の行を選んだ状態で開く。一括操作の欄の「プレイリスト」の「外す」のチップの名前も同じ。
  - 中央の一覧の行のアイコンを押したとき（上の「中央の一覧」）と、再生の欄の曲名を押したとき（上の「再生の欄の曲名を押したとき」）。
- 項目の詳細（別名・中身・曲のリスト）を出す欄は、今回は設けない（今は右の欄に出している）。
- 項目のチェックでできる操作は、項目を外す・fx を付ける・再生方法を変えるだけにする。今の「一括操作」（項目の曲へのタグ付けなど）は外し、中央の一覧でチェックして行う。
- プレイリスト上での名前（別名）は、編集画面でだけ直せる（右の欄では直さない）。項目の行の名前をダブルクリックすると入力欄になり、Enter で決め、Esc でやめる。
- タグの組み合わせの項目は、編集画面の中のタグの入力欄で加える（右の欄の「付けるタグ」と同じ形。今の「選択タグをリストに追加」の代わり）。
- 書出は編集画面に置く（今の一番下の行と同じ）。

### 再生の欄のエフェクトの表示
- 別の作業「再生の欄のエフェクトの表示」で行う。

### 書出
- 今までどおり、プレイリストの階層をフォルダにして書き出す（抽選した並びではなく、書き出すときに展開する）。

## 現在の想定（任された点・細部）

### 編集で抽選し直す範囲
- 抽選し直す：選んでいるプレイリストか、その中に入っている（子・参照の）プレイリストの、項目の追加・削除・並べ替え・再生方法の変更。タグの統合・削除で、タグの組み合わせの項目が変わったとき。一覧の行を、選んでいるプレイリストへドラッグして加えたとき。
- 抽選し直さず、一覧の表示だけ直す：別名の変更、項目の fx の変更。
- 何もしない：プレイリストの名前の変更、エフェクトセットの中身の変更（エフェクトは曲を鳴らすときにかけるので、そのまま効く）。
- タグの付け外しでは抽選し直さない（一覧が勝手に変わらないように）。ただし、削除したファイル・ライブラリから外したファイルの行は消す。

### そのほか
- プレイリストの選択は、アプリを閉じると覚えていない（ほかの絞り込みの条件と同じ）。
- 選んでいるプレイリストを削除したときは、選択が外れてライブラリの一覧に戻る。
- 「最後まで再生した」は、順に連続・ランダムで、再生の順番の最後の曲が終わったとき。一曲だけ・ランダムセレクトで1曲鳴らして止まったときは含めない。
- 抽選の結果は画面側で持つ。絞り込み・件数の計算のたびに、それを Rust 側へ渡す。

## 懸念点
- 性能：プレイリストの行の件数（通しで流したときの曲数）を、データが変わるたびにすべてのプレイリストについて数える。抽選した並びを、絞り込みと件数の計算のたびに Rust 側へ渡す。数万曲・大きなタグの組み合わせの項目で重くならないか。試作して計測してから、計算の方法を決める。
- 一覧の作りの変更：今の一覧は、右の欄に出す行・鳴らしている行の印・キーボードの↑↓・Shift でのチェック・再生の欄の曲名から移る先などを、すべてファイルの id で見分けている。同じファイルが2行出るので、行（曲の出番）で見分けるように直す必要がある。チェックと一括操作はファイルのまま。
- 再生方法「ランダム」で再生したときと、抽選した🔀の項目の並べ替えが重なる。動きとしては問題ないが、どちらの並べ替えか分かりにくいかもしれない。
- 画面テスト（playlists・effects・export・bulk・facets・perf・layout）、資料（プレイリスト・再生・エフェクト・画面の構成・ファイルの一括操作・音声のタグ管理）、README の画像の書き直しが大きい。

## 決めるべき点（自己レビューで見つかったもの）
1. 編集画面の項目の行のダブルクリック：今は「その項目を再生する」。別名の入力欄もダブルクリックで出すので、ぶつかる。案：名前の上のダブルクリックは別名の入力欄、それ以外の所のダブルクリックは今どおり再生。
2. タグの入力欄で、組み合わせ（複数のタグ）をどう作るか。案：入力欄でタグを1つずつ選んでチップとして並べ、「追加」で、並べたタグの組み合わせの項目を加える。
3. 一覧の件数（行の数）とチェックの件数（ファイルの数）の数え方がそろわない。一番下の行の表示を「12曲」「チェック 3ファイル」のように単位を変えて区別するか、今の「件」のままにするか。
4. 作業の順番：「再生の欄のエフェクトの表示」をこの作業の前後どちらで行うか（互いに依存は小さい）。
