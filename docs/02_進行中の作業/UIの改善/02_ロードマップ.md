# ロードマップ

各周で、ユースケースを1つ想定し、必要な操作を列挙して、今の画面をレビューし、直す。
周ごとに、単体テスト、型の確認とlint、リリースビルドでのすべての画面テストを行う（画面の変更で必要ならテストを直す）。
ユーザーの指示（進め方と観点が示されている）に従い、レビューを待たずに進める。

- [ ] 1周目：TRPGのシナリオに使う効果音を吟味しつつプレイリストとしてまとめる（一括解除のボタンもこの周で作る）
- [ ] 2周目：音楽再生アプリとして使う
- [ ] 3周目：一般公開するコンテンツ用に、ライセンスの緩い効果音を探す
- [ ] 4周目：シナリオごとのプレイリストを見て、過去にどのファイルをどう使ったか振り返る
- [ ] 5周目：新しく入手した素材集を取り込み、タグ・出典・ライセンスを付けて整理する
- [ ] 6周目：重複したファイルや、移動して見つからなくなったファイルを片付ける
- [ ] 7周目：素材集の中から、似た音を聞き比べて選ぶ
- [ ] 8周目：大量のファイルの中から、条件を重ねて目的の音を探す
- [ ] 9周目：エフェクトを調整しながら、狙った音を作って書き出す
- [ ] 10周目：友人にプレイリストを書き出して渡す
