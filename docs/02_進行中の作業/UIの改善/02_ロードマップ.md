## 各周の記録

### 1周目：TRPGのシナリオに使う効果音を吟味しつつプレイリストとしてまとめる
- ユースケース：シナリオのプレイリストと、シーンごとの子のプレイリストを作る。タグで絞り込んで試聴しながら音を選び、シーンに入れる。別名を付け、シナリオ用のエフェクトを結び付け、シーンを再生して確かめる。
- 必要な操作
  1. シナリオのプレイリストを作り、編集画面で子のプレイリスト（シーン）を作る
  2. タグで絞り込み、行の再生ボタンで試聴する
  3. 選んだファイルをシーンに入れる（何件も、何度も）
  4. 項目に別名を付ける、エフェクトのまとまりを選ぶ
  5. シーンを再生する
  6. 次の音を探すために、絞り込みや選択を外す
- レビューで見つけたこと
  - 3の手間が大きい。1件ずつなら「行をクリック → 右の欄でプレイリストを選ぶ → 追加」の3手。チェックしてまとめるなら「チェック → 一括操作の欄で『プレイリストに追加』→ 選ぶ → 追加 → 確認」の5手。何度も繰り返す操作なのに、毎回確認が出る。
  - 編集画面の各行に文字が多い（「ファイル」「子のプレイリスト」などの種類、「別名」「外す」のボタン、「エフェクトなし」）。行が横に詰まり、内容が読みにくい。
  - 「プレイリストを加える」の下の説明文（ループになるものは選べない）は、選べない候補にその理由が出ているので不要。「（タグで絞り込んでいません）」も、ボタンが押せないことで伝わる。
  - 6で、絞り込み・チェック・右の欄の表示をまとめて外す手段がない（指示の一括解除のボタン）。
  - 一覧の行の「⚠見つからない」は、取り消し線と記号で十分伝わる。
- 直したこと
  - ファイルの行を、左の欄のプレイリストへドラッグして加えられるようにした（1手）。チェックした行をつかむと、チェックしたファイルすべてを加える。ドラッグ中は件数（「♪ 3」）をポインタの横に出し、落とす先を枠で示す。
  - プレイリストへ加える操作の確認をやめた（加えるだけで、編集画面で外せるため）。
  - 編集画面の行：種類を記号（♪・🏷・📁・↪。名前はマウスを乗せると出る）に、「外す」を「✕」に、「エフェクトなし」を「fx なし」にした。「別名」ボタンをなくし、名前を押すと別名を入力できるようにした。
  - 説明文と「（タグで絞り込んでいません）」を消した。
  - 「絞り込みを解除」を、記号だけの「✕」（すべて解除）に置き換えた。絞り込み・チェック・右の欄の表示のどれかがあるときだけ出し、押すとすべて外す。
  - 一覧の行の見つからない印を「⚠」だけにした（名前はマウスを乗せると出る）。
- 動きの変化（仕様の変更）
  - 「すべて解除」はチェックも外す（これまでの「絞り込みを解除」はチェックを残した）。絞り込みだけを外すときは、選んでいる項目をもう一度押す。「01_現在の機能」の該当する記述を直した。
- テストの修正：「絞り込みを解除」の後もチェックが残ることを前提にしていたテスト（bulk.mjsのB04〜B06・B08）を直した。プレイリストへ加える確認を確かめていたP02を直した。行の種類を記号の名前（title）から読むようにした。ドラッグの共通部分で、つかむ所と落とす先を画面の中までスクロールしてから操作するようにした。
- テストの追加：playlists.mjsのP20（行をドラッグしてプレイリストへ加える、チェックした行ならすべて）、bulk.mjsのB05（すべて解除でチェック・右の欄も外れ、ボタンが消える）。
