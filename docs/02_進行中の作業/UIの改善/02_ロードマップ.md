# ロードマップ

各周で、ユースケースを1つ想定し、必要な操作を列挙して、今の画面をレビューし、直す。
周ごとに、単体テスト、型の確認とlint、リリースビルドでのすべての画面テストを行う（画面の変更で必要ならテストを直す）。
ユーザーの指示（進め方と観点が示されている）に従い、レビューを待たずに進める。

## 各周の記録

### 1周目：TRPGのシナリオに使う効果音を吟味しつつプレイリストとしてまとめる
- ユースケース：シナリオのプレイリストと、シーンごとの子のプレイリストを作る。タグで絞り込んで試聴しながら音を選び、シーンに入れる。別名を付け、シナリオ用のエフェクトを結び付け、シーンを再生して確かめる。
- 必要な操作
  1. シナリオのプレイリストを作り、編集画面で子のプレイリスト（シーン）を作る
  2. タグで絞り込み、行の再生ボタンで試聴する
  3. 選んだファイルをシーンに入れる（何件も、何度も）
  4. 項目に別名を付ける、エフェクトのまとまりを選ぶ
  5. シーンを再生する
  6. 次の音を探すために、絞り込みや選択を外す
- レビューで見つけたこと
  - 3の手間が大きい。1件ずつなら「行をクリック → 右の欄でプレイリストを選ぶ → 追加」の3手。チェックしてまとめるなら「チェック → 一括操作の欄で『プレイリストに追加』→ 選ぶ → 追加 → 確認」の5手。何度も繰り返す操作なのに、毎回確認が出る。
  - 編集画面の各行に文字が多い（「ファイル」「子のプレイリスト」などの種類、「別名」「外す」のボタン、「エフェクトなし」）。行が横に詰まり、内容が読みにくい。
  - 「プレイリストを加える」の下の説明文（ループになるものは選べない）は、選べない候補にその理由が出ているので不要。「（タグで絞り込んでいません）」も、ボタンが押せないことで伝わる。
  - 6で、絞り込み・チェック・右の欄の表示をまとめて外す手段がない（指示の一括解除のボタン）。
  - 一覧の行の「⚠見つからない」は、取り消し線と記号で十分伝わる。
- 直したこと
  - ファイルの行を、左の欄のプレイリストへドラッグして加えられるようにした（1手）。チェックした行をつかむと、チェックしたファイルすべてを加える。ドラッグ中は件数（「♪ 3」）をポインタの横に出し、落とす先を枠で示す。
  - プレイリストへ加える操作の確認をやめた（加えるだけで、編集画面で外せるため）。
  - 編集画面の行：種類を記号（♪・🏷・📁・↪。名前はマウスを乗せると出る）に、「外す」を「✕」に、「エフェクトなし」を「fx なし」にした。「別名」ボタンをなくし、名前を押すと別名を入力できるようにした。
  - 説明文と「（タグで絞り込んでいません）」を消した。
  - 「絞り込みを解除」を、記号だけの「✕」（すべて解除）に置き換えた。絞り込み・チェック・右の欄の表示のどれかがあるときだけ出し、押すとすべて外す。
  - 一覧の行の見つからない印を「⚠」だけにした（名前はマウスを乗せると出る）。
- 動きの変化（仕様の変更）
  - 「すべて解除」はチェックも外す（これまでの「絞り込みを解除」はチェックを残した）。絞り込みだけを外すときは、選んでいる項目をもう一度押す。「01_現在の機能」の該当する記述を直した。
- テストの修正：「絞り込みを解除」の後もチェックが残ることを前提にしていたテスト（bulk.mjsのB04〜B06・B08）を直した。プレイリストへ加える確認を確かめていたP02を直した。行の種類を記号の名前（title）から読むようにした。ドラッグの共通部分で、つかむ所と落とす先を画面の中までスクロールしてから操作するようにした。
- テストの追加：playlists.mjsのP20（行をドラッグしてプレイリストへ加える、チェックした行ならすべて）、bulk.mjsのB05（すべて解除でチェック・右の欄も外れ、ボタンが消える）。
- テスト：単体テスト80件、画面テスト132件、すべて成功。

### 2周目：音楽再生アプリとして使う
- ユースケース：「任天堂曲」のプレイリストを作り、「ゲーム曲 ＋ 任天堂」のタグの組み合わせを入れる。「ランダムセレクト」の項目で、毎回違う曲が選ばれるようにする。シャッフルで流し、曲を送ったり、曲の途中へ飛んだりしながら聞く。
- 必要な操作
  1. プレイリストを作り、タグの組み合わせを加える
  2. 項目の再生方法を選ぶ
  3. プレイリストをシャッフル（または1曲だけ）で再生する
  4. 曲を送る、曲の中の位置を変える、どこまで聞いたかを見る
- レビューで見つけたこと
  - 3：シャッフルで聞くには、編集画面で「再生方法」の欄を選び直してから「▶ 再生」を押す2手が要る。欄の値は画面を開き直すと戻るので、毎回選び直す。
  - 2：項目の再生方法の選択肢が「ランダムセレクト再生」などと長く、行の幅を取る。
  - 1：タグの組み合わせで「選ぶ」が文字のボタンで、何度も押す操作なのに目立ちすぎる。
  - 4：再生の欄に、曲のどこを再生しているかが出ず、位置も変えられない。音楽として聞くには困る。
- 直したこと
  - 編集画面の「再生方法」の欄と「▶ 再生」を、記号のボタン3つ（▶ 順に・🔀 シャッフル・🎲 1曲。名前はマウスを乗せると出る）にした。押した方法ですぐ再生する（1手）。
  - 項目の再生方法の選択肢を「▶ 順に」「🔀 シャッフル」「🎲 1曲」と短くした（記号はプレイリスト自体の再生のボタンとそろえた）。
  - タグの組み合わせの「選ぶ」を「＋」にした。
  - 再生の欄に、細い進み具合のバーを加えた。マウスを乗せると「経った時間 / 長さ」が出て、押すとその位置へ移る。
- 途中で起きたこと：前に裏で始めた画面テストの実行（直す前のrun.sh）が残っていて、今回の実行と同じ通信の口を使い、テストのアプリを止めたため、export.mjsが失敗した。古い実行が終わった後に流し直し、成功した。
- テストの修正：再生ボタンの名前を「▶ 再生」から「順に再生」に変えた。
- テストの追加：playlists.mjsのP21（シャッフル・1曲のボタンですぐ再生、進み具合のバーで位置を移る）。
- テスト：単体テスト80件、画面テスト132件、すべて成功。

### 3周目：一般公開するコンテンツ用に、ライセンスの緩い効果音を探す
- ユースケース：動画で公開するので、商用可・改変可で、できればクレジット表記の要らない効果音を探す。複数の素材サイトの規約（ライセンス）が登録してある。条件に合うライセンスを選んで絞り込み、試聴して選び、使う音の出典とURLを確かめる。
- 必要な操作
  1. 条件に合うライセンスを見分ける
  2. そのライセンス（複数）で絞り込み、タグも重ねる
  3. 試聴して選ぶ
  4. 選んだファイルの出典・URL・条項を確かめる（クレジット表記を書くため）
- レビューで見つけたこと
  - 1：左の欄のライセンスの一覧は名前だけで、条項がわからない。管理画面を開くか、ファイルを1つずつ右の欄に出して読む必要がある。ライセンスが多いほど手間が大きい。
  - 4：右の欄の条項が「商用利用：可」のように5行で縦に長く、どれが制約なのかを読み取る必要がある。「種類：独自」も、種類を選んでいない限り意味がない。
  - 右の欄の出典・ライセンスの「外す」が文字のボタンで、ほかの外す操作（✕）とそろっていない。
- 直したこと
  - 左の欄のライセンスの各行に、5つの条項を記号（¥・©・✎・⇆・↺）で並べ、緑（使いやすい側）・橙（制約）・灰色の点線（不明）で色分けした。マウスを乗せると言葉で出る。緑の並ぶ行を選べばよいので、見分けるのに画面を移らずに済む。
  - 右の欄と管理画面の条項は、短い言葉（「商用可」「表記要」など）を同じ色分けで横に並べた。種類は名前と違うときだけ出す。
  - 「外す」を「✕」にした。
- テストの修正：左の欄の行を、行の文字列でなく名前（data-credit-name）と件数の欄で探すようにした。右の欄の条項の表示の変更に合わせた（C10）。管理画面の条項の表示を、空白をそろえてから比べるようにした。
- テストの追加：credits.mjsのC21（左の欄の条項の記号の色分けと、マウスを乗せたときの言葉）。
- テスト：単体テスト80件、画面テスト133件、すべて成功。

### 4周目：シナリオごとのプレイリストを見て、過去にどのファイルをどう使ったか振り返る
- ユースケース：前に遊んだシナリオのプレイリストを開き、どの場面でどの音を使ったか、別名やエフェクトを見ながら1つずつ聞き直す。気に入った音について、ほかのシナリオでも使ったかを確かめ、そのシナリオを開く。
- 必要な操作
  1. シナリオのプレイリストを開き、項目（別名・エフェクト・再生方法）を見る
  2. 項目を1つだけ聞き直す（別名・エフェクトをかけた状態で）
  3. あるファイルを、ほかにどのプレイリストで使っているか調べる
  4. そのプレイリストを開く
- レビューで見つけたこと
  - 2：項目を1つだけ聞く手段がない。プレイリスト全体を再生して「次へ」で送るか、ファイルの一覧に戻ってそのファイルを試聴する（エフェクトはかからない）しかない。
  - 3：ファイルからプレイリストをたどる手段がない。プレイリストを1つずつ開いて探す必要がある。
  - 右の欄の付いているタグの「外す」が文字のボタンで、ほかの外す操作（✕）とそろっていない。
- 直したこと
  - 編集画面の項目の種類の記号（♪・🏷・📁・↪）を、押すとその項目だけを再生するボタンにした。マウスを乗せると ▶ に変わる。項目の再生方法・別名・エフェクトは、プレイリストの中で再生したときと同じ。ボタンを足さずに、すでにある記号に役目を持たせた。
  - 右の欄の「プレイリストに追加」を「プレイリスト」にし、そのファイルを入れているプレイリストをチップで出すようにした。押すと開く。加える操作はその下にそのまま置いた。
  - 付いているタグの「外す」を「✕」にした。
- 内部の変更：項目1つの展開を、プレイリストの展開から関数に切り出した（項目1つの再生と共通にするため）。
- テストの修正：プレイリストの名前の欄を、部分一致しないように探すようにした（P23で「プレイリストの名前」が2つに当たったため）。
- テストの追加：単体テスト（項目1つの展開、ファイルを入れているプレイリスト）、playlists.mjsのP22（項目の記号で1つだけ再生）・P23（右の欄のプレイリストのチップ、押すと開く）。
- テスト：単体テスト81件、画面テスト135件、すべて成功。

### 5周目：新しく入手した素材集を取り込み、タグ・出典・ライセンスを付けて整理する
- ユースケース：素材サイトから効果音の素材集（数百ファイル）をダウンロードした。フォルダを登録し、取り込んだファイルすべてに出典（素材サイト）とライセンス（サイトの規約）を付け、聞きながら種類ごとのタグを付ける。
- 必要な操作
  1. フォルダを登録する
  2. 取り込んだファイルだけを表示する
  3. すべてチェックして、出典とライセンスをまとめて設定する
  4. 聞きながら、ファイルごと・まとまりごとにタグを付ける
  5. あとで、その素材集のファイルだけをもう一度見る
- レビューで見つけたこと
  - 2・5：フォルダで絞り込む手段がない。取り込んだファイルは、ほかのフォルダのファイルと混ざって表示される。「（タグなし）」や「（出典なし）」で近い表示にはできるが、前からあるファイルも混ざるうえ、タグを付けると外れていく。
  - 1：登録した後、何が取り込まれたかを見るには、自分で絞り込みを直す必要がある（ほかの条件が残っていると、新しいファイルが隠れる）。
  - ライブラリフォルダの欄は、フォルダごとにパス全体（数行に折り返す）・件数・「スキャン」「登録解除」の2行を使い、左の欄の上の方を大きく占める。
- 直したこと
  - フォルダの行を押すと、そのフォルダのファイルだけに絞り込むようにした（もう一度押すと外れる。「すべて解除」でも外れる）。選んでいる行は、ほかの絞り込みの項目と同じ色で示す。
  - フォルダを登録したら、ほかの絞り込み・チェック・右の欄の表示を外し、そのフォルダだけを表示するようにした。すぐに「すべてチェック」から一括操作に進める。
  - フォルダの行を1行にした：フォルダの名前（パスの最後。マウスを乗せるとパス全体）、件数、見つからないファイルの「⚠件数」、「⟳」（スキャン）、「✕」（登録解除）。
- テストの修正：テストの共通部分のフォルダの登録で、登録後にフォルダの絞り込みを外すようにした（ほかのテストは全体を見る前提のため）。
- テストの追加：単体テスト（フォルダでの絞り込み）、tag-management.mjsのT01（登録するとそのフォルダだけの表示になり、名前が出て、押すと外れる）。
- テスト：単体テスト82件、画面テスト135件、すべて成功。

### 6周目：重複したファイルや、移動して見つからなくなったファイルを片付ける
- ユースケース：フォルダの整理でファイルを移動・削除したので、スキャンして見つからなくなったファイルを片付ける（移動先にひも付け直すか、ライブラリから外す）。あわせて、同じ素材を別の名前で何度も取り込んでいないかを確かめ、どれを残すかを決める。
- 必要な操作
  1. スキャンして、見つからないファイルがあるかを知る
  2. 見つからないファイルだけを表示し、ひも付け直すか外す（1件ずつ、またはまとめて）
  3. 重複しているファイルだけを表示し、同じ音声のまとまりを見分ける
  4. まとまりの中で、タグや場所を見比べて残すものを決める
- レビューで見つけたこと
  - 1・2：「見つからないファイルだけ」は、見つからないファイルが1件もなくても常に出ていて、押しても0件になるだけ。逆に、見つからないファイルがあることは、フォルダの欄の件数を見ないとわからない。
  - 3：重複の一覧では、同じ音声のファイルが並ぶが、境目はハッシュ値の先頭8文字（英数字）を読み比べないとわからない。
  - 右の欄の見つからないファイルの欄に、ボタンの働きを説明する2行の文がある。
  - ツールバーの「見つからないファイルだけ」「重複しているファイルだけ」の文字のチェックボックスが幅を取り、ツールバーが2行に折り返す。
- 直したこと
  - 「見つからないファイルだけ」を、記号の切り替えボタン「⚠」にした。見つからないファイルがあるとき（か、選んでいるとき）だけ出し、マウスを乗せると件数が出る。ボタンが出ていること自体が、見つからないファイルがあることを示す。
  - 「重複しているファイルだけ」も記号の切り替えボタン「⧉」にした。押すと選んだ状態の色になる。
  - 一覧の行のハッシュ値の文字を、ハッシュ値から決まる色の丸い印にした。同じ音声のファイルは同じ色になり、まとまりの境目が色で見分けられる（マウスを乗せるとハッシュ値）。
  - 右の欄の見つからないファイルの説明文を消し、見出しに「⚠」を付けた。ボタンの働きはマウスを乗せると出る。
- テストの修正：2つの絞り込みをボタンで押すようにした。重複の一覧のハッシュ値の確かめ方を、印のハッシュ値と色にした。
- テストの追加：tag-management.mjsのT14（見つからないファイルがなくなると「⚠」のボタンが消える）、hash-features.mjsのH04（同じ音声のファイルの印が同じ色）。
- テスト：単体テスト82件、画面テスト135件、すべて成功。

### 7周目：素材集の中から、似た音を聞き比べて選ぶ
- ユースケース：「扉」のタグで絞り込むと、似た扉の音が十数件ある。上から順に聞き比べ、シーンに合う2〜3件をチェックして残す。気になった音は、何度か行き来して聞き直す。
- 必要な操作
  1. タグで絞り込む
  2. 1件ずつ試聴し、次の行・前の行へ移って聞く
  3. どこまで鳴ったか（長さ）を見る
  4. 残すものをチェックする
- レビューで見つけたこと
  - 2：次の音を聞くたびに、その行の小さな再生ボタンをマウスで狙って押す必要がある。行き来して聞き直すと、押す回数がさらに増える。右の欄の表示（タグ・ライセンス）も、行をクリックし直さないと変わらない。
  - 3：試聴では、どこまで鳴ったか・あとどれくらい続くかがわからない（再生の欄はプレイリストの再生のときだけ出る）。長さの違う似た音を比べにくい。
- 直したこと
  - 一覧で ↑・↓ キーを押すと、右の欄に表示するファイルを上・下の行に移すようにした。試聴中なら、移った先をそのまま試聴する。キーを押すだけで、聞きながら詳細も見比べられる。
  - スペースキーで、右の欄に表示しているファイルの試聴を始める・止めるようにした。
  - 試聴中の行の下端に、細い進み具合のバーを出すようにした（ボタンや文字を足さずに、どこまで鳴ったかがわかる）。
- テストの追加：tag-management.mjsのT20（↑↓での移動、試聴中なら移った先を試聴、スペースで開始・停止、行の進み具合のバー）。最初は前のテストで外したファイルを使っていて失敗したので、残っているファイルに直した。キーの後の画面の更新を少し待つようにした。
- テスト：単体テスト82件、画面テスト136件、すべて成功。

### 8周目：大量のファイルの中から、条件を重ねて目的の音を探す

- 必要な操作
  1. タグ・出典・ライセンス・フォルダ・ファイル名の条件を足す
  2. いま何で絞り込んでいるかを確かめる
  3. 条件を1つだけ外して、件数の変化を見る
  4. 全部外して、最初からやり直す
- レビューで見つけたこと
  - 2：選んでいる条件は、左の欄の各一覧（タグは階層で長い）の中で色が付くだけ。欄をたたんでいると見出しの件数しか見えず、何を選んでいるかは欄を開いて探す必要がある。
  - 3：1つだけ外すには、左の欄でその項目を探して押し直す必要がある。タグの一覧が長いとスクロールが要る。
  - 「同じ音声：（ハッシュ値の先頭12文字）…」だけが条件としてツールバーに出ていて、ほかの条件と表し方がそろっていない。
  - ツールバーに、チェックが0件のときも「チェックをすべて外す」（押せない）「チェックしたファイルだけ」が出ていて、ツールバーが2行に折り返す。探すときには使わない。

  - 「チェックをすべて外す」・「チェックしたファイルだけ」を、チェックがあるとき（か「チェックしたファイルだけ」を選んでいるとき）だけ出すようにした。チェックしている件数は、以前の指示（常にどこかに出す）のとおり常に出す（最初は件数も隠してしまい、セルフレビューで戻した）。

### 9周目：エフェクトを調整しながら、狙った音を作って書き出す
- ユースケース：扉の音を「古い洋館の扉」らしくするため、速さ・高さを下げ、リバーブを足す。値を少しずつ変えては聞き直し、納得したら保存してプレイリストの項目に結び付け、動画の編集ソフトで使うために書き出す。気になる点があれば、また調整して書き出し直す。
- 必要な操作
  1. 右の欄に扉の音を出し、エフェクトの管理画面を開く
  2. まとまりを作り、エフェクトを加える
  3. 値を変えて試聴する、を何度も繰り返す
  4. 保存し、項目に結び付ける
  5. 書き出す。調整し直して、また同じ所へ書き出す
- レビューで見つけたこと
  - 3：値を変えるたびに「▶ 試聴」を押し直す必要がある（変える→押すの2手）。鳴っている音を止める手段もない。
  - 3：試聴の横に「右の欄のファイル（…）にかけて鳴らします」「試聴するには、ファイルの一覧で…」という説明文があり、横に長い。何にかけて鳴るかは、ボタンにファイル名があれば伝わる。
  - 4：保存していないことを「保存していない変更があります」の文で知らせていて、行が混む。
  - 各エフェクトの「外す」が文字のボタンで、ほかの外す操作（✕）とそろっていない。見出しの「（上から順にかける）」は、番号の付いた並びで伝わる。
  - 5：書き出すたびに、書き出し先のフォルダを入れ直す（「参照」で選び直す）必要がある。
- 直したこと
  - 試聴のボタンを「▶ ファイル名」にし、説明文を消した（説明はマウスを乗せると出る）。鳴っている間は「■」になり、押すと止まる。
  - 鳴っている間に値や並びを変えると、0.5秒待ってから自動で鳴らし直すようにした（値を変えるだけで聞き比べられる）。
  - 保存していない変更があるときは、「保存」を目立つ色にし、文は消した。
  - 各エフェクトの「外す」を「✕」に、見出しを「中のエフェクト」にした。
  - 書き出し先の欄に、前に書き出しを始めたフォルダを入れておくようにした（書き出せなかったフォルダは覚えない）。
- テストの修正：試聴のボタンの名前を「試聴」にした。
- テストの追加：effects.mjsのE09（試聴のボタンにファイル名、値を変えると自動で鳴らし直す、止める、保存の目立ち方）、export.mjsのX05（前に書き出したフォルダが入っている）。最初はテストの前提（開いている画面、開いたままの欄）を誤っていて失敗したので直した。
- テスト：単体テスト82件、画面テスト139件、すべて成功。
