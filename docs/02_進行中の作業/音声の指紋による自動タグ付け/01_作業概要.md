# 音声の指紋による自動タグ付け

状態：実装検討中（中断。2026-11-05）

## 目的
曲の音声から指紋（Audio Fingerprinting）を作り、どの曲かをネットのサービスで調べて、アーティスト・アルバム・ジャンルなどのタグを自動で付ける。

## これまでの検討
使えるサービスの比較は `01-01_サービスの検討.md` にまとめた。要点は次のとおり。
- 無料で使えるのは AcoustID（指紋 → MusicBrainz の曲）と MusicBrainz（曲の詳しい情報）の組み合わせ。
- 指紋は Rust の rusty-chromaprint で作れる見込みだが、AcoustID で曲が見つかるかは試作で確かめる必要がある。
- 見つかるのは市販・配信の音楽で、効果音や自作の音はまず見つからない。
- 全体ロードマップの「ファイル内の情報による自動タグ付け」を先に行い、情報のない曲だけを指紋で調べる組み合わせがよい。

## 未決事項（再開したときに決める）
- 何をタグにするか（アーティスト、アルバム、ジャンル、年など）と、タグの階層への入れ方。
- 一致の点数が低い候補の扱い（自動で付けるか、確かめてから付けるか）。
- 調べる対象の選び方（チェックしたファイル、タグのないファイルなど）と、数千曲を調べるときの進み具合の出し方・中止。
- 「ファイル内の情報による自動タグ付け」と、1つの作業にするか分けるか。

## 再開するとき
1. AcoustID にアプリを登録して、アプリ用のキーをもらう（MusicBrainz・Google などのアカウントでログインが必要なので、谷口さんのブラウザで行う）。
2. 試作：手元の数曲で、rusty-chromaprint で作った指紋で AcoustID が曲を見つけられるかと、1曲あたりにかかる時間を確かめる。
3. 上の未決事項を決めて、この作業概要を仕上げ、ロードマップを作る。
