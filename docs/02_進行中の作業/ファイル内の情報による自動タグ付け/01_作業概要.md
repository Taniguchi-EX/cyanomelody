# ファイル内の情報による自動タグ付け

## 目的
音声ファイルの中の情報（タグ情報）のアーティスト・アルバム・ジャンル・作曲者をもとに、タグを自動で付ける。

調べた結果は `01-01_既存の曲の調査.md` にある（情報が入っているのは約半分の曲）。

## 範囲

### 対象の項目と付けるタグ
- ファイルの中の情報の、次の4つの項目を使う。項目ごとに、項目の名前の親のタグを置き、その下に値のタグを付ける。
  | 項目 | 親のタグ | 読むもの |
  |---|---|---|
  | アーティスト | 「アーティスト」 | アーティスト（MP3 の TPE1 など）。空なら、アルバムアーティスト（TPE2 など） |
  | アルバム | 「アルバム」 | アルバム名（TALB など） |
  | ジャンル | 「ジャンル」 | ジャンル（TCON など）。ID3 の番号の書き方（「(17)」など）はジャンル名にする |
  | 作曲者 | 「作曲者」 | 作曲者（TCOM など。WAV の INFO には作曲者の項目がない） |
- 親のタグがなければ、最上位の最後に作る（「アルバム」は今あるので、それを使う）。
- 値のタグ
  - 同じ名前のタグ（大文字・小文字の違いを含む）が既にあれば、どの親の下にあっても、そのタグを付ける（タグの名前はアプリの中で1つなので、別の親の下に同じ名前は作れない）。
  - なければ、その項目の親のタグの下の最後に作って付ける。
  - アーティストと作曲者が同じ名前なら、タグは1つ（先に作った方の親の下）。
- 値は前後の空白を除いてそのまま使う。表記ゆれ（空白の違い、「A/B」のような複数の名前など）は考えない。空の値は使わない。
- 文字コードは、曲名と同じく読み直す（作業23。MP3 の ISO-8859-1 の項目と、WAV の INFO は UTF-8 → Shift_JIS の順に判定する）。
- タグは付けるだけで、外さない（何度行っても、付くタグは同じ）。見つからないファイルは読めないので飛ばす。

### 意味のない値
- 取り込むときの確認のダイアログに「意味のない値は無視する」のチェックボックスを置く。最初は ON（ダイアログを開くたびに ON から始める）。
- チェックボックスの下に、無視する値の一覧を、薄い文字で1行に1つずつ出す。一覧はこのダイアログの中で編集できる。
  - 各行の右に「✎」（編集）と「−」（削除）。「✎」を押すと、その行が入力欄になり、Enter（か入力欄の外を押す）で決め、Esc でやめる。「−」はすぐに消す（確認しない）。
  - 一覧の最後に「＋」（追加）。押すと、最後に空の入力欄の行が出て、Enter で加える（Esc でやめる）。
  - 空の値、一覧にもうある値（大文字・小文字は区別しない）は入れられない（下にそのことを出す）。
  - 変えるとすぐに保存し、次に開いたときも同じ一覧を出す。初期値は Unknown / アーティスト情報なし / Other。
  - チェックボックスが OFF のときは、一覧を薄くし、編集はできるままにする。
- ON のときは、項目の値が一覧の値と同じ（大文字・小文字は区別しない、前後の空白は除く）なら、その値は使わない。
- 一覧はデータベースの設定に保存する（key "meta_ignore_values"）。データのエクスポート・インポートの「出典・ライセンスと設定」にも含める（新しく作るタグの既定値と同じ扱い）。

### 実行するところ
- ファイルの詳細（右の欄）と一括操作の欄に、「ファイルの情報からタグを付ける」のボタンを置く。どちらも、押すと確認のダイアログ（アプリの中のダイアログ）を出す。
  - ダイアログ：「N件のファイルの情報を読み、アーティスト・アルバム・ジャンル・作曲者のタグを付けます」（ファイルの詳細なら「このファイルの…」）、上の「意味のない値は無視する」、「タグを付ける」「やめる」（Esc でも）。
- ファイルの詳細：すぐ読み、付けたタグを下の行に出す（例：「アーティスト：米津玄師、ジャンル：J-POP を付けました」。付けるものがなければ、そのこと）。
- 一括操作の欄：対象のファイルすべてに行う。
  - たくさんのファイルを読むので、裏で行い、下の行に進み具合（「ファイルの情報からタグを付けています 120/5334」）と中止のボタンを出す（ハッシュ値の計算と同じ形）。
  - 終わったら結果（読んだファイル、タグを付けたファイル、作ったタグ、情報がなかったファイル、読めなかったファイルの数）を出し、データを読み直す。中止したときは、それまでに付けたタグは残す。

## やらないこと
- 表記ゆれの整理。上の3つのほかの意味のない値の除外。付いたタグは、ふつうのタグと同じく手で直す・統合する・消す。
- 関係IP、リリース年のタグ付け（リリース年は、長さと同じく「その他」の絞り込みにする。別の作業）。
- 付けたタグを元に戻すこと（取り消し）。
- フォルダ名からのタグ付け。
