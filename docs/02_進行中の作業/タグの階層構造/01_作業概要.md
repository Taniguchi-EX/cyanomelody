# タグの階層構造

## 目的

タグを親子の階層で整理できるようにする（例：「環境音」の下に「雨」「風」）。
タグの順番と階層は、ドラッグアンドドロップで自由に並べ替えられるようにする。

## 範囲

### やること
- タグに親子関係と、兄弟の中での順番を持たせる
- タグの管理画面で、ドラッグアンドドロップで順番と階層を変える
- 左の「タグで絞り込む」の欄を、階層（字下げ）で表示する。子を持つタグは開く・たたむができる
- 親のタグで絞り込むと、子孫のタグが付いたファイルも含める
- 削除・統合のときの子のタグの扱い

### やらないこと
- 同じ名前のタグを別の親の下に作ること（名前はこれまでどおり全体で一意。仮決定事項を参照）
- 左の欄でのドラッグアンドドロップ（左の欄は絞り込み用。並べ替えは管理画面で行う）
- キーボードでの並べ替え
- ファイルをタグにドラッグしてタグを付ける操作

## 仕様

### 階層と順番
- 各タグは、親のタグを1つまで持つ。親がないタグは最上位になる。
- 階層の深さに制限はない。
- 兄弟（同じ親を持つタグ）の中での順番を持つ。一覧はこの順番で表示する（これまでの名前の順はやめる）。
- 新しく作ったタグ（管理画面での作成、ファイルにタグを付けるときの新しい名前）は、最上位の最後に入る。
- この作業の前からあるタグは、最上位に名前の順で並べた状態から始める。

### ドラッグアンドドロップ（管理画面）
- 管理画面の一覧を階層（字下げ）で表示し、タグの行をドラッグして、別のタグの行の上に落とす。
- 落とす位置は、落とす先の行の上下の位置で決める。
  - 上の端（行の高さの1/4）：落とす先の前に入る（同じ親の兄弟になる）
  - 下の端（行の高さの1/4）：落とす先の後ろに入る（同じ親の兄弟になる）
  - 真ん中：落とす先の子の最後に入る
- ドラッグ中は、どこに入るかが分かるように、線（前・後ろ）か枠（子）を表示する。
- 自分自身や、自分の子孫の中には落とせない（その位置では表示を出さず、落としても何もしない）。
- 移すと、子孫のタグも一緒に移る。
- 一覧の下の空いた所に落とすと、最上位の最後に入る。

### 左の欄の表示
- 「タグで絞り込む」の欄を、管理画面と同じ順番と階層（字下げ）で表示する。
- 子を持つタグには開く・たたむの印を付ける。最初はすべて開いている。開閉の状態はアプリを閉じても覚えておく。
- 各タグの件数は、そのタグか子孫のタグが付いたファイルの数にする（絞り込んだときの件数と合わせる）。

### 絞り込み
- タグを選ぶと、そのタグか、その子孫のタグが付いたファイルに絞り込む。
- 複数のタグを選んだときは、これまでどおりAND（選んだタグごとに、そのタグか子孫が付いていること）。
- 親と子を両方選んだときは、子の条件が残る（結果として子が付いたファイルになる）。

### ファイルに付いているタグの表示
- 一覧の各行や右の欄のタグは、タグの一覧と同じ順番で表示する。名前だけを出し、親の名前は出さない。

### 名前変更・統合・削除
- 名前変更：階層の位置は変わらない。
- 統合：統合元の子のタグは、統合先の子の最後に移る。統合先の位置は変わらない。
- 統合先が統合元の子孫のときは統合できない（エラーにする）。
- 削除：子のタグは消さず、削除したタグがあった位置に繰り上がる（削除したタグの親の子になる）。確認のメッセージにも、子のタグが繰り上がることを書く。
- 使われていないタグの一括削除：そのタグにも子孫にもファイルが付いていないタグだけを削除する。

## データ

- tags に以下の列を加える。
  - parent_id：親のタグのid。最上位なら空。親のタグを消したときの繰り上げはアプリで行う
  - position：兄弟の中での順番（小さいほど前）

## 試作で確かめること

- WebView2（Tauri）の中で、HTMLのドラッグアンドドロップが動くか。Tauriはファイルのドロップを受け取るために、ウィンドウへのドロップを横取りすることがある。動かないときは、設定でこれを止めるか、マウスの操作で自作する。

## 仮決定した事項

- タグの名前は、階層が違っても全体で一意のままにする。ファイルにタグを付けるときに名前で指定しているため（同じ名前があると、どれか分からなくなる）。
- ドラッグアンドドロップは、管理画面だけで行う。左の欄はクリックで絞り込むので、ドラッグと混ざると誤操作しやすい。
- 親のタグで絞り込むと、子孫のタグも含める。
- 左の欄の件数は、子孫を含めた数にする。
- 親のタグを削除したとき、子のタグは繰り上げて残す（消さない）。
- 一覧の順番は、名前の順をやめて、ドラッグアンドドロップで決めた順にする。
