# 試作の結果

実施日：2026-11-11。試作のコードは `android-update-prototype` ブランチ（一時的なコマンド `app/src-tauri/src/update_proto.rs` と、設定の変更。main には入れていない）。
実機（Android 17）に USB の有線デバッグで入れて確かめた。

## 確かめたことと結果

### リリース版の APK
- Docker の中で `npx tauri android build --apk --target aarch64 --ci` でビルドできる。出てくるのは署名していない APK（`app-universal-release-unsigned.apk`）。
- 大きさ：約27MB（デバッグ版は約250〜450MB。リリース版はデバッグ情報を除き、縮める）。
- 署名：試作用の鍵（keytool で作った使い捨てのもの）で、SDK の `build-tools` の `zipalign` と `apksigner` を使って署名できた。Docker のイメージの build-tools は 34.0.0 に `zipalign` があり、36.0.0 にはない。
- 実機に入れて動く：名前は `dev.cyanomelody.app`、版は 1.3.0（versionCode 1003000）。デバッグ版（`.debug`）とは別のアプリとして並ぶ。
- コードを縮める処理（ProGuard / R8）の後も、SAF（cyanomelody 用のフォルダの設定）・Windows からのコピーの取り込み・再生が動いた（プラグインのクラスが削られていない）。

### アプリの中からの更新
- APK のダウンロード：Rust の `ureq` で、アプリのキャッシュの場所（`$APPCACHE/update/`）にダウンロードできた（250MB を約7秒。PC に立てたサーバーに `adb reverse` でつないだ）。
- インストールの画面に渡す：プラグインの `file_provider` の機能を有効にし（Cargo の feature と、`tauri.conf.json` の `plugins.android-fs.fileProvider` で `$APPCACHE/update/**/*` を許す）、`AndroidFs::get_uri_for_file_path(パス, Some("application/vnd.android.package-archive"))` で URI を作り、`Opener::open_file` で開くと、インストールの画面に進めた。マニフェストに `android.permission.REQUEST_INSTALL_PACKAGES` が要る。
- 流れ（初めて）：「どのアプリで開くか」の選び肢 → パッケージインストーラ → 「権限が必要です」（この提供元からのアプリはインストールできません）→「設定」→「この提供元のアプリを許可」をオン → 戻る。ここで流れが閉じてアプリに戻った。もう一度ダウンロードからやり直すと、「このアプリを更新しますか？」→「更新」で入れ替わった。
- 流れ（2回目から）：選び肢 → パッケージインストーラ →「このアプリを更新しますか？」→「更新」。
- 更新の後も、データ（ライブラリの49件）は残った。

## 分かったこと（本実装で守ること）
- プラグインの `open_file` は、アプリの選び肢（chooser）を出す。端末に APK を開けると名乗るほかのアプリがあると、それも並ぶ（この端末では、関係のないアプリが1つ並んだ）。パッケージインストーラだけに渡すには、自分で Intent を作る（Android のコードを足す）必要がある。まずはこの選び肢のままにし、画面で「パッケージインストーラを選んでください」と案内する（ほとんどの端末では、パッケージインストーラだけが出るはず）。
- 初めて「この提供元のアプリを許可」したときは、インストールの流れがいったん閉じる。アプリに戻ったら、もう一度「更新する」を押せば進む、と画面で案内する（ダウンロード済みのファイルがあれば、ダウンロードし直さない）。
- ダウンロードした APK は、入れた後は要らない。次に起動したときに消す。
- リリース版の署名は、`build.gradle.kts` の release に signingConfig を足し、鍵の場所とパスワードを環境変数（GitHub Actions ではシークレット）から読む形にする。

## 本実装に向けて
- 作業概要の流れのまま進められる。自動アップデートは「はい」でダウンロードし、インストールの画面を出す形にする。
