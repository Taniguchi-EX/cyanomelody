# Android の画面

状態：作業概要の検討中（画面のレイアウトをユーザーと決める）。

## 目的
Android の端末（縦長の狭い画面）で、cyanomelody を使えるようにする。内部の処理（フォルダの登録・スキャン・ハッシュ値・タグ付け・再生）は作業49で Android でも動くようにしたので、この作業では画面を作る。

## 前提（作業49までで分かっていること）
- 今の画面（左・中央・右の3列と、下の再生の欄）は、Android でもそのまま開くが、狭い画面に押し込まれて使えない（右の欄と、再生の欄の右側が見えない）。
- 画面の上の端が、端末のステータスバー（時刻など）と重なる。上下の余白（セーフエリア）を取る必要がある。
- Android では使えない操作がある（ファイルの削除・エクスプローラーで見せる・ファイルを1つ選んでのひも付け・自動アップデート・フォントの一覧・データの入出力）。今はエラーで知らせているだけなので、画面で隠す。
- 端末がダークモードのときは、暗い配色で出る。
- 確かめる端末：USB の有線デバッグでつないだ実機（縦 2424 × 横 1080 の画面）。

## 範囲（検討中）
- 画面のレイアウト：3列の内容（絞り込み・一覧・ファイルの詳細と一括操作）と、再生の欄・一番下の行を、狭い画面でどう並べ、どう切り替えるか。
- セーフエリア。
- Android で使えない操作を隠す。
- Windows の画面は変えない。

## やらないこと（仮）
- データの入出力・同期（「Androidとの同期機能」で行う）。
- 横向きの画面・タブレット向けのレイアウト（まず縦向きのスマートフォン）。
