- [ ] 音声の指紋（Audio Fingerprinting）による自動タグ付け（実装検討中・中断）
  - 曲の音声から指紋を作り、どの曲かをネットのサービスで調べて、アーティスト・アルバム・ジャンルなどのタグを付ける。
  - 検討の結果（2026-11-05）
    - 無料で使えるのは AcoustID（指紋 → MusicBrainz の曲）と MusicBrainz（曲の詳しい情報）の組み合わせ。非営利・オープンソースなら無料。AcoustID は1秒に3回、MusicBrainz は1秒に1回まで。
    - AcoustID はアプリの登録（アプリ用のキー。使う人ごとには要らない）が必要。データは CC BY-SA 3.0（MusicBrainz の基本のデータは CC0）。
    - ACRCloud・AudD は無料の枠が小さく（試用・300回など）、数千曲には有料になる。
    - 指紋は Rust の rusty-chromaprint（MIT）で作れる見込み。ただし移植の途中とされているので、AcoustID で曲が見つかるかを試作で確かめる。だめなら公式の fpcalc（LGPL）を同梱する。
    - 見つかるのは市販・配信の音楽で、効果音や自作の音はまず見つからない。
    - 上の「ファイル内の情報による自動タグ付け」を先に行い、情報のない曲だけを指紋で調べる組み合わせがよい。
  - 再開するとき：AcoustID にアプリを登録してキーをもらい（谷口さんのブラウザ）、数曲で指紋が通るかと1曲あたりの時間を試作で確かめる。何をタグにするか、点数の低い候補の扱いを作業概要で決める。
