# 全体ロードマップ

今のところやりたいことの一覧と順番。やりたいことが増えたり変わったりしたら、その都度書き換える。
各作業の詳しいロードマップは、それぞれの作業フォルダの`02_ロードマップ.md`に書く。
作業が完了したら、この一覧から消す。

## 作業概要（仮判断）を作ったもの：ユーザーのレビュー・確認を待つ
- [ ] タグとプレイリストへのイメージカラーとジャケット設定機能（作業フォルダ「イメージカラーとジャケット」）
  - タグとプレイリストに、イメージカラーとジャケット（画像）を設定する。グリッドビューの後に行う。
- [ ] 詳細な出典の設定機能（作業フォルダ「詳細な出典の設定」）
  - 今の出典（名前・URL・メモ）より詳しく、出典を設定できるようにする。何を「詳しく」するかの確認が要る。
- [ ] Android の画面（作業フォルダ「Androidの画面」）
  - 狭い画面のレイアウトを検討中。セーフエリアを取り、Android で使えない操作を隠す。
- [ ] Androidとの同期機能（作業フォルダ「Androidとの同期」）
  - WindowsとAndroidの間で、ライブラリのタグ・プレイリストなどを同期する。Android対応のあとに行う。
