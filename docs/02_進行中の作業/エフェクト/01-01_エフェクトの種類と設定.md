# エフェクトの種類と設定

## 種類と設定

| エフェクト | 設定 | 最初の値 |
|---|---|---|
| 音量調整 | 増減（dB、−30〜+12） | 0dB |
| 音量調整（自動） | そろえ方（ピーク・平均）、目標（dBFS） | ピーク、−1dBFS |
| 再生速度・音程調整 | 速度（0.5〜2.0倍）、音程（−12〜+12半音） | 1.0倍、0半音 |
| リバーブ | 残響の長さ（0.1〜5秒）、混ぜる割合（0〜100%） | 1.5秒、30% |
| エコー | 遅れ（0.05〜2秒）、繰り返しの強さ（0〜90%）、混ぜる割合（0〜100%） | 0.3秒、40%、30% |
| フェードイン | 長さ（秒） | 1秒 |
| フェードアウト | 長さ（秒） | 1秒 |

### 補足
- 音量調整（自動）：音全体を調べて、ピーク（いちばん大きい所）か平均の大きさ（RMS）が目標になるように音量を変える。平均でそろえて大きくなりすぎるときは、ピークが0dBFSを超えないところで止める。
- 再生速度・音程調整：速度と音程は別々に変えられる（速度を変えても音程は変わらず、音程を変えても長さは変わらない）。
- リバーブ・エコーは、残響の分だけ音が長くなる（終わりの残響を切らない）。
- フェードイン・フェードアウトの長さが音より長いときは、音の長さに合わせる。
- 並べた順にかけるので、たとえば「エコー → フェードアウト」と「フェードアウト → エコー」では結果が変わる。

## 処理の方法（試作で決める）

### 案A：Rust側で処理する（仮決定）
- Rustで元のファイルを読んで波形にし（symphonia などのライブラリを使う）、エフェクトをかけて、WAVにして鳴らす。
- 良い点：再生と出力で同じ処理を使える。元の形式によらず同じように扱える。
- 心配な点：鳴らす前に全体を処理するので、長い曲では鳴り始めが遅れる。速度と音程を別々に変える処理を自分で作る必要がある。

### 案B：画面側（WebView2のWeb Audio）で処理する
- 再生はWeb Audioの部品（音量、残響、遅延など）でその場で処理する。出力はOfflineAudioContextで処理して、Rustに書き出させる。
- 良い点：すぐに鳴らせる。リバーブ・エコーなどは用意された部品を使える。
- 心配な点：速度と音程を別々に変える部品はないので、結局自分で作る。再生と出力で同じ結果になるよう気を付ける必要がある。

効果音の素材は短いものが多いので、案Aの鳴り始めの遅れは小さいと見込む。試作で、数秒・1分・5分の音で時間を測って決める。
