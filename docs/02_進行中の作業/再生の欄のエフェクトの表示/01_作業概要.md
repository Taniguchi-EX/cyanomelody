# 再生の欄のエフェクトの表示

状態：検討中（作業「プレイリストの絞り込み化」の検討から分けた）

## 目的
今は、プレイリストの項目のエフェクトセットがかかる曲を鳴らしているとき、再生の欄のエフェクトセットのプルダウンがグレーアウトするだけで、何がかかっているかが見えない。かかっているエフェクトセットを再生の欄に出す。

## 要件
- プレイリストの項目のエフェクトセットがかかる曲を鳴らしている間は、再生の欄のエフェクトセットのプルダウンをグレーアウトし、項目で設定したエフェクトセットを出す。
- 入れ子で複数かかるときは、内側から外側の順に「洞窟の響き → 全体を小さく」と並べる。
- マウスを乗せると、理由（プレイリストの項目のエフェクトがかかっていること）を出す。
- 項目のエフェクトがかからない曲のときは、今までどおり再生の欄で選んだものを出す。

## 現在の想定
- 再生の順番の各曲は、かけるエフェクトセットの id を内側から外側の順に持っている（`PlayEntry.chains`）。名前はエフェクトセットの一覧から引く。
- グレーアウトしていても選び直せる、という今の動き（「エフェクト」の「再生の欄のエフェクトセット」）は変えない。選び直したものは、項目のエフェクトがかからない曲から効く。

## 決めるべき点
- 表示の形：グレーアウトしたプルダウンの中身を、項目のエフェクトセットの名前に差し替えるか、プルダウンの横に名前を出すか。名前が長いときや複数のときに、再生の欄の幅に収まるか（狭い画面の表示との兼ね合い）。
- 作業の順番：「プレイリストの絞り込み化」の前後どちらで行うか（互いに依存は小さい）。

## やらないこと
- ファイルの一覧の行に、エフェクトがかかることを示す印を付けること
