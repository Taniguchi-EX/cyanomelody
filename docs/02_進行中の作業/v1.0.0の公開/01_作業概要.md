# v1.0.0の公開

## 目的
今の版を v1.0.0 として GitHub で公開し、ほかの人がインストールして使えるようにする。以後の版は、アプリから自動で更新できるようにする。

## 範囲

### README とライセンス
- リポジトリの一番上に README.md を置く。非技術者向けに、日本語で書く。
  - このアプリの特徴
  - 導入方法（ダウンロード、インストール、Windows の警告（SmartScreen）が出たときの開き方、更新）
  - 大まかな操作方法（スクリーンショット付き。画像はテスト用のデータで撮ったものを使う）
- ライセンスは MIT（著作権者は Taniguchi-EX）。LICENSE を置く。

### 配布の形
- Windows 向けの NSIS のインストーラー（`.exe`）だけを配る。zip のポータブル版は置かない（自動アップデートで更新できないため）。
- インストール先は、管理者の権限がいらない「自分のユーザーだけ」。
- 版は 1.0.0（tauri.conf.json、Cargo.toml、package.json をそろえる）。
- アプリの名前は今のまま「cyanomelody」（オオルリの種小名から）。

### 自動アップデート
- Tauri の updater プラグインを使う。更新の情報（latest.json）は、GitHub の最新の Release から読む。
- 起動したときに新しい版を探す。見つかったら、アプリの中のダイアログで「新たなバージョンが公開されました。アプリをアップデートしますか？」と、見つかった版（v1.0.1 など）を出し、次の3つから選んでもらう。
  - はい：ダウンロードしてインストールし、アプリを再起動する。ダウンロードしている間は、そのことを出してボタンを押せなくする。失敗したら、ダイアログを閉じてエラーを下の行に出す。
  - いいえ（Esc でも）：何もしない。次に起動したときにまた聞く。
  - このバージョンをスキップ：その版では、もう聞かない（覚えておく）。もっと新しい版が出たら、また聞く。
- 探せなかったとき（オフラインなど）は、何も出さない。
- 開発用のビルド（画面テストで使うデバッグビルド）では探さない。
- 更新ファイルには、専用の鍵で署名する（偽物の更新を入れないため。有料の Windows のコード署名とは別のもの）。
  - 秘密鍵は、リポジトリの外（`C:\Users\tnms\.tauri\cyanomelody-updater.sec.key`）に置き、GitHub のシークレットにも登録する。バックアップは谷口さんが取る。鍵を無くすと、配布済みのアプリに更新を届けられなくなる。
  - 公開鍵はアプリの設定（tauri.conf.json）に書く。

### GitHub での公開
- GitHub Actions で、版のタグ（`v1.0.0` など）を押すと、Windows でビルドし、インストーラーと更新の情報を付けた Release の下書きを作る。
- 手動の操作（谷口さんのブラウザで行う）
  - 署名の秘密鍵をリポジトリのシークレットに登録する。
  - Release の下書きを確かめて公開する。
- リポジトリは公開のまま（作業記録やコミットのメールアドレスも見える）。

## やらないこと
- Windows のコード署名（有料の証明書）。
- Linux・Android 向けの配布。
- 更新の内容（変更点）をアプリの中に出すこと。
