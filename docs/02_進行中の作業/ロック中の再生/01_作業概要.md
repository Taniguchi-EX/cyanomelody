# ロック中の再生

状態：作業概要（仮判断）。ユーザーのレビューを待つ。

## 目的
Android 版で、画面をロックしたときや、ほかのアプリに切り替えたときも、再生を続ける。一般的な音楽のアプリと同じく、ロック画面と通知の欄から操作できるようにする。

## 今の状態
- 音は、画面（WebView）の中の audio 要素で鳴らしている。曲が終わると、画面の側（`useAudioPlayer`）が次の曲に移る。エフェクトをかけた曲は、Rust で作った音のファイルを鳴らす。
- 画面をロックする・ほかのアプリに切り替えると、アプリが一時停止の扱いになり、Tauri の土台（`WryActivity` の `onPause`）が WebView ごと止めるので、音も止まる。
- 裏で動いているアプリは、Android がしばらくすると眠らせたり終わらせたりする。

## 範囲（仮判断）
- 裏でも鳴らし続ける
  - アプリが一時停止の扱いになっても、再生の通知を出している間（鳴らしている・一時停止している）は、WebView を止めない（ロック画面の「▶」で再開できるように）。通知を出していないときは、今までどおり止める。
  - 鳴らしている間は、Android の「メディアの再生」のフォアグラウンドサービスを動かし、アプリが眠らされないようにする。このとき「再生中」の通知を出す（Android の決まり）。
  - 裏でも、曲が終わったら次の曲に移る（再生方法・プレイリストの抽選の並びは、画面で鳴らすときと同じ）。
- ロック画面と通知の欄の操作（ユーザーの回答：ボタンも出す）
  - 曲の名前（再生の欄の1行目と同じ）、再生しているもの（プレイリストの名前か「ファイルの一覧」と、何曲目か）、進み具合を出す。
  - ボタン：「⏮」（前へ）、「▶／⏸」、「⏭」（次へ）。動きは再生の欄のボタンと同じ。
  - 進み具合のバーを動かすと、その位置に移る（Android が出すバーで動かせるとき）。
  - イヤホン・Bluetooth の機器のボタン（再生・一時停止・次へ・前へ）でも操作できる（同じ仕組みで受け取れる）。
  - 絵は、アプリのアイコンにする（ジャケットは、作業「イメージカラーとジャケット」の後に考える）。
  - 一時停止している間は通知を残す。「■」（停止）を押したとき・最後まで鳴らし終えたときは、通知を消してサービスを止める。
- 割り込み（ユーザーの回答：一時停止する）
  - 電話がかかってきたとき・ほかのアプリが音を鳴らし始めたときは、一時停止する。自動では再開しない（ナビの案内のような短い割り込みでは、音を小さくして続ける）。
  - イヤホンを抜いた・Bluetooth の機器が切れたときは、一時停止する（スピーカーから急に鳴らない）。
- アプリを閉じたとき（ユーザーの回答：再生を止める）
  - 最近使ったアプリの一覧から払って閉じたら、再生を止め、通知を消す。
- 作り方（仮判断）
  - 音を鳴らすのは今までどおり WebView の audio 要素にし、Android の側（Kotlin）に、サービス・通知・ロック画面の操作（MediaSession）・割り込みの受け取りを置く。画面の側から、鳴らしている曲・状態・進み具合を Android の側に知らせ、Android の側で押されたボタンや割り込みは画面の側に知らせる。
  - 鳴らす仕組みを Android の側（ExoPlayer など）に移す案は、エフェクト・再生方法・抽選などの処理を Android の側にも作ることになるので、取らない。
  - 試作で、次を実機で確かめる。
    - WebView を止めずにおけば、ロック中も音が続き、曲が終わったときに次の曲へ移れるか（裏の画面の処理を Android の WebView が遅らせても、間が空きすぎないか）。
    - 30分ほど鳴らし続けても、途中で止まらないか（Android の電池の節約で眠らされないか）。
    - 通知・ロック画面のボタンと、割り込みの受け取り。
  - 試作で、ロック中に次の曲へ移れないと分かったときは、作り方を考え直してユーザーに相談する。

## やらないこと
- Windows 版の変更（Windows は今でも裏で鳴り続け、ロック画面の操作は今回の範囲外）。
- 通知・ロック画面からの「戻す」「進める」（10秒）、再生方法の切り替え、エフェクトセットの切り替え。
- 通知の欄でのジャケットの表示。
- Android Auto・スマートウォッチなどでの操作（MediaSession で一部は動くかもしれないが、確かめない）。
- 割り込みの後の自動の再開。

## 決めたこと（ユーザーの回答）
- ロック画面と通知の欄に、曲の名前と再生・一時停止・次へ・前へのボタンを出す。
- 電話・ほかのアプリの音・イヤホンを抜いたときは、一時停止する。
- 最近使ったアプリの一覧から払って閉じたら、再生を止める。
