# Androidとの同期機能

状態：作業概要（仮判断で作成）。作業「Android対応」の後に行う（全体ロードマップのとおり）。それまでは着手しない。

ユーザーの離席中に、全体ロードマップの「Androidとの同期機能」（Windows と Android の間で、ライブラリのタグ・プレイリストなどを同期する）を、仮判断で作業概要にしたもの。

## 目的
Windows で整理したタグ・プレイリストなどを、Android の端末でも使えるようにする（逆も）。

## 範囲（仮判断）
- 同期するもの：今のデータのエクスポート・インポートと同じ項目（タグ・プレイリストとエフェクト・出典とライセンスと設定）。音声ファイルそのものは同期しない（両方の端末に、同じ音声ファイルがある前提）。
- 曲の見分け方：データのインポートと同じく、パス → ハッシュ値 → 名前と大きさの順（端末でパスが違うので、ハッシュ値が主になる）。
- 同期の方法（仮判断）：最初は、エクスポートした JSON を共有フォルダ（Google ドライブなど）に置いて取り込む「手で行う同期」をそのまま使い、取り込みに「新しい方を残して混ぜる」取り込み方を加える。サーバーを立てる自動の同期は、その後に考える。
- 混ぜ方（仮判断）：タグ付け・プレイリストの項目は足し合わせる。名前を変えた・消したものは、変えた日時の新しい方を残す（そのため、各データに変えた日時を持たせる）。

## やらないこと
- 音声ファイルの転送。
- 3台以上の端末の同期（最初は2台）。

## 前提・未決事項
- Android 対応の試作の結果。
- 自動で同期したいか（サーバーを使うか）、手で行う同期でよいか。
- 消したものを同期で消すか（消したことを覚えておく仕組みが要る）。
