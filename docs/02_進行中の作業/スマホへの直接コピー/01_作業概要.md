# スマホへの直接コピー

状態：作業概要の確認済み（2026-11-11）。試作から始める。

## 目的
作業52の「Windows からのデータのコピー」を、PC とスマホを USB でつないでいるときに、Windows のアプリからスマホへ直接写す機能に変える。スマホに cyanomelody 用のフォルダを作り、その中に Windows のライブラリの全曲とデータを書き出す。スマホのアプリは、そのフォルダから取り込む。

## 決めたこと（ユーザーの回答）
- スマホの cyanomelody 用のフォルダは、内部ストレージの `Music/cyanomelody` に固定する。
- 2回目以降は差分だけ写す：スマホにない曲・変わった曲だけ写し、Windows のライブラリからなくなった曲は、スマホの cyanomelody 用のフォルダからも消す。
- Android は、最初の1回だけ cyanomelody 用のフォルダを選んで許可する。以後は、アプリを開いたときに新しいデータがあれば知らせ、項目を選んで取り込む（置き換える）。
- 作業52の Windows の「音声ファイルも入れる」はやめ、「スマホへコピー」に置き換える。Android の「ファイルを選ぶ…」（JSON だけ）は残し、「フォルダを選ぶ…」は cyanomelody 用のフォルダの設定に変える。

## 流れ（仮判断）
1. ユーザーが、スマホを USB でつなぎ、スマホで「ファイル転送」を選ぶ（Windows のエクスプローラーにスマホが出る状態。MTP）。
2. Windows：設定画面の「データ」の「スマホへコピー」で、つないでいる端末を選ぶ（1台なら、それを選んでおく）。
3. 写すものを数えて確かめる：写す曲の数と大きさ、消す曲の数。
4. 写す：`Music/cyanomelody` の中に、ライブラリのフォルダごとのフォルダ（中は相対パスのまま）と、データの `cyanomelody.json`（全項目）を書く。進み具合を出し、やめられる。データの JSON は、音声ファイルを写し終えてから最後に書く（途中でやめたときに、半端なデータを取り込まないため）。
5. Android：アプリを開いたとき、cyanomelody 用のフォルダの `cyanomelody.json` が、前に取り込んだものより新しければ、「Windows から新しいデータがあります」と知らせる。押すと設定画面の「データ」で見込みを出し、項目を選んで「取り込む」（作業52のコピーと同じ置き換え）。

## 差分の決め方（仮判断）
- スマホに前に書いた `cyanomelody.json` を読み、その中の曲（相対パス・大きさ・ハッシュ値）と、今のライブラリの曲を比べる。
  - 前にない・大きさかハッシュ値が違う → 写す（あれば消してから写す）。
  - 前にあって今ない → スマホから消す。
  - 前のデータが読めない（初めて・壊れている）ときは、スマホにあるファイル（名前と大きさ）と比べる。
- スマホのファイルが消えていた（ユーザーが消した）ときも写せるよう、写す前にスマホのフォルダの中の一覧（名前と大きさ）も見る。
- 写すのは、見つからない印のない曲だけ。

## 技術的に怪しいところ（試作で確かめる）
- Windows のアプリから、MTP の端末に書き込めるか（Windows Portable Devices の API。Rust の `windows` クレートか、それを包んだクレート）。フォルダを作る・ファイルを写す・消す・一覧を読む、日本語の名前。
- 写す速さ（数百曲・数GB）。
- MTP で書いたファイルを、Android のアプリ（SAF）からすぐに読めるか。
- Android：最初に選ぶ画面を `Music/cyanomelody` から始められるか。フォルダがまだないとき（Windows から一度も写していない）の扱い。

## やらないこと
- Wi-Fi などでの受け渡し、Android → Windows のコピー、両方向の同期。
- Windows のライブラリの一部の曲だけを写す（全曲を写す）。取り込む項目は Android で選べる。
- 複数のスマホの区別（つないだ端末に写すだけ）。

## 管理するフォルダ（ユーザーの回答）
- スマホの `Music/cyanomelody` の中は cyanomelody が管理する。Windows のライブラリにないファイルは消す。外のファイルには触らない。
- スマホの容量を空けたいときは、Windows のライブラリから外して写し直す（スマホ側で一部の曲だけ消す機能は作らない）。
