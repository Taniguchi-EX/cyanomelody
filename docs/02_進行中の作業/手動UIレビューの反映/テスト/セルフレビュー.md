# セルフレビュー

## 1回目の指摘

### 仕様との食い違い
- 作業概要では、右の欄の出典・ライセンスのボタンも「＋」としていたが、設定済みのものを置き換える操作なので「設定」のままにした（「＋」は足す意味に見えるため）。タグは足す操作なので「＋」にした。作業概要の書き方を直した。

### 不具合・境界値
- フォルダ・ファイルを選ぶダイアログを開けなかったとき、エラーが画面に出ず、何も起きないように見えた。下の欄にエラーを出すようにした。
- 欄の幅を広げたあとでウィンドウを狭くすると、中央の欄がつぶれていた（左・右の幅が固定のため）。左・右の欄の列を「最小の幅〜覚えた幅」にし、左・右の欄が最小まで縮んでから中央が縮むようにした。
- WAV の INFO のタイトルは末尾に NUL 文字が付いていて、空白の除去だけでは残った（単体テストで見つけた）。NUL も取り除くようにした。
- トラック名は読み終わるまで出さない。別のファイルに移ったときに、前のファイルのトラック名が出ないよう、読んだファイルのパスと組にして持つ。
- 右の欄のタグの入力欄の候補は、既に付いているタグを除いた。付いているタグ名を入れても「＋」は押せない。
- 右の欄で何も選んでいないときは何も出さない（空の欄）。

### 既存の機能への影響
- タグの入力欄で新しいタグを作れなくなったため、画面テストの補助関数 `addTag` は、まだないタグを管理画面で作ってから付けるようにした。
- 一括操作の欄の出典・ライセンス・タグは、今までどおり新しい名前で作れる（`CreditField` の `bulk` で分ける）。
- 一覧の色の印の書式 `hash` を、右の欄のハッシュ値から外した（これが縦に細長くなる原因だった）。
- `Collapsible` は、左の欄の「選んでいる数」に加えて、右の欄の「件数」も出せるようにした（`count`）。左の欄の表示は変わらない。

### 書き方
- 境界の部品は `Splitter` にまとめ、左右の欄で同じものを使う。幅を覚える処理は `storage.ts` の `useStoredNumber` にまとめ、ドラッグを終えたときだけ保存する。
- トラック名を読む処理は Rust の `metadata.rs` に分けた（エフェクトのデコードとは目的が違うため）。

## 2回目の指摘

### 仕様との食い違い
- なし。記号（＋・✎・🗑・🧹）と、行にマウスを乗せたときだけ出すことは、作業概要どおり。

### 不具合・境界値
- 0件でグレーアウトした行は、行全体を薄くしていたため、行の「✎」「🗑」まで押せないように見えた。使われていないタグ（0件）を消したり名前を変えたりするのはよくある操作なので、薄くするのを名前・件数などだけにし、記号と取っ手は薄くしないようにした。
- グレーアウトした行（タグ・出典・ライセンス）には `aria-disabled` を付けていたが、ARIAでは中の要素まで「押せない」扱いになり、行の「✎」「🗑」も押せないものとして扱われていた（画面テストで見つけた）。これらの行には付けず、グレーアウトは書式（class）だけで示すようにした。「（タグなし）」などの、ボタンを持たない行はそのまま。
- 出典・ライセンスの行は、名前と件数が離れて並んでいた（件数が行の中ほどに出る）。名前が残りの幅を使うようにし、件数・記号を右に寄せた（タグの行と同じ並び）。
- 名前の入力欄は、外を押すとやめる。統合の確認ダイアログが出るとウィンドウからフォーカスが外れて入力欄が閉じるが、確認の結果どおりに変える（キャンセルなら何も変えない）。キャンセルしたときに入力した名前は残らないが、入れ直せば済むため、このままにした。
- 作れなかった・変えられなかったとき（同じ名前など）は、入力欄・フォームを残し、直して続けられるようにした。
- 名前を変えずにEnterを押したときは、何もせず入力欄を閉じる（変えていないのに「変えました」と出さない）。
- 「✎」「🗑」は、行の絞り込み・中央で開く処理に届かないようにした（入力欄を押したときも同じ）。
- 出典・ライセンスのフォームは重ねて表示するので、フォームを開いている間に同じものが削除されることはない（管理画面にあった「編集中のものが削除されたら作成に戻す」処理は要らなくなった）。

### 既存の機能への影響
- 「使われていないタグを削除」は見出しの「🧹」に移した。プレイリストで使われているタグを消さないなどの決まりは変えていない。
- 中央の編集画面での、プレイリストの名前の変更・削除・子のプレイリストの作成はそのまま。
- 行の記号はキーボードのTabでは届かない（マウスを乗せる前は隠しているため）。左の欄の行はもともとキーボードで選べないため、今回は合わせない。

### 書き方
- 行の「✎」「🗑」は `RowActions`、その場の名前の入力欄は `NameInput` にまとめ、タグ・プレイリスト・出典・ライセンスで同じものを使う（`TreeParts.tsx`）。
- 管理画面（`TagManager`）を消し、出典・ライセンスの管理画面は、フォームだけの `CreditForm` にした。使わなくなった書式（管理画面の表など）も消した。
