# エフェクト（段階2の検討）

状態：決定（ユーザーの確認済み）。

SOUND VOLTEX の FX（押している間だけかかる10種類）と、つまみで動かすフィルターを参考に、近いものを作る。参考にしたのは、譜面の形式（K-Shoot MANIA の ksh 形式）の仕様にある効果の種類と設定（Retrigger・Gate・Flanger・PitchShift・BitCrusher・Phaser・Wobble・TapeStop・Echo・SideChain、フィルターの peak・hpf・lpf・bitc）。ボタンの名前は英語（音楽の制作で使う一般的な名前）にする（ユーザーの指示）。同時にかけるのは1つだけ（ユーザーの確認済み）。

## 共通の決まり
- 指を置いている間だけかかり、離すと外れる（段階1と同じ）。ただし、エコーだけは、離した後も残りの響きが自然に消えるまで鳴らす（いきなり切ると不自然なため）。
- テンポに合わせるエフェクトは、BPM のボタンで測った BPM を使う。指を置いた瞬間を拍の頭とみなす（曲の拍の位置は分からないため。合わせたいときは、拍の頭で指を置く）。
- テンポに合わせるエフェクトの横の位置は、細かさを段階で選ぶ（左から 1/4・1/8・1/12・1/16・1/24・1/32 拍。1/4 は四分音符1つ分）。横に動かすと、段階が変わったときだけ切り替わる。
- 指を置いている間、パッドに今の値（「1/16」「+5半音」など）を出す。

## 並べるエフェクト（12個。2列×6段。この順に左上から）

| ボタン | 効き方 | 横 | 縦 | BPM |
|---|---|---|---|---|
| Retrigger（リトリガー）| 指を置いた瞬間の音を、短い長さで繰り返す（「ダダダダ」）| 繰り返す長さ（1/4〜1/32）| 元の音と混ぜる割合（上ほど繰り返しだけ）| 使う |
| Gate（ゲート）| 拍に合わせて音を細かく切る（「タタタタ」）| 刻み（1/4〜1/32）| 切る深さ（上ほど無音まで切る）| 使う |
| Echo（エコー）| 拍に合わせた遅れで、音が繰り返しながら小さくなる | 遅れ（1/4〜1/16）| 繰り返しの強さ（上ほど長く残る）| 使う |
| Wobble（ワブル）| こもった音が、拍に合わせて「ワウワウ」と揺れる | 揺れの速さ（1/4〜1/32）| 揺れの幅 | 使う |
| SideChain（サイドチェイン）| 拍の頭ごとに音量が沈んで戻る（ポンプのような揺れ）| 刻み（1/4〜1/16）| 沈む深さ | 使う |
| TapeStop（テープストップ）| テープを止めたように、音が低く遅くなって止まる | 止まるまでの時間（左ほど速く止まる。0.2〜2秒）| （使わない）| 使わない |
| Pitch（ピッチ）| 音の高さだけを変える（速さは変えない）| 高さ（-12〜+12 半音。半音ずつ）| 元の音と混ぜる割合 | 使わない |
| Flanger（フランジャー）| 「シュワー」とうねる金属的な音 | うねりの速さ | 深さ（くせの強さ）| 使わない |
| Phaser（フェイザー）| 「フワフワ」と柔らかくうねる音 | うねりの速さ | 深さ | 使わない |
| BitCrush（ビットクラッシュ）| 古いゲーム機のような、ざらついた音 | 細かさ（左ほど荒い）| ビットの粗さ（上ほど荒い）| 使わない |
| LPF | 高い音を削って、こもった音にする（段階1の仮のもの）| 効く周波数 | 強さ（くせ）| 使わない |
| HPF | 低い音を削って、軽い音にする | 効く周波数（右ほど低音が消える）| 強さ（くせ）| 使わない |

- SOUND VOLTEX のつまみのフィルターのうち、ピーキング（特定の周波数だけ強める）は入れない（XY パッドでは LPF・HPF で足りるため）。ビットクラッシュは FX の方に入れた。
- 段階1の「LPF」は、この並びの LPF になる。

## 作り方（メモ）
- ブラウザの部品で作るもの：LPF・HPF・ワブル（BiquadFilter と、拍に合わせた値の動き）、ゲート・サイドチェイン（音量の動き）、エコー（Delay と、繰り返しの音量）、フランジャー・フェイザー（Delay・AllPass のフィルターを、揺れる値で動かす）、ビットクラッシュ（WaveShaper と、AudioWorklet での間引き）。
- AudioWorklet で自前で作るもの：リトリガー（指を置いた瞬間からの音を覚えて繰り返す）、テープストップ（覚えた音を、だんだん遅く読む）、ピッチ（短い区切りで読み直す方法。速さを変えずに高さだけ変える）。
- 拍に合わせる動きは、AudioContext の時刻で予定を組む（画面の描き直しの遅れに影響されないようにする）。
