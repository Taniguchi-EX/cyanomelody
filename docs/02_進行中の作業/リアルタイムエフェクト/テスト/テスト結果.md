## エミュレータ（Android 17・x86_64）
曲は試験用の `d_70s.mp3`（440Hz の音）。出口の音は、開発者ツールから `window.__cmLiveAudio.probe()` で測った。

- 全画面の再生の右上のボタンで、ライブの画面が開く。並びは作業概要のとおり（写真で確かめた）：見出しの行（←・曲名・一時停止）、左に単発の音6個と BPM のボタン、右に LPF のボタンと XY パッド。
- XY パッド：左の辺り（周波数を低く）を長押ししている間、出口の大きさが 0.119 → 0.043 に下がり（440Hz が弱まる）、パッドに印が出る。離すと 0.119 に戻り、印が消える。
- 単発の音：曲を止めて「キック」を押すと、出口に音が出る（最大 0.63）。押してから出口に音が出るまで約22ミリ秒（端末のスピーカーまでの遅れは含まない）。
- BPM：約0.58秒の間隔で6回押すと「BPM 106」と出て、覚えた値（105.8）が保存される（adb で押すときの間隔のぶれの範囲で合っている）。
- 戻る操作：ライブの画面 → 全画面の再生 → 一覧の順に戻る。
- AudioContext に通した後も、audio 要素の音量が効く（1 → 0.5 → 0.1 で 0.119 → 0.059 → 0.012）。

# テスト結果（段階2：エフェクト）

- 単体テスト 147件・画面テストすべて成功。型チェック・lint は新しい警告なし。

## エミュレータ
曲は試験用の `d_70s.mp3`（440Hz の音。大きさ 0.119）。BPM は 120（1/4 は 0.5秒）。指の位置は開発者ツールから `window.__cmLiveAudio.press({x, y}, 120)` で与え、出口の音を測った（XY パッドを指で押す操作は段階1で確かめた）。

| エフェクト | 指の位置 | 結果 |
|---|---|---|
| LPF | 左・下（150Hz）| 大きさ 0.119 → 0.015（440Hz が弱まる）|
| HPF | 右・下（8kHz）| 0.119 → 0.000 |
| Wobble | 左・上（1/4、6オクターブ）| 0.064〜0.302 で揺れる |
| Flanger | 真ん中・上 | 0.028〜0.334 で揺れる |
| Phaser | 真ん中・上 | 0.025〜0.142 で揺れる |
| Gate | 左・上（1/4、深さ100%）| 1.5秒の間に、鳴る（0.119）と無音（0.000）が6回切り替わる（0.25秒ずつ）|
| SideChain | 左・上（1/4）| 0.029〜0.119 で、1.5秒の間に8回上下する |
| Pitch | 右・上（+12半音）／左（-12半音）| 零交差から数えた周波数が、曲のままの約1.85倍／約0.51倍になる。単独の 440Hz の音では 441Hz → 861Hz／230Hz |
| BitCrush | 左・上（4ビット、40点ずつ）| 波の値の種類が 945 → 3 に減り、同じ値が続く。離すと元に戻る |
| Retrigger | 左・上（1/4）| 0.7秒置いてから曲を一時停止しても、0.119 で鳴り続ける（覚えた音を繰り返す）。離すと無音（一時停止中なので）|

| Echo | 左・上（1/4、強く残る）| 指を離して曲を一時停止した直後も 0.101〜0.188 で鳴り、3秒後も 0.032〜0.060 で残る（だんだん小さくなる）|

- パッドに出す今の値：「150Hz」「8.0kHz」「1/4」「+12半音」「4bit」「0.2秒」などが返る。
