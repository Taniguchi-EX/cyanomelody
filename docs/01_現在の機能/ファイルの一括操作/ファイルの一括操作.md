# ファイルの一括操作

ファイルの一覧でファイルをチェックして集め、チェックしたファイルを左の欄にドラッグしてまとめて操作する。
チェックは絞り込みの条件を変えても外れないので、条件を変えながら対象を少しずつ集められる。

## チェックボックス

- ファイルの一覧の各行の右端にチェックボックスがある。押すとチェック・チェックを外すができる。
- チェックは、絞り込みの条件を変えても外れない。一覧に見えていないファイルのチェックも残る。
- チェックボックスを押しても、右の欄に表示しているファイル（行のクリックで選ぶ）は変わらない。
- チェックしている行には、右の欄に表示している行より薄い色を付ける（両方なら、右の欄に表示している行の色）。
- 1件以上チェックしているときに出る中央のツールバーの「全てチェック」で、表示中のファイルをすべてチェックする（表示中がすべてチェック済みのときは押せない）。1件もチェックしていないときは、1件チェックしてから押す。一覧の見出しの行（すべてチェックするチェックボックス）はない。
- 一覧にフォーカスがあるときにCtrl+Aを押すと、表示中のファイルをすべてチェックする。
- Shiftを押しながらチェックボックスを押すと、前に押したチェックボックスの行との間を、押した行の新しい状態（チェックする・外す）にそろえる。前に押した行が今の一覧にないときは、押した行だけが変わる。
- ライブラリから消えたファイル（フォルダの登録解除、見つからないファイルを外す、ひも付け直し）は、チェックからも外れる。
- チェックの状態は、アプリを閉じると消える。

## チェックしている件数

- ウィンドウの一番下の行（処理の結果を出す行）の右側に、一覧の件数と、チェックしている件数を常に表示する。0件のときも出す。
- 表示中のうちの件数も出す（例：「チェック 12件（表示中 5件）」）。
- 中央のツールバーの「チェックをすべて外す」で、チェックをすべて外す。
- 中央のツールバーには「全てチェック」「チェックをすべて外す」「チェックしたファイルだけ表示」だけを置き、チェックがあるとき（か「チェックしたファイルだけ表示」を選んでいるとき）だけ出す。出すものがないときは、ツールバーの行自体を出さない。

## チェックしたファイルだけを表示

- 中央のツールバーの「チェックしたファイルだけ表示」で、チェックしたファイルだけに絞り込む。ほかの絞り込みの条件とはANDで組み合わせる。
- 表示中にチェックを外すと、そのファイルは一覧から消える。
- チェックをすべて外すと、「チェックしたファイルだけ表示」も外れる（チェックがないときは出さない）。

## まとめての操作（ドラッグ）

- チェックした行をつかんで左の欄の行に落とすと、チェックしたファイルすべて（表示中かどうかによらない）に対して操作する。チェックしていない行をつかんだときは、その1件だけ。
  - タグの行：そのタグを付ける（「音声のタグ管理」を参照）
  - プレイリストの行：その最後に加える（「プレイリスト」を参照）
  - 出典・ライセンスの行：それを設定する。設定済みなら置き換わる（「出典とライセンスの管理」を参照）
  - 「（タグなし）」「（出典なし）」「（ライセンスなし）」の行には落とせない。
- どれもすぐ元に戻せる操作なので、確認は出さない。終わったら下の行に「n件に…しました」と出す。
- 操作の後もチェックは外さない（続けて別の操作ができる）。
- まとめて外す操作（タグ・出典・ライセンスを外す）と、見つからないファイルのまとめての「ひも付け直す」「ライブラリから外す」はない。右の欄で1件ずつ行う（以前の「一括操作の欄」は、5回目の手動UIレビューでなくした）。

## データ

- データベースの変更はない。チェックの状態は画面の中だけで持つ。データが変わるたびに、チェックしたidのうちライブラリにあるものを問い合わせ、消えたファイルをチェックから外す。
- チェックしたファイルのidは、数万件でもSQLの引数の数の上限にかからないよう、JSONの配列1つとして渡す。
