# ファイルの一括操作

ファイルの一覧でファイルをチェックして集め、チェックしたファイルをまとめて操作する。
チェックは絞り込みの条件を変えても外れないので、条件を変えながら対象を少しずつ集められる。

## チェックボックス

- ファイルの一覧の各行の右端にチェックボックスがある。押すとチェック・チェックを外すができる。
- チェックは、絞り込みの条件を変えても外れない。一覧に見えていないファイルのチェックも残る。
- チェックボックスを押しても、右の欄に表示しているファイル（行のクリックで選ぶ）は変わらない。
- 一覧の上の見出しの行の右端に、表示中のファイルをすべてチェックするチェックボックスがある。
  - 表示中のファイルの一部だけチェックしているときは「－」の表示になる。
  - 押すと表示中のファイルをすべてチェックする。すべてチェック済みのときに押すと、表示中のファイルのチェックをすべて外す。
- 一覧にフォーカスがあるときにCtrl+Aを押すと、表示中のファイルをすべてチェックする。
- Shiftを押しながらチェックボックスを押すと、前に押したチェックボックスの行との間を、押した行の新しい状態（チェックする・外す）にそろえる。前に押した行が今の一覧にないときは、押した行だけが変わる。
- ライブラリから消えたファイル（フォルダの登録解除、見つからないファイルを外す、ひも付け直し）は、チェックからも外れる。
- チェックの状態は、アプリを閉じると消える。

## チェックしている件数

- ツールバーに、チェックしている件数を常に表示する。0件のときも出す。
- 表示中のうちの件数も出す（例：「チェック 12件（表示中 5件）」）。
- 隣の「チェックをすべて外す」で、チェックをすべて外す。

## チェックしたファイルだけを表示

- ツールバーの「チェックしたファイルだけ」で、チェックしたファイルだけに絞り込む。ほかの絞り込みの条件とはANDで組み合わせる。
- 表示中にチェックを外すと、そのファイルは一覧から消える。
- 「絞り込みを解除」で外れる。チェック自体は外れない。

## 一括操作の欄

- チェックしているファイルがあるとき、一覧の上に一括操作の欄を出す。
- 操作の対象は、チェックしたファイルすべて（表示中かどうかによらない）。
- 「タグを付ける」「タグを外す」「出典」「ライセンス」のボタンで、それぞれの操作の欄を開く（もう一度押すと閉じる）。
  - タグを付ける：タグの名前を入力して付ける。まだない名前なら作る。
  - タグを外す：チェックしたファイルに付いているタグを、タグの一覧の順に、付いているファイルの数（「2/12」のように）と一緒に出す。「外す」で、そのタグをチェックしたファイルすべてから外す。
  - 出典・ライセンス：設定の内訳（すべて同じならその名前、違うときは「（ばらばら）」と設定ごとの件数）を出し、設定・外すができる（「出典とライセンスの管理」を参照）。
- チェックしたファイルに見つからないファイルがあるときは、その件数と、「ひも付け直す」「ライブラリから外す」のボタンを出す。
  - ひも付け直す：チェックしたうちの見つからないファイルを、ひも付け直す（「ハッシュ値を使った機能」を参照）。
  - ライブラリから外す：チェックしたうちの見つからないファイルを、ライブラリから外す（「音声のタグ管理」を参照）。
- 操作の前に、対象の件数を出して確認する（例：「チェックした12件にタグ「雨」を付けますか？」）。「キャンセル」を選ぶと何もしない。
- 操作の後もチェックは外さない（続けて別の操作ができる）。

## データ

- データベースの変更はない。チェックの状態は画面の中だけで持つ。
- チェックしたファイルのidは、数万件でもSQLの引数の数の上限にかからないよう、JSONの配列1つとして渡す。
