# タグ自体の管理

タグそのものを作成・名前変更・統合・削除し、シノニム（別の名前）、階層と順番、表示の色を決める。ファイルへのタグの付け外しは「音声のタグ管理」を参照。
操作は左の「タグ」の欄と、そこから開くタグの詳細画面で行う。行の操作・ドラッグでの並べ替え・開閉の共通の決まりは`00_全体/画面の構成.md`を参照。

## 階層と順番

- 各タグは、親のタグを1つまで持つ。親がないタグは最上位になる。階層の深さに制限はない。
- 兄弟（同じ親を持つタグ）の中での順番（ドラッグで決めた順）を持つ。左の欄では、親の次にその子孫が続く順に、字下げして並べる。
- 親のタグが子のタグの並び順を決めているときは、その子はその順に並ぶ（下の「子のタグの並び順」）。
- 新しく作ったタグ（左の欄の「＋」、右の欄でまだない名前を入れたとき）は、最上位の最後に入る。
- タグの名前は、階層が違っても全体で一意。
- 親のタグで絞り込むと、子孫のタグが付いたファイルも含める。件数も、そのタグか子孫のタグが付いたファイルの数（同じファイルは1回だけ数える）。
- タグは、名前と階層・順番のほかに、子のタグの並び順と、背景色・文字色を持つ（詳細画面で決める）。

## 左の欄の行

- 左から、開閉の印、名前、「✎」（詳細を設定する）、「🗑」（削除）、件数。
- 名前を押すと絞り込む。行のドラッグで並べ替える（並べ替えても、絞り込みの条件は変わらない）。

## 作成

- 見出しの「＋」を押すと、一覧の上に名前の入力欄が出る。Enterで、ファイルに付けずにタグを作る。
- ほかのタグの名前・シノニムと同じ名前のタグは作れない（大文字・小文字の違いは同じとみなす。エラーを出す）。

## 詳細画面

- 行の「✎」を押すと、タグの詳細画面（ダイアログ）を出す。「保存」（タグ名の欄ではEnterでも）で保存して閉じる。「やめる」・Escで、何もせず閉じる。
- タグ名：名前を変える。空の名前では保存できない。
  - 名前を変えても、階層の位置は変わらない。
  - 別の既存のタグと同じ名前か、別のタグのシノニムと同じ名前にするときは、そのタグに統合するか確認する（「統合」）。統合したときは、詳細画面で決めた並び順・色・シノニムは保存しない。
  - 自分のシノニムの1つと同じ名前にしたときは、そのシノニムを一覧から外す（名前とシノニムの入れ替えに使える）。
- 子のタグの並び順：「親の設定を引き継ぐ」（作ったタグは、設定画面の「一般」で決めた既定値。決めていなければこれ）・「ドラッグで決めた順」・「登録順」・「ファイル数順」・「ローマ字順」と、「昇順」「降順」（「親の設定を引き継ぐ」「ドラッグで決めた順」では選べない。引き継ぐときは引き継いだ値を出す）。
  - 「親の設定を引き継ぐ」のときは、横に実際の並び順（「今はローマ字順・昇順」など）を出す。
- 背景色・文字色：それぞれ「色を付ける」のチェックと色の選択。付けないときは「親の色を引き継ぐ」と出す。
- 見本：設定した色（親から引き継ぐ色を含む）で、タグ名のチップを出す。
- シノニム（画面の一番下）：このタグの別の名前の一覧（下の「シノニム」）。各行の「✎」で編集、「−」で消し、一覧の下の左端の「＋」で加える（ファイルの情報からのタグ付けの「無視する値」の一覧と同じ操作）。一覧の変更は「保存」でまとめて保存する。入力している間は「保存」を押せない。入れられないときの理由は赤い文字で出す。

### 子のタグの並び順
- そのタグの直下の子の並びを決める。孫の並びは、子のタグの設定で決まる。最上位のタグの並びは、ドラッグで決めた順だけ。
- 「親の設定を引き継ぐ」タグは、親のタグが実際に子を並べる順（親も引き継ぐなら、さらにその親）で、自分の子を並べる。昇順・降順も引き継ぐ。最上位までたどって決まっていなければ、ドラッグで決めた順。
- 登録順：タグを作った順。ファイル数順：左の欄に出す総数（子孫のタグの分を含み、絞り込みには関係しない）。ローマ字順：名前をローマ字にした文字の順。
  - ローマ字にするのは、ひらがな・カタカナ（ヘボン式）。英字は大文字・小文字を区別せず、全角の英数字は半角として扱う。漢字などはそのまま残る（ローマ字の後ろに、文字コードの順で並ぶ）。
- 同じ値どうしは、ドラッグで決めた順に並べる。
- 並び順を決めたタグの子も、行のドラッグで前・後ろに落とせるが、並びは決めた順のまま（ドラッグで決めた順だけが変わる）。「ドラッグで決めた順」に戻すと、その順になる。
- 左の欄のほか、ファイルの行のタグの並びなど、タグの順を使うところすべてに効く。

### 色
- ライブラリのファイルの行のタグと、右の欄のファイルの詳細の付いているタグのチップに、背景色・文字色を付ける（左の欄の行や、条件のチップには付けない）。
- 色のないタグは、親（親にもなければその親…）の色を引き継ぐ。背景色と文字色は別々に引き継ぐ。親子両方に色があれば、子の色を使う。

## シノニム

- タグに、別の名前（シノニム）をいくつでも付けられる。複数の名義で活動しているアーティストなどを、1つのタグでまとめて管理するのに使う。
- シノニムは、次のところで、そのタグの名前と同じように扱う。
  - ファイルの詳細・一括操作の欄の「付けるタグ名」：候補はシノニムでも引っかかり、タグ名の横にシノニムを出す。シノニムを入れて Enter を押すと、そのタグを付ける（新しいタグは作らない。もう付いていれば何もしない）。
  - 左の欄の検索：シノニムが当てはまるタグも出す。
  - ファイルの情報からのタグ付け：値がシノニムと同じなら、そのタグを付ける（「音声のタグ管理」を参照）。
- 重なりは許さない（大文字・小文字の違いは同じとみなす）。シノニムは、ほかのタグの名前・シノニムと同じにできない。加えるときにその場で理由（「「X」は、タグ「Y」の名前です」など）を出して入れない。保存のときも確かめ、重なればエラーを出して何も変えない。同じタグの中で、タグ名やほかのシノニムと同じものも入れない。
- 左の欄のタグの行の名前にマウスを乗せると、名前とシノニムを出す。
- タグを削除すると、そのシノニムも消える。

## 統合

- 統合元のタグが付いていたファイルに統合先のタグを付けて、統合元のタグを削除する。両方が付いていたファイルは、統合先が1つ付いた状態になる。
- 統合元の子のタグは、統合先の子の最後に移る。統合先の位置は変わらない。
- 統合元の名前とシノニムは、統合先のシノニムの最後に加わる（統合の確認にも書く）。
- 統合先が統合元の子孫のときは、統合できない（エラーを表示する）。
- プレイリストのタグの組み合わせの中の統合元のタグも、統合先に置き換わる。
- 統合元のタグで絞り込んでいたときは、統合先のタグでの絞り込みに置き換わる。

## 削除

- 行の「🗑」を押すと確認する。子のタグがあるときは、子が繰り上がることも書く。
- 削除すると、すべてのファイルからそのタグが外れる。ファイル自体は消えない。
- 子のタグは消さず、削除したタグがあった位置に繰り上がる（削除したタグの親の子になる）。
- プレイリストのタグの組み合わせからも外れる。タグが1つもなくなった組み合わせの項目は外れる。
- 削除したタグで絞り込んでいたときは、その条件が外れる。
- どのファイルにも付いていないタグも残る。まとめて消す機能はなく、1つずつ消す。

## 新しく作るタグの既定値
- 設定画面の「一般」で、新しく作るタグの子のタグの並び順（と昇順・降順）・背景色・文字色の既定値を決められる（「設定画面」を参照）。
- タグをどこで作ったとき（左の欄の「＋」、右の欄やチェックの操作で、まだない名前を入れたとき）にも、作ったタグにこの値を設定する。今あるタグは変わらない。
- 最初は、並び順は「親の設定を引き継ぐ」、色はなし（親の色を引き継ぐ）。

## データ

- tags に、親のタグのid（parent_id）と、兄弟の中のドラッグで決めた順番（position）を持つ。
- tags の child_sort（NULL は親の設定を引き継ぐ・manual（ドラッグで決めた順）・created・files・romaji）と child_sort_desc（降順なら1）：子のタグの並び順
- tags の bg_color・fg_color：背景色・文字色（`#rrggbb`。NULL は親の色を引き継ぐ）
- tag_synonyms：シノニム（タグid、シノニム、並び順）。シノニムは表全体で重ならない（大文字・小文字は区別しない）。タグを消すと消える。
- settings：アプリの設定（key・value）。新しく作るタグの既定値は key "new_tag" に、タグの詳細画面の設定と同じ形の JSON で持つ。
