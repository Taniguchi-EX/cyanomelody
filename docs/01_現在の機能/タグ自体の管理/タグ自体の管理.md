# タグ自体の管理

タグそのものを作成・名前変更・統合・削除し、階層と順番を決める。ファイルへのタグの付け外しは「音声のタグ管理」を参照。
操作はすべて左の「タグ」の欄で行う（専用の管理画面はない）。行の操作・ドラッグでの並べ替え・開閉の共通の決まりは`00_全体/画面の構成.md`を参照。

## 階層と順番

- 各タグは、親のタグを1つまで持つ。親がないタグは最上位になる。階層の深さに制限はない。
- 兄弟（同じ親を持つタグ）の中での順番を持つ。左の欄では、親の次にその子孫が続く順に、字下げして並べる。
- 新しく作ったタグ（左の欄の「＋」、右の欄でまだない名前を入れたとき）は、最上位の最後に入る。
- タグの名前は、階層が違っても全体で一意。
- 親のタグで絞り込むと、子孫のタグが付いたファイルも含める。件数も、そのタグか子孫のタグが付いたファイルの数（同じファイルは1回だけ数える）。
- タグには、名前と階層・順番のほかの属性はない。

## 左の欄の行

- 左から、開閉の印、名前、「✎」（名前を変える）、「🗑」（削除）、件数、取っ手（≡）。
- 名前を押すと絞り込む。取っ手のドラッグで並べ替える（並べ替えても、絞り込みの条件は変わらない）。

## 作成

- 見出しの「＋」を押すと、一覧の上に名前の入力欄が出る。Enterで、ファイルに付けずにタグを作る。

## 名前変更

- 行の「✎」を押すと、その行の名前が入力欄になる（字下げはそのまま）。名前を変えずにEnterを押すと、何もせず閉じる。
- 名前を変えても、階層の位置は変わらない。
- 別の既存のタグと同じ名前にするときは、統合するか確認する。

## 統合

- 統合元のタグが付いていたファイルに統合先のタグを付けて、統合元のタグを削除する。両方が付いていたファイルは、統合先が1つ付いた状態になる。
- 統合元の子のタグは、統合先の子の最後に移る。統合先の位置は変わらない。
- 統合先が統合元の子孫のときは、統合できない（エラーを表示する）。
- プレイリストのタグの組み合わせの中の統合元のタグも、統合先に置き換わる。
- 統合元のタグで絞り込んでいたときは、統合先のタグでの絞り込みに置き換わる。

## 削除

- 行の「🗑」を押すと確認する。子のタグがあるときは、子が繰り上がることも書く。
- 削除すると、すべてのファイルからそのタグが外れる。ファイル自体は消えない。
- 子のタグは消さず、削除したタグがあった位置に繰り上がる（削除したタグの親の子になる）。
- プレイリストのタグの組み合わせからも外れる。タグが1つもなくなった組み合わせの項目は外れる。
- 削除したタグで絞り込んでいたときは、その条件が外れる。
- どのファイルにも付いていないタグも残る。まとめて消す機能はなく、1つずつ消す。

## データ

- tags に、親のタグのid（parent_id）と、兄弟の中の順番（position）を持つ。
