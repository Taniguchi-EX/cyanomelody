# 音声のタグ管理

ライブラリにするフォルダを登録して音声ファイルを取り込み、ファイルにタグを付けて絞り込む。

## 画面の構成

- 左：ライブラリ（登録したフォルダ）の一覧、タグ、プレイリスト（「プレイリスト」を参照）、出典、ライセンス。タグ・出典・ライセンスは絞り込みに使う
- 中央：ファイルの一覧と、検索などでの絞り込み。プレイリストを開いているときは、その編集画面（「プレイリスト」を参照）
- 中央の上：チェックしたファイルの一括操作（チェックしているときだけ。「ファイルの一括操作」を参照）
- 右：一覧でクリックしたファイル1件の詳細と、タグの付け外し、出典・ライセンスの設定（「出典とライセンスの管理」を参照）、見つからないファイルの扱い
- 下：プレイリストの再生の欄（再生中だけ）と、処理の結果やエラーの表示

### 欄の幅
- 左・中央・右の欄の境界をドラッグすると、左と右の欄の幅を変えられる。中央の欄は残りの幅を使う。
- 境界は、マウスを乗せると色が変わり、カーソルが左右の矢印になる。
- 左・右の欄は180px、中央の欄は320pxより狭くならない。ウィンドウを狭くしたときは、左・右の欄が180pxまで縮んでから中央の欄が縮む。
- 変えた幅は、アプリを閉じても覚えておく。

### 左の欄
- 「ライブラリ」「タグ」「プレイリスト」「出典」「ライセンス」の5つの欄を、この順に同じ階層に並べる。
- 見出しを押すと、その欄をたたむ・開くができる。最初はすべて開いている。たたんだ状態はアプリを閉じても覚えておく。
- 絞り込みの条件を選んでいる欄（ライブラリ・タグ・出典・ライセンス）は、見出しに選んでいる数を出す（たたんでいても分かる）。
- 見出しの右のボタン（ライブラリの「追加」、タグ・出典・ライセンスの「管理」など）は、たたんでいても押せる。

### 選んだときの件数とグレーアウト
- 左の欄の各項目（タグ、出典、ライセンスと、「（タグなし）」などの「なし」）には、その項目を選んだときの件数を出す。
  - タグ：いまの絞り込みの条件（「（タグなし）」を除く）に合うファイルのうち、そのタグか子孫のタグが付いたものの数（タグどうしはANDのため）
  - 出典・ライセンス：同じ欄の条件を除いた、ほかのすべての条件に合うファイルのうち、それが設定されたものの数（同じ欄どうしはORのため）
  - 「なし」の項目：同じ欄の条件を除いた、ほかのすべての条件に合うファイルのうち、タグ（出典、ライセンス）がないものの数
  - 「ほかの条件」には、ファイル名、見つからないファイルだけ、重複しているファイルだけ、同じ音声、チェックしたファイルだけを含む。
  - 絞り込みの条件がないときは、そのタグなどが付いたファイルの総数になる。
- 件数が0の項目はグレーアウトし、押しても選べない。条件がないときも、0件の項目（どのファイルにも付いていないタグなど）はグレーアウトする。
- 選んでいる項目は、件数が0でもグレーアウトせず、押して選択を外せる。
- 「管理」のボタン、開く・たたむの印、タグの並べ替えの取っ手はグレーアウトしない。
- 件数は、絞り込みの条件を変えたときと、データが変わったとき（タグの付け外しなど）に、一覧と一緒に求め直す。ファイル名の入力中は、一覧と同じく少し待ってから求め直す。
- 件数は、SQLでタグ以外の条件に合うファイルを取り出し、タグの条件と数えるのはメモリの上で行う（3万ファイル・300タグで60ms以下）。

## ライブラリ

- フォルダを複数登録できる。「追加」を押すとフォルダを選ぶダイアログを開き、選ぶとそのまま登録する（キャンセルしたときは何もしない）。
- 既に登録したフォルダ自体・その中のフォルダ・その親フォルダは登録できない（同じファイルの二重取り込みを防ぐ）。
- 登録すると、そのフォルダをスキャンする。取り込んだファイルを整理できるよう、絞り込み・チェック・右の欄の表示をすべて外し、そのフォルダのファイルだけを表示する。
- 「✕」（登録解除）で登録を解除できる。解除の前に確認し、解除するとそのフォルダのファイルの情報と、付けたタグ・出典・ライセンスの設定がアプリから消える。実際のファイルは消えない。
- フォルダごとに、フォルダの名前（パスの最後。マウスを乗せるとパス全体）、ファイルの件数、見つからないファイルがあれば「⚠」とその件数、「⟳」（スキャン）、「✕」（登録解除）を1行に出す。
- フォルダの行を押すと、そのフォルダのファイルだけに絞り込む（ほかの条件とAND）。もう一度押すと外れる。

## スキャン

- 「⟳」（スキャン。フォルダが複数あるときは「すべてスキャン」も）を押したときと、フォルダを登録したときに行う。アプリの起動時には行わない。
- 登録したフォルダの中を、サブフォルダも含めて調べる。シンボリックリンクはたどらない。
- 対象は拡張子がmp3・wav・flac・ogg・m4aのファイル（大文字・小文字は区別しない）。
- ファイルは「登録したフォルダ」と「そのフォルダからの相対パス」で識別する。
  - 新しく見つかったファイルを追加する。
  - 以前あったのに見つからなくなったファイルには、見つからない印を付ける。付けたタグは残す。
  - 印が付いたファイルが同じ場所に戻ってきたら、印を外す。
  - ファイルのサイズと更新日時を記録する。サイズか更新日時が変わったファイルは、ハッシュ値を計算し直す（「ハッシュ値を使った機能」を参照）。
- 登録したフォルダ自体が見つからないとき（外付けドライブを外しているときなど）は、エラーを表示する。中のファイルに印は付けない。
- 結果として、見つかった件数・追加した件数・見つからなくなった件数・戻った件数を表示する。
- スキャンが終わると、ハッシュ値の計算を裏で始める（「ハッシュ値を使った機能」を参照）。

## ファイルの一覧と絞り込み

- ファイルを、フォルダ・相対パスの順に一覧表示する。数万件でも見えている行だけを描画する。
- 各行に、再生ボタン、見つからない印（⚠）、相対パス、付いているタグ（タグの一覧と同じ順）を表示する。見つからないファイルは名前に取り消し線を引く。
- 以下の条件で絞り込める。条件は組み合わせられる。
  - ツールバーの「検索」の欄：ファイル名（相対パス）の部分一致。大文字・小文字は区別しない。
  - タグ。そのタグか、その子孫のタグが付いたファイルに絞り込む。複数のタグを選ぶと、選んだタグごとの条件をすべて満たすファイルに絞り込む（AND）。
  - タグなし。「（タグなし）」を選ぶと、タグの選択は解除される（逆も同じ）。
  - 見つからないファイルだけ（ツールバーの「⚠」。見つからないファイルがあるときか、選んでいるときだけ出す。マウスを乗せると件数）
  - 重複しているファイルだけ、同じ音声のファイル（「ハッシュ値を使った機能」を参照）
  - 出典、ライセンス（「出典とライセンスの管理」を参照）
- 選んでいる絞り込みの条件（フォルダ、タグ、タグなし、出典、ライセンス、出典なし、ライセンスなし、同じ音声）は、一覧の上にチップで並べる。種類の記号（📁フォルダ・🏷タグ・🔗出典・⚖ライセンス・🔊同じ音声）と名前と「✕」を出し、押すとその条件だけを外す。左の欄の長い一覧の中から選んだ項目を探さなくても、何で絞り込んでいるかがわかり、1つずつ外せる。条件がないときは出さない。
- 何かを絞り込んでいるか、チェック・右の欄の表示があるときは、ツールバーに「✕」（すべて解除）を出す。押すと、絞り込みの条件（フォルダ、ファイル名、タグ、出典、ライセンス、見つからない・重複・チェックしたファイルだけ、同じ音声）、チェック、右の欄の表示をすべて外す。
- 絞り込みの条件だけを外すときは、選んでいる項目をもう一度押す。
- 件数と、選んでいる件数を表示する。

## 確認のダイアログ

- 登録解除や削除など、元に戻せない操作の前には、OSのダイアログで確認する。「キャンセル」を選ぶと何もしない。

## ファイルのクリック（詳細の表示）

- 行（チェックボックスと再生ボタン以外の部分）をクリックすると、そのファイル1件を右の欄に表示する。Ctrl・Shiftを押しながらのクリックも同じ（複数選択はしない）。
- 右の欄には、そのファイル1件について、次の順に表示し、操作する。見出しの「ファイルの詳細」などは出さない。何もクリックしていないときは、右の欄は空。
  1. トラック名：音声ファイルのタグ情報（MP3 の ID3、WAV の INFO、FLAC・OGG の Vorbis コメント、M4A の MP4 のメタデータ）のタイトル。右の欄に出すときにファイルから読む（データベースには保存しないため、一覧への表示や検索はしない）。タイトルがないファイルや、見つからないファイルでは出さない。
  2. ファイル名：ライブラリのフォルダからの相対パス。マウスを乗せると絶対パスを出す。
  3. タグ：付けるタグの入力欄と、付いているタグの一覧（「タグ」を参照）
  4. プレイリスト：このファイルを直接入れているプレイリスト（押すと開く）と、加えるプレイリストを選ぶ欄
  5. 出典、ライセンス（「出典とライセンスの管理」を参照）
  6. ハッシュ値と「同じ音声のファイルを探す」（「ハッシュ値を使った機能」を参照）
  7. 見つからないファイルのときは、「⚠ 見つからないファイル」の操作（「見つからないファイルの扱い」を参照）
- 「タグ」と「プレイリスト」は、行の数が増えるため、見出しを押すとたたむ・開くができる。見出しには件数（付いているタグ、入っているプレイリストの数）を出す（たたんでいても分かる）。たたんだ状態はアプリを閉じても覚えておく。
- 右の欄に表示しているファイルが絞り込みで一覧から消えたときは、右の欄の表示も消える。
- 複数のファイルをまとめて操作するときは、行の右端のチェックボックスでチェックする（「ファイルの一括操作」を参照）。

## タグ

- タグは名前だけを持つ。名前の大文字・小文字は区別しない。前後の空白は取り除く。空の名前や制御文字を含む名前は付けられない。
- 右の欄の「タグ」で、表示中のファイルにタグを付けられる。入力欄には、既にあって、まだ付いていないタグ名が候補に出る。名前を入れて「＋」かEnterで付ける（大文字・小文字は区別しない）。
- 右の欄では新しいタグは作れない。まだないタグ名・付いているタグ名・空の名前では「＋」を押せない。新しいタグは、タグの管理画面か、一括操作の欄で作る。
- 入力欄の下に、表示中のファイルに付いているタグを一覧し、「✕」（外す）で外せる。
- 複数のファイルへのタグの付け外しは、チェックして一括操作の欄で行う（「ファイルの一括操作」を参照）。
- 左のタグの一覧は階層で表示し、各タグを選んだときの件数（「選んだときの件数とグレーアウト」を参照）を表示する（並べ替えなどは「タグ自体の管理」を参照）。どのファイルにも付いていないタグも残る（削除は「タグ自体の管理」で行う）。

## 試聴

- 一覧の再生ボタンで再生し、もう一度押すと停止する。同時に再生できるのは1件。プレイリストの再生中なら、プレイリストの再生は止まる。
- 試聴中の行の下端に、進み具合を細いバーで出す。
- キーボード（一覧にフォーカスがあるとき）
  - ↑・↓：右の欄に表示するファイルを、上・下の行に移す（画面の外なら見える所までスクロールする）。試聴中なら、移った先のファイルを続けて試聴する（聞き比べ）。
  - スペース：右の欄に表示しているファイルの試聴を始める・止める（ボタンやチェックボックスの上では、そちらの操作になる）。
- 見つからないファイルは再生できない（↑・↓で移っても試聴は始めない）。
- 再生できなかったときはエラーを表示する。

## 見つからないファイルの扱い

- 右の欄に表示したファイルが見つからないファイルのとき、「ライブラリから外す」が出る。チェックしたファイルに見つからないファイルが含まれるときは、一括操作の欄にも出る。
- 外す前に確認し、外すとファイルの情報と、付けたタグ・出典・ライセンスの設定が消える。見つからない印が付いていないファイルは外れない。
- 移動したファイルへのひも付け直しは「ハッシュ値を使った機能」を参照。

## データ

アプリのデータ領域（`%APPDATA%\dev.cyanomelody.app\cyanomelody.db`）のSQLiteに保存する。

- library_folders：ライブラリフォルダ（id、絶対パス、登録日時）
- audio_files：音声ファイル（id、フォルダid、相対パス（区切りは`/`）、サイズ、更新日時、見つからない印、登録日時、ハッシュ値、ハッシュ値を計算できなかった理由、出典のid、ライセンスのid）
- tags：タグ（id、名前、作成日時）。名前は大文字・小文字を区別せず一意。
- file_tags：ファイルとタグの対応（ファイルid、タグid）
