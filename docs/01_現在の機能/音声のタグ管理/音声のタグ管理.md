# 音声のタグ管理

ライブラリにするフォルダを登録して音声ファイルを取り込み、ファイルにタグを付けて絞り込む。
画面全体の配置と共通の操作は`00_全体/画面の構成.md`を、一覧の再生は「再生」を参照。

## ライブラリ

- フォルダを複数登録できる。左の欄の「ライブラリ」の「＋」でフォルダを選ぶと、そのまま登録する。
- 既に登録したフォルダ自体・その中のフォルダ・その親フォルダは登録できない（同じファイルの二重取り込みを防ぐ）。
- 登録すると、そのフォルダをスキャンする。取り込んだファイルを整理できるよう、絞り込み・チェック・右の欄の表示をすべて外し、そのフォルダのファイルだけを表示する。
- 各行には、フォルダの名前（パスの最後。マウスを乗せるとパス全体）、ファイルの件数、見つからないファイルがあれば「⚠」とその件数、「⟳」（スキャン）、「✕」（登録解除）を出す。
- 行を押すと、そのフォルダのファイルだけに絞り込む。
- 「✕」で登録を解除できる（確認する）。解除すると、そのフォルダのファイルの情報と、付けたタグ・出典・ライセンスの設定がアプリから消える。実際のファイルは消えない。

## スキャン

- 「⟳」を押したときと、フォルダを登録したときに行う。アプリの起動時には行わない。
- 登録したフォルダの中を、サブフォルダも含めて調べる。シンボリックリンクはたどらない。
- 対象は拡張子がmp3・wav・flac・ogg・m4aのファイル（大文字・小文字は区別しない）。
- ファイルは「登録したフォルダ」と「そのフォルダからの相対パス」で識別する。
  - 新しく見つかったファイルを追加する。
  - 以前あったのに見つからなくなったファイルには、見つからない印を付ける。付けたタグなどは残す。
  - 印が付いたファイルが同じ場所に戻ってきたら、印を外す。
  - サイズか更新日時が変わったファイルは、ハッシュ値を計算し直す（「ハッシュ値を使った機能」を参照）。
- 登録したフォルダ自体が見つからないとき（外付けドライブを外しているときなど）は、エラーを表示する。中のファイルに印は付けない。
- 結果として、見つかった件数・追加した件数・見つからなくなった件数・戻った件数を表示する。
- 終わると、ハッシュ値の計算を裏で始める。

## ファイルの一覧

- 中央に、ファイルを並べる。数万件でも見えている行だけを描画する。一覧の上には「ライブラリ」と出し、その行の右にファイル名の検索の欄と、並び順のプルダウンを置く。

### 並び順
- 並び順のプルダウン：「パス順」（最初はこれ。ライブラリフォルダ・相対パスの順）・「ファイル名順」（フォルダを除いた名前。大文字・小文字は区別しない）・「追加した順（新しい順）」「追加した順（古い順）」・「更新日時順（新しい順）」・「長さ順（短い順）」「長さ順（長い順）」（長さのないファイルは最後）。
- 同じ値どうしはパス順に並べる。
- 選んだ並び順はアプリを閉じても覚えておく。「すべての条件を外す」では戻さない。
- 「直近で再生したもの」で絞り込んでいる間は、新しく再生した順に並べ、プルダウンは選べない。「重複しているファイル」では、同じハッシュ値のファイルをまとめたうえで、その中を選んだ順に並べる。
- 一覧を再生するときの順番も、この並びになる。
- 各行に、再生ボタン、見つからない印（⚠）、ファイル名（パスの最後。マウスを乗せると相対パス）、付いているタグ（左の欄のタグの順。タグの色を付ける）、チェックボックス（「ファイルの一括操作」を参照）を出す。見つからないファイルは名前に取り消し線を引く。
- 行（チェックボックスと再生ボタン以外）を押すと、そのファイル1件を右の欄に出す。Ctrl・Shiftを押しながらでも同じ（複数選択はしない）。

## 絞り込み

条件はすべてANDで組み合わせる（同じ欄の出典どうし・ライセンスどうしだけはOR）。
- ファイル名の検索：ファイルの一覧の見出し（「ライブラリ」）の行の右端の欄。ファイル名（相対パス）の部分一致で、大文字・小文字は区別しない。入力の途中は少し待ってから絞り込む。文字があるときは欄の中の右端に「×」を出し、押すと文字を消す。
- ライブラリ：そのフォルダのファイル。
- タグ：そのタグか、その子孫のタグが付いたファイル。複数選ぶと、選んだタグごとの条件をすべて満たすファイル。
- 「（タグなし）」：タグが1つもないファイル。タグの選択とは同時に選べない（どちらかを選ぶと、もう一方は外れる）。
- 出典・ライセンス（「出典とライセンスの管理」を参照）。
- 「その他」の欄
  - ⧉ 重複しているファイル（「ハッシュ値を使った機能」を参照）
  - 🕘 直近で再生したもの（「再生」を参照）。これで絞り込んでいる間は、新しく再生した順に並べる。
  - ⚠ リンク切れしているもの：見つからない印が付いたファイル
  - ⏱ 長さ：長さの入力欄（最初は「00:00:00」）と「以上」「以下」のボタン。押すと、入れた長さ以上・以下のファイルに絞り込む条件を加える（下の「長さ」）
  - 📅 リリース年：年の入力欄（最初は空）と「以上」「以下」のボタン。押すと、入れた年以上・以下（その年を含む）のファイルに絞り込む条件を加える（下の「リリース年」）
- 同じ音声のファイル（「ハッシュ値を使った機能」を参照）
- チェックしたファイルだけ表示（「ファイルの一括操作」を参照）

### 条件のチップ
- 選んでいる条件（ファイル名の検索の文字を除く）は、左の欄の検索の欄の下にチップで並べる。種類の記号（📁フォルダ・🏷タグ・🔗出典・⚖ライセンス・⧉重複・🕘直近で再生・⚠リンク切れ・⏱長さ・📅リリース年・🔊同じ音声）、名前、「✕」を出し、押すとその条件だけを外す。条件がないときは出さない。
- チップが2つ以上あるときは、最後に名前のない「✕」だけのチップを出す。押すと、絞り込みの条件（ファイル名の検索の文字を含む）をすべて外す。チェックと右の欄の表示はそのまま。

### 長さ
- 入力欄には「時:分:秒」「分:秒」「秒」の形で入れる（全角の数字・コロンでもよい。分・秒は60以上でもよい）。入力欄を押すと中の文字をすべて選ぶ。
- 形が正しくないとき（入力欄の枠を赤くする）や0秒のときは、「以上」「以下」を押せない。押した後も入力欄の値は残る。
- 「以上」「以下」の条件は、それぞれ1つまで。押し直すと置き換わる。両方を加えると、その間の長さのファイルになる。
- チップには「⏱ 1:30以上」「⏱ 1:00:00以下」のように出す。「その他」の見出しの選んでいる数には、長さの条件の数も入れる。
- 長さを調べていないファイルや、長さのない（読めない）ファイルは、長さの条件があるときは出さない。
- 長さは、ハッシュ値の計算と一緒に裏で調べる（「ハッシュ値を使った機能」を参照）。音声ファイルの情報（全体のサンプル数）から求め、情報にないとき（一部のMP3など）は、音声データを最後まで（デコードせずに）たどって求める。

### リリース年
- 入力欄には4桁の年（1000〜2999。全角の数字でもよい）を入れる。入力欄を押すと中の文字をすべて選ぶ。
- 空のときや、4桁の年でないとき（空でなければ入力欄の枠を赤くする）は、「以上」「以下」を押せない。押した後も入力欄の値は残る。
- 「以上」「以下」は、その年を含む。それぞれ1つまで。押し直すと置き換わる。両方を加えると、その間の年のファイルになる（同じ年なら、その年だけ）。
- チップには「📅 2010年以上」「📅 2019年以下」のように出す。「その他」の見出しの選んでいる数には、リリース年の条件の数も入れる。
- 年を調べていないファイルや、年のないファイルは、リリース年の条件があるときは出さない。
- リリース年は、長さと同じく、ハッシュ値の計算と一緒に裏で調べる。ファイルの中の情報の日付（MP3 の TYER・TDRC、Vorbis コメントの DATE・YEAR、WAV の INFO の ICRD など）→ リリース日（TDRL）→ 元のリリース日（TDOR・TORY）の順に、最初に年が読めたもの。値の先頭の4桁の数字（「2006」「2026-04-14」「20160219」など）を年とする（1000〜2999 のときだけ）。

### 選んだときの件数とグレーアウト
- 左の欄の各項目（ライブラリを除く）には、その項目を選んだときの件数を出す。
  - タグ：いまの条件（「（タグなし）」を除く）に合うファイルのうち、そのタグか子孫のタグが付いたものの数
  - 出典・ライセンス：同じ欄の条件を除いた、ほかのすべての条件に合うファイルのうち、それが設定されたものの数
  - 「なし」の項目：同じ欄の条件を除いた、ほかのすべての条件に合うファイルのうち、それがないものの数
  - 「その他」の項目：いまの条件に合うファイルのうち、それに当たるものの数
  - 条件がないときは、そのタグなどが付いたファイルの総数になる。
- 件数が0の項目はグレーアウトし、押しても選べない。選んでいる項目は、0件でもグレーアウトせず、押して外せる。
- 件数は、条件を変えたときと、データが変わったとき（タグの付け外しなど）に、一覧と一緒に求め直す。

## 右の欄

一覧で押したファイル1件について、次の順に出す。見出し（「ファイルの詳細」など）は出さない。
1. タイトル：音声ファイルのタグ情報（MP3 の ID3、WAV の INFO、FLAC・OGG の Vorbis コメント、M4A の MP4 のメタデータ）のタイトル。右の欄に出すときにファイルから読む（保存しないので、一覧への表示や検索はしない）。タイトルがないとき・見つからないファイルでは、拡張子を除いたファイル名。
   - 文字コード：WAV の INFO のタイトルは、UTF-8 として正しければ UTF-8、そうでなく Shift_JIS として正しければ Shift_JIS として読む。MP3 の ID3 で文字コードが ISO-8859-1 の項目（ID3v1 を含む）は、0x80 以上の文字があれば元のバイト列を同じように判定し直す（Shift_JIS で書かれた日本語の曲名が多いため）。どちらでもなければ、WAV は UTF-8（読めない部分は「�」）、MP3 は ISO-8859-1 として読む。ほかの形式のタグは UTF-8。
2. パス：絶対パス。押すと、エクスプローラーでそのファイルを選んだ状態でフォルダを開く（見つからないファイルではリンクにしない）。
3. タグ：付けるタグの入力欄と、付いているタグ（下の「タグの付け外し」）
4. プレイリスト：このファイルを直接入れているプレイリストと、加えるプレイリストのプルダウン（「プレイリスト」を参照）
5. 出典、ライセンス（「出典とライセンスの管理」を参照）
6. ハッシュ値と「同じ音声のファイルを探す」（「ハッシュ値を使った機能」を参照）
7. 見つからないファイルのときは、「⚠ 見つからないファイル」の操作（下の「見つからないファイル」）

- 「タグ」と「プレイリスト」は、見出しを押すとたたむ・開くができる。見出しには件数を出す。たたんだ状態はアプリを閉じても覚えておく。
- 右の欄に出しているファイルが絞り込みで一覧から消えたときは、右の欄の表示も消える。

## タグの付け外し

- タグの名前の決まりは`00_全体/画面の構成.md`を参照。階層・作成・削除・色などは「タグ自体の管理」を参照。
- 右の欄のタグの入力欄で、表示中のファイルにタグを付ける。既にあって、まだ付いていないタグ名が候補に出る。
  - 候補の一覧から選ぶと、すぐに付ける。打ち込んでいる途中で名前が一致しても、Enterを押すまでは付けない。
  - 名前を入れてEnterを押すと付ける。まだない名前なら、最上位の最後に新しいタグを作って付ける。
  - 空の名前や、既に付いているタグ名でEnterを押しても何もしない。
- 入力欄の下に、付いているタグを条件のチップと同じ形（「🏷 名前 ✕」）で、タグの色を付けて並べる。押すとそのタグを外す。
- 複数のファイルにまとめて付けるのは、チェックして左の欄のタグの行にドラッグする。まとめて外すのは、チェックの操作の行のタグのチップで行う（どちらも「ファイルの一括操作」を参照）。

## ファイルの情報からのタグ付け

ファイルの中の情報（タグ情報）のアーティスト・アルバム・ジャンル・作曲者を、タグとして付ける。

### 実行するところ
- ファイルの詳細（右の欄）のタグの欄の「ファイルの情報からタグを付ける」：そのファイル1件。見つからないファイルでは押せない。終わったら、付けたタグを下の行に出す（「アーティスト：米津玄師、ジャンル：J-POP を付けました」。付けるものがなければ「付けるタグはもう付いています」「ファイルの中に、タグにできる情報はありませんでした」、読めなければ「ファイルを読めませんでした」）。
- 一括操作の欄のタグの欄の「ファイルの情報からタグを付ける」：対象のファイルすべて（「ファイルの一括操作」を参照）。裏で行い、下の行に進み具合（「ファイルの情報からタグを付けています 120/5334」）と「中止」を出す。終わると結果（読んだファイル、タグを付けたファイル、作ったタグ、情報がなかったファイル、読めなかったファイル（見つからないファイルを含む）の数）を出し、データを読み直す。中止したときは、それまでに付けたタグは残す。同時に2つは行えない。
- どちらも、押すと確認のダイアログを出す：対象（「このファイル」か「N件のファイル」）、「以下の値は無視する」のチェックボックスと無視する値の一覧、「以下の文字で区切る（アーティスト・作曲者）」のチェックボックスと区切り文字の一覧、「やめる」（Esc でも）・「タグを付ける」。チェックボックスは、開くたびに ON から始める。一覧を編集している間は「タグを付ける」を押せない。

### 無視する値の一覧
- チェックボックスの下に、1行に1つずつ薄い文字で出す（チェックを外すと、さらに薄くする）。初期値は Unknown / アーティスト情報なし / Other。
- 各行の「✎」でその行が入力欄になり、Enter か入力欄の外を押すと決まり、Esc でやめる（ダイアログは閉じない）。「−」ですぐに消す。一覧の最後の「＋」で空の入力欄の行を出し、Enter で加える。
- 空の値・一覧にもうある値（大文字・小文字は区別しない）は入れられない（下にそのことを出し、入力を続ける）。
- 変えるとすぐに保存し、次に開いたときも同じ一覧を出す（データベースの設定。データのエクスポート・インポートの「出典・ライセンスと設定」にも含める）。
- チェックボックスが ON のときは、項目の値が一覧の値と同じ（大文字・小文字は区別しない、前後の空白は除く）なら、その値は使わない。

### 区切り文字の一覧
- 「以下の文字で区切る」のチェックボックスの下に、無視する値の一覧と同じ形で出し、同じ操作（✎・−・＋）で編集する。初期値は `,` `/` `／` `feat.` `with` `&`（`・` はカタカナの外国の名前を分けてしまうので入れない）。
- 変えるとすぐに保存し、次に開いたときも同じ一覧を出す（データベースの設定。データのエクスポート・インポートの「出典・ライセンスと設定」にも含める）。
- チェックボックスが ON のときは、アーティストと作曲者の値を、一覧のどの区切り文字でも分け、分けた値ごとにタグを付ける（アルバム名・ジャンルは分けない）。
  - 大文字・小文字は区別しない（「Feat.」「WITH」も区切る）。
  - 英字で始まる・終わる区切り文字（`feat.`・`with` など）は、前後が英数字でないとき（単語として）だけ区切る（「Smith」「Withered」の with では区切らない）。
  - 分けた値は前後の空白を除き、空のもの・同じ値（大文字・小文字の違いを含む）は1つにする。無視する値かどうかは、分けた値ごとに確かめる。

### 読む項目
| 項目 | 読むもの |
|---|---|
| アーティスト | アーティスト（MP3 の TPE1、Vorbis コメントの ARTIST、WAV の INFO の IART など）。空なら、アルバムアーティスト（TPE2 など） |
| アルバム | アルバム名（TALB、ALBUM、IPRD など） |
| ジャンル | ジャンル（TCON、GENRE、IGNR など）。ID3 の番号の書き方（「(17)」「17」）はジャンル名（Rock など）にし、「(13)Pop」のように名前が続けばその名前 |
| 作曲者 | 作曲者（TCOM、COMPOSER など。WAV の INFO にはない） |

- 文字コードは曲名と同じく読み直す（MP3 の ISO-8859-1 の項目、WAV の INFO は UTF-8 → Shift_JIS の順に判定する）。
- 形式の外側のタグ（MP3 の先頭の ID3v2 など）を先に読み、同じ項目が両方にあれば外側の値を使う。値が NUL で区切られて複数あるとき（ID3v2.4）は最初の値。前後の空白を除き、空の値は使わない。

### 付けるタグ
- 項目ごとに、項目の名前の親のタグ（「アーティスト」「アルバム」「ジャンル」「作曲者」）の下のタグを付ける。親のタグがなければ、最上位の最後に作る（同じ名前のタグがどこかにあれば、それを親として使う）。
- 値と同じ名前のタグ（大文字・小文字の違いを含む）が既にあれば、どの親の下にあっても、そのタグを付ける。なければ、項目の親のタグの子の最後に作って付ける（新しく作るタグの既定値を使う）。タグの名前に使えない値は使わない。
- 表記ゆれ（空白の違い、「A/B」のような複数の名前など）は考えない（値をそのまま名前にする）。
- タグは付けるだけで外さない。何度行っても、付くタグは同じ。

## 見つからないファイル

- 右の欄に出したファイルが見つからないファイル（リンク切れ）のとき、「⚠ 見つからないファイル」の操作として「ひも付け直す」「ファイルを紐づける」「指定フォルダから自動で探す」「ライブラリから外す」を出す。
- ひも付け直しの3つは「ハッシュ値を使った機能」を参照。
- 「ライブラリから外す」：確認してから、ファイルの情報と、付けたタグ・出典・ライセンスの設定を消す。

## データ

アプリのデータ領域（`%APPDATA%\dev.cyanomelody.app\cyanomelody.db`）のSQLiteに保存する。

- library_folders：ライブラリフォルダ（id、絶対パス、登録日時）
- audio_files：音声ファイル（id、フォルダid、相対パス（区切りは`/`）、サイズ、更新日時、見つからない印、登録日時、ハッシュ値、ハッシュ値を計算できなかった理由、出典のid、ライセンスのid、長さ（duration、秒。読めなければ NULL）、長さを調べたか（duration_done）、リリース年（release_year。読めなければ NULL）、リリース年を調べたか（release_year_done））
- tags：タグ（id、名前、作成日時）
- file_tags：ファイルとタグの対応（ファイルid、タグid）
