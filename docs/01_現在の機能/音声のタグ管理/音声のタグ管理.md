# 音声のタグ管理

ライブラリにするフォルダを登録して音声ファイルを取り込み、ファイルにタグを付けて絞り込む。

## 画面の構成

- 考え方：左の欄で絞り込み、その結果の一覧が中央に出る。絞り込みの操作は左の欄に、一覧そのものとチェックの操作は中央に置く。
- 左：一番上に絞り込みの操作（検索など）。その下に、ライブラリ（登録したフォルダ）の一覧、タグ、プレイリスト（「プレイリスト」を参照）、出典、ライセンス。タグ・出典・ライセンスは絞り込みに使う
- 中央：絞り込んだファイルの一覧と、件数・チェックの操作。プレイリストを開いているときは、その詳細画面（「プレイリスト」を参照）
- 中央の上：チェックしたファイルの一括操作（チェックしているときだけ。「ファイルの一括操作」を参照）
- 右：一覧でクリックしたファイル1件の詳細と、タグの付け外し、出典・ライセンスの設定（「出典とライセンスの管理」を参照）、見つからないファイルの扱い。プレイリストの詳細画面では、押した項目の詳細
- 下：プレイリストの再生の欄（左・中央・右の欄をまたぐ。何も再生していないときも出す。「プレイリスト」を参照）と、その下に処理の結果やエラーの表示

### 欄の幅
- 左・中央・右の欄の境界をドラッグすると、左と右の欄の幅を変えられる。中央の欄は残りの幅を使う。
- 境界は、マウスを乗せると色が変わり、カーソルが左右の矢印になる。
- 左・右の欄は180px、中央の欄は320pxより狭くならない。ウィンドウを狭くしたときは、左・右の欄が180pxまで縮んでから中央の欄が縮む。
- 変えた幅は、アプリを閉じても覚えておく。

### 左の欄
- 一番上に、絞り込みの操作を置く。左の欄をスクロールしても、この部分は一番上に残る（下の欄だけがスクロールする）。
  - 1行目：「検索」の入力欄
  - その下：選んでいる絞り込みの条件のチップ
- その下に、「ライブラリ」「タグ」「プレイリスト」「出典」「ライセンス」「その他」の6つの欄を、この順に同じ階層に並べる。
- 見出しを押すと、その欄をたたむ・開くができる。最初はすべて開いている。たたんだ状態はアプリを閉じても覚えておく。
- 絞り込みの条件を選んでいる欄（ライブラリ・タグ・出典・ライセンス・その他）は、見出しに選んでいる数を出す（たたんでいても分かる）。
- 見出しの右のボタン（ライブラリ・タグ・プレイリスト・出典・ライセンスの「＋」など）は、たたんでいても押せる。「＋」は枠を付けず、記号だけを出す。
  - タグ・プレイリストの「＋」をたたんでいるときに押すと、欄を開いてから名前の入力欄を出す。

### 選んだときの件数とグレーアウト
- 左の欄の各項目（タグ、出典、ライセンスと、「（タグなし）」などの「なし」）には、その項目を選んだときの件数を出す。
  - タグ：いまの絞り込みの条件（「（タグなし）」を除く）に合うファイルのうち、そのタグか子孫のタグが付いたものの数（タグどうしはANDのため）
  - 出典・ライセンス：同じ欄の条件を除いた、ほかのすべての条件に合うファイルのうち、それが設定されたものの数（同じ欄どうしはORのため）
  - 「なし」の項目：同じ欄の条件を除いた、ほかのすべての条件に合うファイルのうち、タグ（出典、ライセンス）がないものの数
  - 「ほかの条件」には、ファイル名、見つからないファイルだけ、重複しているファイルだけ、同じ音声、チェックしたファイルだけ表示を含む。
  - 絞り込みの条件がないときは、そのタグなどが付いたファイルの総数になる。
- 件数が0の項目はグレーアウトし、押しても選べない。条件がないときも、0件の項目（どのファイルにも付いていないタグなど）はグレーアウトする。
- 選んでいる項目は、件数が0でもグレーアウトせず、押して選択を外せる。
- 見出しのボタン、開く・たたむの印、行の「✎」「🗑」、タグの並べ替えの取っ手はグレーアウトしない。
- 件数は、絞り込みの条件を変えたときと、データが変わったとき（タグの付け外しなど）に、一覧と一緒に求め直す。ファイル名の入力中は、一覧と同じく少し待ってから求め直す。
- 件数は、SQLでタグ以外の条件に合うファイルを取り出し、タグの条件と数えるのはメモリの上で行う（3万ファイル・300タグで60ms以下）。

## ライブラリ

- フォルダを複数登録できる。見出しの「＋」（フォルダを追加）を押すとフォルダを選ぶダイアログを開き、選ぶとそのまま登録する（キャンセルしたときは何もしない）。
- 既に登録したフォルダ自体・その中のフォルダ・その親フォルダは登録できない（同じファイルの二重取り込みを防ぐ）。
- 登録すると、そのフォルダをスキャンする。取り込んだファイルを整理できるよう、絞り込み・チェック・右の欄の表示をすべて外し、そのフォルダのファイルだけを表示する。
- 「✕」（登録解除）で登録を解除できる。解除の前に確認し、解除するとそのフォルダのファイルの情報と、付けたタグ・出典・ライセンスの設定がアプリから消える。実際のファイルは消えない。
- フォルダごとに、フォルダの名前（パスの最後。マウスを乗せるとパス全体）、ファイルの件数、見つからないファイルがあれば「⚠」とその件数、「⟳」（スキャン）、「✕」（登録解除）を1行に出す。
- フォルダの行を押すと、そのフォルダのファイルだけに絞り込む（ほかの条件とAND）。もう一度押すと外れる。

## スキャン

- フォルダごとの「⟳」（スキャン）を押したときと、フォルダを登録したときに行う。アプリの起動時には行わない。
- 登録したフォルダの中を、サブフォルダも含めて調べる。シンボリックリンクはたどらない。
- 対象は拡張子がmp3・wav・flac・ogg・m4aのファイル（大文字・小文字は区別しない）。
- ファイルは「登録したフォルダ」と「そのフォルダからの相対パス」で識別する。
  - 新しく見つかったファイルを追加する。
  - 以前あったのに見つからなくなったファイルには、見つからない印を付ける。付けたタグは残す。
  - 印が付いたファイルが同じ場所に戻ってきたら、印を外す。
  - ファイルのサイズと更新日時を記録する。サイズか更新日時が変わったファイルは、ハッシュ値を計算し直す（「ハッシュ値を使った機能」を参照）。
- 登録したフォルダ自体が見つからないとき（外付けドライブを外しているときなど）は、エラーを表示する。中のファイルに印は付けない。
- 結果として、見つかった件数・追加した件数・見つからなくなった件数・戻った件数を表示する。
- スキャンが終わると、ハッシュ値の計算を裏で始める（「ハッシュ値を使った機能」を参照）。

## ファイルの一覧と絞り込み

- ファイルを、フォルダ・相対パスの順に一覧表示する。数万件でも見えている行だけを描画する。
- 各行に、再生ボタン、見つからない印（⚠）、ファイル名（パスの最後。マウスを乗せると相対パス）、付いているタグ（タグの一覧と同じ順）を表示する。見つからないファイルは名前に取り消し線を引く。
- 以下の条件で絞り込める。条件は組み合わせられる。
  - 左の欄の一番上の「検索」の欄：ファイル名（相対パス）の部分一致。大文字・小文字は区別しない。
  - タグ。そのタグか、その子孫のタグが付いたファイルに絞り込む。複数のタグを選ぶと、選んだタグごとの条件をすべて満たすファイルに絞り込む（AND）。
  - タグなし。「（タグなし）」を選ぶと、タグの選択は解除される（逆も同じ）。
  - 「その他」の欄（項目どうしと、ほかの条件とはAND。各項目に選んだときの件数を出し、0件ならグレーアウトする）
    - ⧉ 重複しているファイル（「ハッシュ値を使った機能」を参照）
    - 🕘 直近で再生したもの：最後に再生した100件。試聴（一覧の行の再生ボタン）と、プレイリストの再生（1曲ごと）のどちらも数える。同じファイルは1件にまとめる。アプリを閉じても覚えておく。これで絞り込んでいる間は、新しく再生した順に並べる。
    - ⚠ リンク切れしているもの：見つからない印が付いたファイル（「見つからないファイルの扱い」を参照）
  - 同じ音声のファイル（「ハッシュ値を使った機能」を参照）
  - 出典、ライセンス（「出典とライセンスの管理」を参照）
- 選んでいる絞り込みの条件（フォルダ、タグ、タグなし、出典、ライセンス、出典なし、ライセンスなし、重複、直近で再生、リンク切れ、同じ音声）は、左の欄の一番上（検索の下）にチップで並べる。種類の記号（📁フォルダ・🏷タグ・🔗出典・⚖ライセンス・⧉重複・🕘直近で再生・⚠リンク切れ・🔊同じ音声）と名前と「✕」を出し、押すとその条件だけを外す。左の欄の長い一覧の中から選んだ項目を探さなくても、何で絞り込んでいるかがわかり、1つずつ外せる。条件がないときは出さない。
- 条件のチップが2つ以上あるときは、並びの最後に名前のない「✕」だけのチップを出す。押すと、絞り込みの条件（検索の文字を含む）をすべて外す。チェックと右の欄の表示はそのまま。
- 絞り込みの条件だけを外すときは、選んでいる項目をもう一度押す。
- ウィンドウの一番下の行の右側に、一覧の件数と、チェックしている件数を表示する（「ファイルの一括操作」を参照）。
- 一覧の見出しの行には、右端の「表示中のファイルをすべてチェック」のチェックボックスだけを置く（「ファイル」などの文字は出さない）。

## 確認のダイアログ

- 登録解除や削除など、元に戻せない操作の前には、OSのダイアログで確認する。「キャンセル」を選ぶと何もしない。

## ファイルのクリック（詳細の表示）

- 行（チェックボックスと再生ボタン以外の部分）をクリックすると、そのファイル1件を右の欄に表示する。Ctrl・Shiftを押しながらのクリックも同じ（複数選択はしない）。
- プレイリストの詳細画面で項目の行を押したときも、右の欄に出す（「プレイリスト」を参照）。
- 右の欄には、そのファイル1件について、次の順に表示し、操作する。見出しの「ファイルの詳細」などは出さない。何もクリックしていないときは、右の欄は空。
  1. タイトル：音声ファイルのタグ情報（MP3 の ID3、WAV の INFO、FLAC・OGG の Vorbis コメント、M4A の MP4 のメタデータ）のタイトル。右の欄に出すときにファイルから読む（データベースには保存しないため、一覧への表示や検索はしない）。タイトルがないファイルや、見つからないファイルでは、拡張子を除いたファイル名を出す。
  2. パス：ファイルの絶対パス。リンクで出し、押すとエクスプローラーでそのフォルダを開く（そのファイルを選んだ状態で）。見つからないファイルのときはリンクにしない。
  3. タグ：付けるタグの入力欄と、付いているタグの一覧（「タグ」を参照）
  4. プレイリスト：このファイルを直接入れているプレイリスト（条件と同じ形のチップ。名前を押すと開き、「✕」でそのプレイリストから外す）と、加えるプレイリストを選ぶプルダウン（選ぶとすぐ加え、プルダウンは「（プレイリストを選ぶ）」に戻る）
  5. 出典、ライセンス（「出典とライセンスの管理」を参照）
  6. ハッシュ値と「同じ音声のファイルを探す」（「ハッシュ値を使った機能」を参照）
  7. 見つからないファイルのときは、「⚠ 見つからないファイル」の操作（「見つからないファイルの扱い」を参照）
- 「タグ」と「プレイリスト」は、行の数が増えるため、見出しを押すとたたむ・開くができる。見出しには件数（付いているタグ、入っているプレイリストの数）を出す（たたんでいても分かる）。たたんだ状態はアプリを閉じても覚えておく。
- 右の欄に表示しているファイルが絞り込みで一覧から消えたときは、右の欄の表示も消える。
- 複数のファイルをまとめて操作するときは、行の右端のチェックボックスでチェックする（「ファイルの一括操作」を参照）。

## タグ

- タグは名前だけを持つ。名前の大文字・小文字は区別しない。前後の空白は取り除く。空の名前や制御文字を含む名前は付けられない。
- 右の欄の「タグ」で、表示中のファイルにタグを付けられる。入力欄には、既にあって、まだ付いていないタグ名が候補に出る。
  - 候補の一覧から選ぶと、すぐに付ける（Enterは要らない）。打ち込んでいる途中で名前が一致しても、Enterを押すまでは付けない。
  - 名前を入れてEnterを押すと付ける。既にあるタグ名（大文字・小文字は区別しない）ならそのタグを、まだない名前なら最上位（親なし）に新しいタグを作って付ける。
  - 空の名前や、既に付いているタグ名でEnterを押しても何もしない。
- 入力欄の下に、表示中のファイルに付いているタグを、左の欄の絞り込みの条件と同じ形のチップ（「🏷 名前 ✕」）で並べる。押すとそのタグを外す。
- 複数のファイルにタグを付けるのは、チェックしてタグの行にドラッグする（下を参照）。まとめて外す操作はない。
- 左のタグの一覧は階層で表示し、各タグを選んだときの件数（「選んだときの件数とグレーアウト」を参照）を表示する（並べ替えなどは「タグ自体の管理」を参照）。どのファイルにも付いていないタグも残る（削除は「タグ自体の管理」で行う）。
- ファイルの一覧の行を、左の欄のタグの行にドラッグして落とすと、そのタグを付ける。
  - チェックした行をつかんだときは、チェックしたファイルすべてに付ける。既に付いているファイルはそのまま。
  - ドラッグ中は、つかんだ件数（「♪ 3」）をポインタの横に出し、落とす先のタグの行を枠で示す。「（タグなし）」の行には落とせない。
  - プレイリストへのドラッグと同じく、確認はしない（すぐ外せるため）。付けたら下の行に「n件にタグ「名前」を付けました」と出す。

## 試聴（一覧の再生）

- 一覧の行の再生ボタンを押すと、表示中の一覧（絞り込んだ結果の並び）をプレイリストのように扱い、その行から順に再生する。鳴らしている行の再生ボタンを押すと止まる。
  - 再生の欄（「プレイリスト」の「再生」を参照）で、前へ・次へ・一時停止・停止・シークバーを操作できる。再生の欄の名前は「ファイルの一覧」で、何曲目か（「3/12」）を出す。
  - 再生を始めたときの一覧で再生する（途中で絞り込みを変えても、再生の順番は変わらない）。見つからないファイルは除く。一覧の最後まで再生したら止まる。
  - プレイリストの再生中に押すと、プレイリストの再生をやめて一覧の再生になる。
- プレイリストを開いておらず、何も再生していないときは、再生の欄の「▶」「🔀」「🎲」で、表示中の一覧を順に・シャッフルで・1曲だけ再生する。
- 鳴らしている行の下端に、進み具合を細いバーで出す。
- キーボード（一覧にフォーカスがあるとき）
  - ↑・↓：右の欄に表示するファイルを、上・下の行に移す（画面の外なら見える所までスクロールする）。鳴らしているなら、移った先のファイルから続けて再生する（聞き比べ）。
  - スペース：右の欄に表示しているファイルから、再生を始める・止める（ボタンやチェックボックスの上では、そちらの操作になる）。
- 見つからないファイルは再生できない（↑・↓で移っても再生は始めない）。
- 再生できなかったときはエラーを表示する。
- エフェクトの管理画面の試聴は、そのファイル1件だけを鳴らす（再生の欄には「試聴」と出す）。

## 見つからないファイルの扱い

- 右の欄に表示したファイルが見つからないファイル（リンク切れ）のとき、「⚠ 見つからないファイル」の操作として「ひも付け直す」「ライブラリから外す」「ファイルを紐づける」「指定フォルダから自動で探す」が出る（ひも付けは「ハッシュ値を使った機能」を参照）。
- 外す前に確認し、外すとファイルの情報と、付けたタグ・出典・ライセンスの設定が消える。見つからない印が付いていないファイルは外れない。
- 移動したファイルへのひも付け直し（同じ音声を探す、ファイルを選ぶ、フォルダから探す）は「ハッシュ値を使った機能」を参照。

## データ

アプリのデータ領域（`%APPDATA%\dev.cyanomelody.app\cyanomelody.db`）のSQLiteに保存する。

- library_folders：ライブラリフォルダ（id、絶対パス、登録日時）
- recent_plays：直近で再生したファイル（ファイルid、再生した順の通し番号）。100件を超えたら古いものから消す。ファイルを消すと一緒に消える
- audio_files：音声ファイル（id、フォルダid、相対パス（区切りは`/`）、サイズ、更新日時、見つからない印、登録日時、ハッシュ値、ハッシュ値を計算できなかった理由、出典のid、ライセンスのid）
- tags：タグ（id、名前、作成日時）。名前は大文字・小文字を区別せず一意。
- file_tags：ファイルとタグの対応（ファイルid、タグid）
