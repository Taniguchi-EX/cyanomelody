# プレイリストの出力

プレイリストの曲（編集画面でチェックした項目の曲。チェックがなければすべての項目の曲）を、エフェクトをかけた状態のファイルとして、フォルダに書き出す。プレイリストの階層構造を、フォルダの構造にする。

## 書き出す曲

- 書き出すときにプレイリストを展開し直し（`再生の順番の決め方.md`）、チェックした項目（プレイリストの直下の項目）から来た曲を、項目の並びの順に書き出す。チェックがなければすべての項目。
  - 🎲・🔀の項目は、書き出すたびに抽選し直す。中央の一覧の抽選した並びは変えない（選んでいるかどうか、絞り込みにもよらない）。
- 同じ曲が2回出ていれば、2回書き出す。見つからない曲は書き出せないので、「書き出せなかった」に数える。

## フォルダの構造

- 選んだフォルダの中に、プレイリストの名前のフォルダを作り、その中に書き出す。同じ名前のフォルダがあるときは、名前の後ろに「 (2)」などを付ける（上書きしない）。
- 各曲を、その曲が通った項目（選んだプレイリストから、どの項目を通って来たか）に沿って、次のように置く。
  - ファイルの項目・タグの組み合わせの項目から来た曲：そのフォルダに置く
  - プレイリストの項目（子・参照とも）を通った曲：そのフォルダの中に、そのプレイリストのフォルダを作って、その中へ
    - 「順に再生」の項目：中の階層もそのままフォルダにする
    - シャッフル・ランダムセレクトの項目：並べ替えや選び方が中の階層をまたぐので、中のフォルダは作らず、そのフォルダに並べる
- フォルダは、その中の最初の曲が出てくる位置に置く。1曲もないフォルダは作らない。
- ファイル名・フォルダ名の先頭に、そのフォルダの中での順番を3桁の数字で付ける（例：`001_激しめの雨.wav`、`002_シーン1/`。1000件以上なら桁を増やす）。フォルダの中は、展開した順。
- 名前には、項目のプレイリスト上での名前（別名）があればそれを、なければファイル名（拡張子を除く）・プレイリスト名を使う。Windowsのファイル名に使えない文字（`\ / : * ? " < > |`と制御文字）は「_」に置き換え、末尾の空白と「.」を除く。長い名前は100文字で切る。

## 形式

- エフェクトのかかる曲：エフェクトをかけた音を、WAV（16bit、元の標本化周波数とチャンネル数）で書き出す。
- エフェクトのかからない曲：元のファイルをそのままコピーする（形式も変えない）。

## 操作

- プレイリストの編集画面の一番下の行に「書き出し：」「ファイル」「メタデータ」と、対象の説明（「チェックした2件の項目」か「すべての項目」が対象で、🎲・🔀の項目は書き出すときに抽選し直すこと）を出す。
- 「ファイル」：押すとすぐ、書き出し先のフォルダを選ぶダイアログを出し（一括操作の書き出しと同じ）、選ぶと書き出しを始める。ダイアログは、前に書き出しを始められたフォルダから開く（始められなかったフォルダは覚えない。開けないときは場所を決めずに開く）。
- 「メタデータ」：押すとすぐ保存先を選ぶダイアログを出し、選ぶと、対象の曲（同じ曲は1回）のメタデータを JSON に書き出す（「データのエクスポートとインポート」の「選んだファイルの書き出し」。保存先の名前の初期値はプレイリストの名前）。🎲・🔀の項目は、このときに抽選し直す。
- 書き出し先のフォルダがないときは、エラーを出して始めない。
- 書き出しは裏で行い、画面の下に進み具合（何件中何件）を出す。「中止」で止められる（途中まで書き出したファイルは残す）。
- 書き出しは同時に1つだけ。
- 終わったら、書き出した件数と、書き出せなかった件数（見つからない、読めないなど）、書き出したフォルダを出す。フォルダはリンクで、押すとエクスプローラーでそのフォルダを選んだ状態で見せる（友人に渡すときなどに、探さなくてよい）。
