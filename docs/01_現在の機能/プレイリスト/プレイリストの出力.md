# プレイリストの出力

プレイリストの中身を、エフェクトをかけた状態のファイルとして、フォルダに書き出す。プレイリストの階層構造を、そのままフォルダの構造にする。

## 書き出す曲

- プレイリスト全体を再生したときと同じように項目を展開する（`再生の順番の決め方.md`）。シャッフルはそのときに並べ替え、ランダムセレクトはそのときに1曲選ぶ。
- 見つからないファイルの項目は書き出せないので、「書き出せなかった」に数える。タグの組み合わせからは、再生と同じく見つからないファイルを除く。

## フォルダの構造

- 選んだフォルダの中に、プレイリストの名前のフォルダを作り、その中に書き出す。同じ名前のフォルダがあるときは、名前の後ろに「 (2)」などを付ける（上書きしない）。
- 項目ごとに、上から順に次のように書き出す。
  - ファイルの項目：そのフォルダにファイルを書き出す
  - タグの組み合わせの項目：対象のファイル（展開した結果）を、そのフォルダに書き出す
  - プレイリストの項目（子・参照とも）：そのフォルダの中に、そのプレイリストのフォルダを作る
    - 「順に再生」の項目：中の階層をそのままフォルダにして書き出す
    - シャッフル・ランダムセレクトの項目：並べ替えや選び方が中の階層をまたぐので、展開した曲をそのフォルダに並べる（中のフォルダは作らない）
- ファイル名・フォルダ名の先頭に、そのフォルダの中での順番を3桁の数字で付ける（例：`001_激しめの雨.wav`、`002_シーン1/`。1000件以上なら桁を増やす）。見つからないファイルの項目も番号を使うので、番号が飛ぶことがある。
- 名前には、項目の別名があれば別名を、なければファイル名（拡張子を除く）・プレイリスト名を使う。Windowsのファイル名に使えない文字（`\ / : * ? " < > |`と制御文字）は「_」に置き換え、末尾の空白と「.」を除く。長い名前は100文字で切る。

## 形式

- エフェクトのかかる曲：エフェクトをかけた音を、WAV（16bit、元の標本化周波数とチャンネル数）で書き出す。
- エフェクトのかからない曲：元のファイルをそのままコピーする（形式も変えない）。

## 操作

- プレイリストの編集画面の「書き出す」で、書き出し先の欄を出す。欄には、前に書き出しを始められたフォルダを入れておく（書き出し先がなくて始められなかったフォルダは覚えない）。フォルダのパスを入れるか「参照」で選び、「書き出しを始める」（またはEnter）で始める。
- 書き出し先のフォルダがないときは、エラーを出して始めない。
- 書き出しは裏で行い、画面の下に進み具合（何件中何件）を出す。「中止」で止められる（途中まで書き出したファイルは残す）。
- 書き出しは同時に1つだけ。
- 終わったら、書き出した件数と、書き出せなかった件数（見つからない、読めないなど）、書き出したフォルダを出す。フォルダはリンクで、押すとエクスプローラーでそのフォルダを選んだ状態で見せる（友人に渡すときなどに、探さなくてよい）。
