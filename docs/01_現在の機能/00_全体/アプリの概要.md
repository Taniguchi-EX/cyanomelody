# アプリの概要

## 目的

効果音などの音声素材を管理するアプリ。ローカルにある音声ファイルにタグを付けて管理する。
使うのは本人と、限られた友人数名。

## 動作環境

- 対応OS：Windows11。Android（10 以降）は対応の途中で、内部の処理（フォルダの登録・スキャン・ハッシュ値・タグ付け・再生）だけが動く（画面は狭い画面に合わせていないので、まだ配布しない）。
- 配布：GitHub の Releases で、Windows 向けのインストーラ（NSIS の `.exe`。自分のユーザーだけにインストールし、管理者の権限は要らない）を公開する。使い方は、リポジトリの README.md（利用者向け）に書く。
- 更新：起動したときに新しい版を探し、確かめてからアップデートする（`アップデート.md`）。
- ライセンス：MIT
- 規模：1端末あたり最大で数万ファイル
- 対応する形式：MP3、WAV、FLAC、OGG、M4A

## アーキテクチャ

- Tauri 2で作る。内部処理はRust、画面表示はReact。
- タグやハッシュ値などのメタデータは、アプリのデータ領域にSQLiteで保存する。
- ライブラリは端末ごとに独立して扱う。端末間での共有や同期はしない。

## 基本方針

### 元のファイルを変更しない
- タグ・出典・ライセンスはアプリのメタデータにだけ持つ。ファイル内のタグ情報（ID3など）には書き込まない。
- 音声を加工した結果は、別のファイルとして書き出す。

### ファイルの登録と追従
- ライブラリにするフォルダを登録し、スキャンしてファイルを取り込む。
- アプリの外でファイルが移動・名前変更・削除されても、自動では追いかけない。

### ハッシュ値
- ファイル内のタグ情報を除いた、音声データの部分だけを対象に計算する。
- そのため、ファイル名やファイル内のタグ情報を書き換えても、ハッシュ値は変わらない。

## 機能

各機能の詳細は、`01_現在の機能`の機能ごとのフォルダを参照する。

- 音声のタグ管理：ライブラリ（フォルダ）の登録とスキャン、ファイルの一覧と絞り込み、右の欄（ファイルの詳細）、ファイルへのタグの付け外し
- タグ自体の管理：タグの作成・名前変更・統合・削除
- ファイルの一括操作：ファイルのチェック（絞り込みを変えても残る）と、チェックしたファイルへの一括操作、左の欄へのドラッグ
- 再生：再生の欄、中央の一覧の再生（試聴）、プレイリストの再生、直近で再生したもの
- プレイリスト：ファイル・タグの組み合わせ・プレイリストをまとめて、再生方法（順に・シャッフル・ランダムセレクト）を選ぶ。左の欄で選ぶと抽選して中央の一覧になり（絞り込みの条件の1つ）、続けて再生する。中身は重ねて出す編集画面で直す
- プレイリストの出力：選んだプレイリストの中央の一覧の曲を、エフェクトをかけた状態で、階層をフォルダにして書き出す
- エフェクト：エフェクトセットを作り、プレイリストの項目に結び付けて、エフェクトをかけて再生する（元のファイルは変更しない）
- 出典とライセンスの管理：出典・ライセンスの登録と管理、ファイルへの設定、絞り込み
- ハッシュ値を使った機能：ハッシュ値の計算、重複しているファイルの絞り込み、同じ音声のファイルの検索、見つからないファイルのひも付け直し

画面全体の配置と、機能に共通する操作・名前の決まりは`画面の構成.md`を、開発の手順は`開発の手順.md`を参照する。
