# 設定画面

再生の欄の右端の歯車の絵で開く。メインの画面に重ねて出し、「閉じる」か Esc で閉じる。

## タブ
- 上にタブを並べ、押したタブの中身を出す：「一般」「表示」「データ」「バージョンとライセンス」。
- 最初は「一般」。次に開くときは、前に開いていたタブを出す（画面の設定として覚えておく）。

## 一般
- 再生：「戻す・進める秒数」（再生の欄の「戻す」「進める」で動かす秒数。1〜600秒、最初は10秒）。欄を離れたとき・Enter で、範囲に収めて保存する（画面の設定として覚えておく）。
- 新しく作るタグの既定値：子のタグの並び順（親の設定を引き継ぐ・ドラッグで決めた順・登録順・ファイル数順・ローマ字順）と昇順・降順、背景色・文字色（「色を付ける」のチェックと色。付けなければ「親の色を引き継ぐ」）。タグの詳細画面と同じ並び。見本のチップに、決めた色で「新しいタグ」と出す。
- 変えるとすぐに保存する（保存のボタンはない）。データベースに保存する（「タグ自体の管理」の「新しく作るタグの既定値」）。

## 表示
- 文字の大きさ：小・標準・大・特大（0.9・1・1.15・1.3倍）。画面全体の文字に効き、一覧の行の高さ・グリッドのタイルも合わせて大きくする。
- 文字のフォント：「標準」と、OS にインストールされているフォント（Windows 全体とユーザーごとのフォントのフォルダにあるもの。日本語の名前があるものは日本語の名前で、名前の順）。選んでいたフォントが見つからなくなっても、選び肢に残す。
- グリッドの横の数：3・4・5・6・7・8・10（最初は6）。中央の欄が狭くて入らないときは減らす。
- ファイル名の拡張子を省く：中央の一覧・再生の欄のファイル名から拡張子を省いて出す。
- 変えるとすぐに画面に効き、保存する（画面の設定として覚えておく。データのエクスポートの「画面の設定」に入る）。

## データ
データの入出力（`データのエクスポートとインポート.md`）。

## バージョンとライセンス
- アプリの名前と版（「v1.0.0」など）、アプリ自体のライセンス（MIT License）、GitHub のリポジトリへのリンク（押すとブラウザで開く）。
- 使っているライブラリの一覧（件数）：アプリに組み込んでいる Rust のライブラリ（Windows 向けのビルドで、通常の依存としてたどれるもの）と、画面の JavaScript のライブラリ（開発用を除く）。名前の順。
  - 各行：名前、版、ライセンスの種類（SPDX の表記）。押すと開き、配布元（押すとブラウザで開く）と、ライセンスの文章（ファイル名と中身）を出す。もう一度押すと閉じる。
  - ライセンスに MPL を含むものは、「このライブラリのソースコードは、上の配布元から入手できます（改変していません）。」と出す。
  - 「ライブラリ名で検索」の欄で、名前の部分一致で絞り込む（大文字・小文字は区別しない）。
- 一覧は、このタブを開いたときに読み込む（大きいため）。一覧の作り方は`開発の手順.md`の「ライセンスの一覧の作り方」。
