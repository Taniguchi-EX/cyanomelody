# 設定画面

再生の欄の右端の歯車（⚙）で開く。メインの画面に重ねて出し、「閉じる」か Esc で閉じる。

## タブ
- 上にタブを並べ、押したタブの中身を出す：「一般」「バージョンとライセンス」。
- 最初は「一般」。次に開くときは、前に開いていたタブを出す（画面の設定として覚えておく）。

## 一般
- 新しく作るタグの既定値：子のタグの並び順（親の設定を引き継ぐ・ドラッグで決めた順・登録順・ファイル数順・ローマ字順）と昇順・降順、背景色・文字色（「色を付ける」のチェックと色。付けなければ「親の色を引き継ぐ」）。タグの詳細画面と同じ並び。見本のチップに、決めた色で「新しいタグ」と出す。
- 変えるとすぐに保存する（保存のボタンはない）。データベースに保存する（「タグ自体の管理」の「新しく作るタグの既定値」）。

## バージョンとライセンス
- アプリの名前と版（「v1.0.0」など）、アプリ自体のライセンス（MIT License）、GitHub のリポジトリへのリンク（押すとブラウザで開く）。
- 使っているライブラリの一覧（件数）：アプリに組み込んでいる Rust のライブラリ（Windows 向けのビルドで、通常の依存としてたどれるもの）と、画面の JavaScript のライブラリ（開発用を除く）。名前の順。
  - 各行：名前、版、ライセンスの種類（SPDX の表記）。押すと開き、配布元（押すとブラウザで開く）と、ライセンスの文章（ファイル名と中身）を出す。もう一度押すと閉じる。
  - ライセンスに MPL を含むものは、「このライブラリのソースコードは、上の配布元から入手できます（改変していません）。」と出す。
  - 「ライブラリ名で検索」の欄で、名前の部分一致で絞り込む（大文字・小文字は区別しない）。
- 一覧は、このタブを開いたときに読み込む（大きいため）。

## ライセンスの一覧の作り方
- `app/scripts/licenses.mjs` が、ビルドの前（`npm run build`・`npm run dev`）と、`check.sh` の型チェックの前に、`app/src/generated/licenses.json`（Git の管理外）を作る。
- Rust：`cargo metadata`（Windows 向け）で、アプリから通常の依存をたどったライブラリ。JavaScript：`npm ls --omit=dev`。
- 各ライブラリのフォルダの LICENSE・COPYING・NOTICE・COPYRIGHT・UNLICENSE・AUTHORS などのファイルを読む。同じ文章は1つにまとめて持つ。
- ライセンスのファイルを入れずに配布されているライブラリ（symphonia など）は、ライセンスの種類の標準の文章（`app/scripts/license-templates/`。MPL-2.0・MIT・BSD-3-Clause）を使い、ファイル名の欄に「（標準の文章）」と付ける。MIT・BSD の著作権の行には、そのライブラリの作者（なければ「The <名前> authors」）を入れる。
