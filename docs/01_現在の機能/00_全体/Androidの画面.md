# Android の画面

Android（縦向きのスマートフォン）での画面の構成と操作。中身（絞り込みの欄・ファイルの詳細・プレイリストの編集など）は Windows と同じで、各機能の文書を参照する。ここには、狭い画面のための並べ方と、指での操作の違いだけを書く。Windows の画面は `画面の構成.md`。

## 画面の構成

- 上下2つのエリアに分ける。上下は、端末のステータスバーとナビゲーションバーの分を空ける（セーフエリア）。
  - 動的エリア：ファイルの一覧・絞り込み・ファイルの詳細・一括操作・プレイリストの編集のうち1つを出す。各画面の一番上に見出しの行（スクロールしても残す）を置き、画面の切り替えと「戻る」はここで行う。
  - 再生エリア（小）：画面の下に常に出す。進み具合の細い線、曲の名前と再生しているもの（「森の探索シーン 3/12」）、再生・一時停止と次へのボタン（図形の絵）。ボタンのない所を押すと、全画面の再生を開く。
- アプリを開いたときは、ファイルの一覧を出す。
- 処理の結果やエラーは、再生エリアの上に4秒出して消す（Windows の一番下の行の代わり）。
- 重ねて出す画面（タグの詳細・出典とライセンスの編集・エフェクトセットの管理・設定・確認）は、動的エリアいっぱいに広げて出す（再生エリアは隠さない）。

## 画面の切り替えと戻る

- 一覧と絞り込みの行き来は、見出しの行の右端の切り替えのボタンで行う（2つの画面で同じ位置）。
  - ファイルの一覧では漏斗の絵（押すと絞り込みへ）。選んでいる条件があれば、その数を添える。
  - 絞り込みでは一覧の絵（押すと一覧へ）。今の条件で一覧に出る件数を添える。
- 中に入った画面（ファイルの詳細・一括操作・プレイリストの編集）の見出しの行には「←」と画面の名前を出す。
- 端末の戻る操作（ジェスチャー・戻るボタン）と「←」は同じに動き、開いた順に1つずつ戻る。重ねて出す画面・全画面の再生・チェックも、戻る操作で閉じる（チェックはすべて外れる）。ファイルの一覧で戻る操作をすると、アプリを閉じる。
- 開き方
  - ファイルの詳細：一覧の行を押す。
  - 一括操作：チェックしているときの、チェックの操作の行の「一括操作」。
  - プレイリストの編集：絞り込みのプレイリストの行の「⋮」→「編集」、一覧の行の来た項目・fx のアイコン、ファイルの詳細・一括操作のプレイリストのチップの名前、全画面の再生の曲名（選んでいないプレイリストの曲のとき）。
- 絞り込みでプレイリストを押すと、選んで（抽選して）一覧へ移る。タグなどほかの条件を押したときは、絞り込みの画面のまま（続けて条件を足せる）。

## 各画面

- ファイルの一覧
  - 見出しの行：見出し（ライブラリかプレイリストの名前）、「🔍」（押すと見出しの行がファイル名の検索の欄になる。「✕」で検索をやめて文字を消す）、切り替えのボタン。
  - その下に、並び順のプルダウン、件数、見せ方（一覧・グリッド）の切り替え（見出しの行のボタンと同じ大きさ）。
  - 行は1段で、再生ボタン、（プレイリストを選んでいるとき）来た項目と fx のアイコン、見つからない印、名前を出す。タグとチェックボックスは出さない（タグはファイルの詳細で見る）。行の高さは指で押しやすい高さにする。
  - グリッドは、横に最大3つ（設定の「グリッドの横の数」が3より小さければ、その数）。
  - 行を長押しすると、チェックを始める（押した行をチェックする）。チェックしている間は、見出しの行が「✕」・「N件をチェック」・「全て」（表示中をすべてチェック）になり、行の再生ボタンの代わりにチェックボックスを出し、行を押すとチェックを付け外しする。下にチェックの操作の行（Windows と同じ）を出す。チェックが0件になるか、「✕」・戻る操作で、チェックを終える。
- 絞り込み：見出しの行に「絞り込み」、設定を開く歯車、切り替えのボタン。中身は Windows の左の欄と同じ（検索の欄、各欄、条件のチップ）。行の「✎」「🗑」は、行の右端の「⋮」の選び肢（「編集」などと「削除」）にまとめる。
- ファイルの詳細：見出しの行は「←」と「ファイルの詳細」だけ（再生は一覧の行の再生ボタンで行う）。中身は Windows の右の欄と同じ。ファイルの場所は相対パスで出し、押せない。
- 一括操作：見出しは「一括操作（N件）」。中身は Windows の一括操作の欄と同じ。
- プレイリストの編集：見出しの行に「←」・名前・「✎」、その下の行に「▶ 再生」。項目の行は2段にする（1段目：種類の記号・内容・「⋮」・チェックボックス、2段目：再生方法と件数・fx のプルダウン）。「⋮」の選び肢は、プレイリスト上での名前を付ける・外す。
- 全画面の再生：左上に「↓」（閉じる）。ジャケット（ないときは出さない）と Windows の再生の欄の中身（設定の歯車を除く）を縦に並べ、画面の下に詰める（指の届きやすい位置）。ボタンは大きくする。一番上までスクロールしているときに、ボタン・つまみ・プルダウンのない所を下へスワイプしても閉じる。
- 設定：タブの名前は折り返さず、入らない分は横にスクロールする。「データ」のタブには「Windows からコピー」だけを出す（`データのエクスポートとインポート.md` の「Windows からのコピー」）。「表示」のタブに文字のフォントを出さない。

## 指での操作

- 並べ替え（絞り込みのタグ・プレイリスト・出典・ライセンスの行、プレイリストの編集の項目）は、行を長押し（0.35秒動かさない）してからドラッグする。長押しの前に指を動かすと、スクロールになる。ドラッグの間はスクロールしない。落とす位置の決まりは Windows と同じ。
- ファイルの行を左の欄へ落とすドラッグはない（タグ・プレイリスト・出典・ライセンスは、ファイルの詳細か一括操作で設定する）。
- 長押しで、文字の選択や端末の選び肢は出さない（入力欄を除く）。

## アプリのアイコン

ホーム画面のアイコンは、Windows と同じ絵（`app/src-tauri/icons/icon.png`）を使う。丸などに切り抜かれても欠けないよう、周りを空けて白い背景に置く（`gen/android` の `mipmap-anydpi-v26/ic_launcher.xml`）。絵を変えたときは、`npx tauri icon` で作り直して `gen/android` の `res` に写す。

## Android で出さない操作

ファイルの削除、エクスプローラーで見せる（ファイルの詳細の場所）、ファイルを紐づける（ファイルを1つ選ぶ）、書き出し（プレイリストの出力・一括操作の書き出し）、データのエクスポートとインポート（設定の「データ」は、Windows からのコピーだけ）、フォントの選択。自動アップデートの確認もしない。
