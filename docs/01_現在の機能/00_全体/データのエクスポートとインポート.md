# データのエクスポートとインポート

設定画面の「データ」タブで、ライブラリ・タグ・プレイリストなどのデータを JSON のファイルに書き出し（エクスポート）、読み込む（インポート）。同じ PC でのバックアップと戻し、別の PC・友人への受け渡しに使う。音声ファイルそのものは入れない。

## 項目
チェックボックスで選ぶ。
- ライブラリ（登録したフォルダ）
- タグ（階層・並び順・色・シノニムと、曲へのタグ付け）
- プレイリストとエフェクト（プレイリストの階層・項目・別名・再生方法・fx と、エフェクトセット）
- 出典・ライセンスと設定（出典・ライセンスと曲への設定、新しく作るタグの既定値、ファイルの情報からのタグ付けで無視する値の一覧と区切り文字の一覧、画面の設定：音量・再生方法・ライブラリの並び順・左右の欄の幅）

入れないもの：直近で再生したもの、たたんだタグ・プレイリスト、再生の欄で選んだエフェクトセット、書き出し先など。

## エクスポート
- 項目を選び（最初はすべて）、「エクスポート…」で保存先を選ぶ（ファイル名の初期値は `cyanomelody-YYYYMMDD.json`）。終わると、書き出した件数を出す。
- 曲の一覧（フォルダ・相対パス・大きさ・ハッシュ値）は、曲を見分けるために一緒に書き出す。ライブラリを選んだときはすべての曲、ほかは選んだ項目に関係する曲（タグの付いた曲、出典・ライセンスを設定した曲、プレイリストの項目の曲）と、そのフォルダ。
- プレイリストだけを選んだときも、タグの組み合わせの項目に使うタグ（とその先祖）は書き出す（取り込み先で名前で対応させるため）。

## インポート
1. 「ファイルを選ぶ…」でファイルを選ぶと、ファイルの場所、書き出した日時とアプリの版、項目ごとの件数（ファイルにない項目は選べない）、曲がこのPCでいくつ見つかるか（パス・ハッシュ値・名前と大きさの内訳）を出す。ファイルにある項目は最初からすべて選んでいる。
   - ライブラリを取り込むときで、見つからない曲があるときは、フォルダを登録してから探すので見つかる曲が増えることがあると出す。
   - ハッシュ値の計算が終わっていない曲があるときは、その数と、終わってから取り込むと見つかる曲が増えることがあると出す。
2. 取り込み方を選ぶ：「今あるデータに足す」（最初）か「選んだ項目を置き換える」。
3. 「取り込む」で取り込む。置き換えるときは、消えるもの（登録を外すフォルダ、タグ、プレイリストとエフェクトセット、出典とライセンスの件数）を出して確かめる。
4. 終わると結果（フォルダの登録、見つかった・見つからなかった曲、作ったタグとタグ付け、作ったプレイリスト・エフェクトセットと取り込まなかった項目、作った出典・ライセンスと曲への設定）を出し、データを読み直す。フォルダを登録したときは、ハッシュ値の計算を始める。

### 曲の見分け方
ファイルの中の曲を、このPCのライブラリの曲に対応させる。上から順に試す。
1. パス：フォルダのパスと相対パスが同じ曲（大文字・小文字は区別しない）。
2. ハッシュ値：音声の中身が同じ曲。複数あれば、見つからない印のないもの、同じファイル名のものを選ぶ。
3. 名前と大きさ：ファイル名と大きさが同じで、1つに決まる曲。

見つからなかった曲のタグ付け・出典・ライセンス・プレイリストの項目は取り込まない。

### 項目ごとの取り込み方
- ライブラリ：このPCにあって未登録のフォルダを登録してスキャンする（このPCにないフォルダや、登録済みのフォルダの中・外にあって登録できないフォルダは飛ばす）。置き換えるときは、ファイルにない登録済みのフォルダの登録を外す。フォルダの登録とスキャンは、曲を見分ける前に行う。
- タグ：同じ名前のタグ（今あるタグのシノニムと同じ名前を含む）は今のものを使う（階層・並び順・色・シノニムは変えない）。ない名前のタグは、ファイルの階層と並びのとおりに作る（親が今あるタグなら、その下の最後に入れる）。作ったタグには、ファイルのシノニムを付ける（ほかのタグの名前・シノニムと重なるものは付けない）。曲へのタグ付けは加える。置き換えるときは、今のタグをすべて消してから作る。
- プレイリストとエフェクト：エフェクトセットは、同じ名前で中身も同じなら今のものを使い、違えば「名前(2)」で作る。プレイリストは、同じ名前があれば「名前(2)」で作る。タグの組み合わせの項目のタグは名前で対応させる（なければ作る）。曲が見つからない項目、タグがなくなった項目は取り込まない。置き換えるときは、今のプレイリストとエフェクトセットをすべて消してから作る。
- 出典・ライセンスと設定：同じ名前の出典・ライセンスは今のものを使う（内容は変えない）。ない名前のものは作る。曲への設定は、足すときは曲にまだ設定がないときだけ、置き換えるときはファイルのとおりにする。新しく作るタグの既定値はファイルの値にする。画面の設定は、次にアプリを起動したときに反映する。
- ライブラリ以外の取り込みは1つのトランザクションで行い、途中で失敗したら何も変えない。

## ファイルの形式
- JSON。app（"cyanomelody"）、formatVersion（1）、appVersion、exportedAt（UNIX 時間の秒）、sections（入っている項目）と、folders・files・tags・sources・licenses・effectChains・playlists・newTag・metaIgnore・metaSeparators・screen。
- フォルダ・曲・タグ・出典・ライセンス・エフェクトセット・プレイリストには、ファイルの中だけの番号（id）を振り、つながりはその番号で表す。
- cyanomelody のものでないファイル、読めないファイル、formatVersion が新しすぎるファイルは取り込まず、エラーを出す。
