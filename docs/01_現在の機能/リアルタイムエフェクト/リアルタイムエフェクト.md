# リアルタイムエフェクト（Android）

鳴らしている曲に、指の操作でその場でエフェクトをかけたり、ドラムなどの単発の音を重ねたりして遊ぶ画面（以下「ライブの画面」）。Android だけ。
エフェクトセット（`エフェクト/エフェクト.md`）と違い、鳴らす前に音を作らず、ファイルや設定も変えない。

## 開き方と閉じ方
- 全画面の再生の右上の切り替えのボタンで開く。
- 「←」と端末の戻る操作で、全画面の再生に戻る。閉じても、曲は鳴り続ける（エフェクトは外れる）。

## 画面
- 見出しの行：「←」、鳴らしている曲の名前（何も鳴らしていなければ「再生していません」）、再生・一時停止（何も鳴らしていなければ、一覧の再生を始める）。
- 左半分
  - 単発の音のボタン（2列×3段。下の「単発の音」）。指が触れた瞬間に鳴らす。曲の音に重ねて鳴らし、エフェクトはかけない。押したボタンは、短く（0.15秒）光る（素早いタップでも光る。BPM のボタンも同じ）。
  - 左下に REC のボタン（下の「録音した音」）と、その右に BPM のボタン（下の「BPM」）。REC モードの間は、その上に録る音の切り替え（曲・マイク）を出す。
- 右半分
  - 上：エフェクトを選ぶボタン（2列×6段）。押すと選ぶ（同時に選べるのは1つ。選んでいるものは色を変える）。
  - 下：XY パッド（残りの高さいっぱい）。指を置いている間だけ、選んでいるエフェクトをかけ、離すと外す。横と縦の位置で効き方を変え、指を置いたまま動かすと、その場で変わる。指の位置に丸い印を出す。パッドの隅に、横と縦で何が変わるかを出す。最初に置いた指だけを追う。
  - 指を置いたままエフェクトを選び直すと、新しいエフェクトに切り替わる（指の位置はそのまま）。
- 指の操作で、画面はスクロールしない。

## エフェクト

SOUND VOLTEX の FX とつまみのフィルターを参考にした12個（2列×6段。この順に左上から）。同時にかけられるのは1つ。選んだものは、アプリを閉じても覚えておく。

共通の決まり
- テンポに合わせるもの（下の表の「BPM」が「使う」）は、BPM のボタンで測った BPM を使い、指を置いた瞬間を拍の頭とみなす（曲の拍の位置は分からないため）。
- テンポに合わせるものの横の位置は、細かさを段階で選ぶ（左から 1/4・1/8・1/12・1/16・1/24・1/32。1/4 は四分音符1つ分。Echo と SideChain は 1/16 まで）。
- 指を置いている間、パッドの上の真ん中に今の値（「1/16」「+5半音」「850Hz」など）を出す。
- Echo だけは、指を離した後も、残りの響きが消えるまで鳴らす（エフェクトを選び直すと消える）。

| ボタン | 効き方 | 横 | 縦 | BPM |
|---|---|---|---|---|
| Retrigger | 指を置いた瞬間からの音を覚えて、決まった長さで繰り返す。1周目はそのまま聞こえ、2周目から繰り返す。長さを変えても、繰り返しの始まりは変えない | 繰り返す長さ（1/4〜1/32）| 元の音と混ぜる割合（30%〜100%。上ほど繰り返しだけ）| 使う |
| Gate | 拍に合わせて音を切る（各刻みの前半は鳴らし、後半を切る）| 刻み（1/4〜1/32）| 切る深さ（50%〜100%）| 使う |
| Echo | 拍に合わせた遅れで、音が繰り返しながら小さくなる | 遅れ（1/4〜1/16）| 繰り返しの強さ（上ほど長く残る）| 使う |
| Wobble | こもった音（ローパス）の周波数を、拍に合わせて揺らす | 揺れの速さ（1/4〜1/32。1/4 で1拍に1回）| 揺れの幅（1〜6オクターブ）| 使う |
| SideChain | 拍の頭ごとに音量を沈めて、なめらかに戻す | 刻み（1/4〜1/16）| 沈む深さ（40%〜95%）| 使う |
| TapeStop | 指を置いた瞬間からの音を、だんだん遅く読み、低く遅くなって止まる | 止まるまでの時間（0.2〜2秒。左ほど速く止まる）| （使わない）| 使わない |
| Pitch | 速さを変えずに、音の高さだけを変える | 高さ（-12〜+12 半音。半音ずつ）| 変えた音の割合（30%〜100%）| 使わない |
| Flanger | とても短い遅れを揺らして元の音と重ね、うねらせる | うねりの速さ（0.1〜4Hz）| 深さ | 使わない |
| Phaser | オールパスのフィルター（4段）の周波数を揺らして元の音と重ね、柔らかくうねらせる | うねりの速さ（0.1〜3Hz）| 深さ | 使わない |
| BitCrush | 古いゲーム機のような、ざらついた音にする | 細かさ（左ほど荒い。同じ値を最大40点続ける）| ビットの粗さ（12〜4ビット）| 使わない |
| LPF | 高い音を削って、こもった音にする | 効く周波数（150Hz〜12kHz）| 強さ（上ほど、効く周波数の辺りが強調される）| 使わない |
| HPF | 低い音を削って、軽い音にする | 効く周波数（30Hz〜8kHz。右ほど低音が消える）| 強さ | 使わない |

- Retrigger・TapeStop・Pitch・BitCrush は、ブラウザの音声処理の部品では作れないので、AudioWorklet で作る（`app/src/live/processors.js`）。
- 拍に合わせる動き（Gate・SideChain）は、少し先までの拍の時刻を AudioContext の時刻で決めて予定しておく（画面の描き直しやタイマーの遅れに影響されないように）。

## 単発の音
録った音（下の「録音した音」）がないボタンは、音のファイルを使わず、その場で作る音を鳴らす（`app/src/live/oneShots.ts`）。ボタンの名前は英語。

| ボタン | 音 |
|---|---|
| Kick | 低い「ドン」 |
| Snare | 「タン」 |
| Clap | 手拍子の「パン」 |
| Hat | 短い「チッ」 |
| Riser | 「シューーッ」と、だんだん高く大きくなる雑音（盛り上げの音）。押している間、1小節（4拍）かけて上がりきり、そのまま鳴る。離すとすぐ消える |
| Impact | 低い「ドーン」と「シャーン」を重ねた、大きな一発（Riser の後の決めの音） |

- 指が触れた瞬間に1回鳴らす（Riser のほかは、押したままにしても1回だけ）。
- いくつかのボタンを同時に押せる（指ごとに別々に扱う）。指がボタンの外に出ても、離すまで続ける（Riser・録音）。
- ライブの画面を閉じると、押したままの音（Riser）と録音も止める。
- 大きさは、曲より少し小さめにそろえる（単発の音の出口で 0.8 倍）。

## 録音した音
単発の音のボタンに、利用者が録った音を割り当てられる（`app/src/live/samples.ts`）。

### 録る
- 左下の REC のボタンを押すたびに、REC モードの入と切が替わる。入のときは、押し込まれた見た目で赤くなり、単発の音のボタンが赤い枠になる。画面を開くたびに切から始まる。
- REC モードの間は、録る音を「曲」と「マイク」から選ぶ（選んだ方は、アプリを閉じても覚えておく）。
  - 曲：今聞こえている曲の音（ライブのエフェクトをかけていれば、かけた後の音）。単発の音は入れない。
  - マイク：端末のマイクの音。マイクは、REC モードで「マイク」を選んでいる間だけ開く（端末にマイクの使用中の印が出る）。初めてのときは、端末がマイクの許可を求める。許可しなければ「マイクを使えません」と出して「曲」に戻す。声の通話向けの処理（こだま消し・雑音消し・音量の自動調整）は切る。スピーカーで曲を鳴らしていると、マイクに曲の音も入る。
- REC モードの間、単発の音のボタンを押している間だけ録る（鳴らさない）。録っている間は、ボタンを赤く塗り、録った長さ（「● 1.2秒」）を出す。最大8秒で、超えたらそこで止める。
- 離すと、録った音をそのボタンに割り当てる（前の音は置き換わる）。録ったときの BPM も一緒に覚える。0.05秒より短いもの（触れてしまっただけ）は捨て、前の音を残す。
- 録った音は、アプリを閉じても残す（WebView の IndexedDB。ボタンごとに1つ）。消して、その場で作る音に戻すことはできない（録り直しはできる）。
- 録った音があるボタンは、名前の下に赤く「REC」と出す。

### 鳴らす（REC モードでないとき）
- 触れた瞬間に録った音を頭から鳴らし、離しても最後まで鳴らす。
- 同じボタンを続けて押すと、前の音を止めて（約5ミリ秒で小さくして）、頭から鳴らし直す。別のボタンの音とは重ねて鳴らす。
- 速さは、今の BPM に合わせる：録ったときの BPM と今の BPM の比で速さを変え、音の高さは変えない（例：BPM 120 で録った音を BPM 150 で鳴らすと、1.25倍の速さで短くなる）。比に上限はない（比が大きいと音が崩れる）。
- 速さを変えるのは、短い区切り（約40ミリ秒）を半分ずつ重ねてつなぎ直す方法（WSOLA）。BPM ごとに作った音を覚えておき、BPM が変わったり録り直したりしたら、押す前に裏で作っておく。

## BPM
- 曲に合わせて何回か押すと、押した間隔から BPM を出して、ボタンに出す（「BPM 128」。整数に丸めて出す）。
- 4回目から出す（それまでは「あと3回」などと出す）。直近の8回までの間隔の平均を使う。前に押してから2秒より空いたら、数え直す。
- 出した BPM は、次に測り直すまで覚えておく（アプリを閉じても覚えておく）。曲ごとには覚えない。一度も測っていないときは 120。
- BPM は、テンポに合わせて動くエフェクト（Retrigger・Gate・Echo・Wobble・SideChain）と、Riser の上がる速さと、録った音の速さに使う。

## 音の流れ
- 曲の audio 要素の音を、ブラウザの音声処理（Web Audio の AudioContext）に通し、入口 →（素通し｜エフェクト）→ 出口と流す。指を置く・離す、エフェクトを切り替えるときは、10ミリ秒で滑らかにつなぐ。
- 曲の音を AudioContext に通すのは、ライブの画面を初めて開いたとき。一度通したら、アプリを閉じるまで通したまま（取り消せない決まりのため）。ライブの画面を開かなければ、普段の再生は今までと同じ。
- 通した後も、アプリの音量・ロック中や裏に回したときの再生は今までと同じ。
- 音を通すため、Android では曲とエフェクトセットの音を、アプリのプロトコル `cm-media` から読む（`00_全体/Androidの画面.md` の「曲の読み方」）。
