# エフェクトの種類と設定

## 種類と設定

| エフェクト | 設定 | 最初の値 |
|---|---|---|
| 音量調整 | 増減（dB、−30〜+12） | 0dB |
| ノーマライズ | そろえ方（ピーク・平均）、目標（dBFS） | ピーク、−1dBFS |
| 再生速度・音程調整 | 速度（0.5〜2.0倍）、音程（−12〜+12半音） | 1.0倍、0半音 |
| リバーブ | 残響の長さ（0.1〜5秒）、混ぜる割合（0〜100%） | 1.5秒、30% |
| エコー | 遅れ（0.05〜2秒）、繰り返しの強さ（0〜90%）、混ぜる割合（0〜100%） | 0.3秒、40%、30% |
| フェードイン | 長さ（秒） | 1秒 |
| フェードアウト | 長さ（秒） | 1秒 |
| 簡易オフボーカル | 消す強さ（0〜100%）、下の周波数（50〜500Hz）、上の周波数（2,000〜16,000Hz） | 100%、120Hz、9,000Hz |

### 補足
- ノーマライズ：音全体を調べて、ピーク（いちばん大きい所）か平均の大きさ（RMS）が目標になるように音量を変える。平均でそろえて大きくなりすぎるときは、ピークが0dBFSを超えないところで止める。
- 再生速度・音程調整：速度と音程は別々に変えられる（速度を変えても音程は変わらず、音程を変えても長さは変わらない）。
- リバーブ・エコーは、残響の分だけ音が長くなる（終わりの残響を切らない）。
- フェードイン・フェードアウトの長さが音より長いときは、音の長さに合わせる。
- 簡易オフボーカル：真ん中から聞こえる音（多くの曲ではボーカル）のうち、下〜上の周波数の音を、消す強さの分だけ弱める。真ん中の低い音（ベース・バスドラムなど）・高い音（シンバルなど）と、左右に広がった音は残す。一覧での短い表示は「簡易オフボーカル 100% 120Hz〜9000Hz」。エフェクトの名前にマウスを乗せると、説明（モノラルの音にはかからないこと）を出す。
  - モノラルの音（左右が1つ）には、ボーカルだけを選べないので、何もしない。左右が3つ以上の音は、最初の2つを左右として扱う。
  - できないこと：真ん中にある楽器（スネア、ベースの倍音、ギターのソロなど）も、下〜上の周波数の分は一緒に弱まる。左右に広げたボーカル・ハモり・ボーカルのリバーブは残る。強く圧縮された MP3 などでは、うっすら残ることがある。
- 並べた順にかけるので、たとえば「エコー → フェードアウト」と「フェードアウト → エコー」では結果が変わる。

## 処理の方法

- エフェクトの処理はRust側（`app/src-tauri/src/effects.rs`）で行う。元のファイルを読んで波形にし（symphonia）、エフェクトを順にかけ、16bitのWAVにする。
- 速度・音程調整は、音程を変えずに長さを変える処理（WSOLA）と、標本の補間（4点のCatmull-Rom）を組み合わせる。音程の比 p、速度 s のとき、長さを p/s 倍に伸ばしてから p 倍の速さで読み直す。
- リバーブは、Schroeder型（8つの櫛形フィルタと4つの全域通過フィルタ）。櫛形フィルタの帰還の強さは、残響が指定の長さで −60dB になるように決める。
- エコーの繰り返しは、−60dBより小さくなるまで（最長10秒）の長さを足す。
- 簡易オフボーカルは、左右を真ん中（M = (L+R)/2）と左右の差（S = (L−R)/2）に分け、M から Linkwitz-Riley（4次）で下〜上の周波数の音を取り出して、強さの分だけ引く。M と S には、Linkwitz-Riley の分け目2つ分と同じ全域通過フィルタ（2次を2つ）をかけて位相をそろえ、L = M′ + S′、R = M′ − S′ に戻す（3つに分けて足し戻すのと同じ結果を、少ないフィルタで得る）。上の周波数は、ナイキスト周波数の 0.45 倍までに収める。
- 速さの目安（リリースビルド、ステレオ44.1kHz、8つすべて）：5秒の音で約0.04秒、1分で約0.5秒、5分で約2.3秒。簡易オフボーカルだけなら、5分で約0.2秒。
