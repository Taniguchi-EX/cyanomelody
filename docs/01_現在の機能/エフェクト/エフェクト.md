# エフェクト

音声に音量調整やリバーブなどのエフェクトをかけて再生する。
エフェクトは、いくつかを順に並べた「エフェクトのまとまり」に名前を付けて管理し、プレイリストの項目に結び付ける。
エフェクトはそのプレイリストでの再生だけで有効で、元のファイルは変更しない。
エフェクトの種類・設定と処理の方法は`エフェクトの種類と設定.md`を参照。

## エフェクトのまとまり

- 名前を持つ。名前の決まりはタグと同じ。全体で一意（大文字・小文字は区別しない）。
- 中身は、順番の付いたエフェクトの並び。上から順にかける。同じ種類のエフェクトを何度入れてもよい。

## 管理画面

- 左の欄のプレイリストの欄の「エフェクト」で開く。メインの画面に重ねて表示し、「閉じる」かEscキーで戻る。
- 左にまとまりの一覧（名前の順。結び付けている項目の数。マウスを乗せると中身の説明）、右に選んだまとまりの中身を出す。
- 作成：名前を入れて「作成」（またはEnter）。作ったまとまりが選ばれる。同じ名前があるときはエラー。
- 名前変更・削除：右の上の欄で行う。削除の確認には、結び付けている項目の数を出す。削除すると、結び付けていた項目からは外れる。
- 中のエフェクト：「加える」で種類を選んで最後に加える（最初の値で）。各行で設定を変え、↑↓で並べ替え、「外す」で外す。
  - 割合の設定（混ぜる割合など）は%で入れる。範囲の外の値は、保存するときに範囲に収める。
  - 変えた内容は「保存」で保存する。「元に戻す」で保存した状態に戻す。保存していない変更があるまま、閉じたり別のまとまりを選んだりするときは、捨ててよいか確かめる。
- 試聴：「▶ 試聴」で、右の欄に出しているファイルに、いま画面にあるエフェクトの並び（保存する前でもよい）をかけて鳴らす。右の欄にファイルがないときは押せない。

## プレイリストの項目への結び付け

- 編集画面の各項目で、エフェクトのまとまりを1つ選ぶ（「エフェクトなし」で外す）。
- ファイルの項目：そのファイルにかける。タグの組み合わせ・プレイリストの項目：対象のファイルすべてにかける。
- 項目が入れ子になっているときは、内側（ファイルに近い方）の項目のまとまりから先にかけ、次に外側をかける。
- 有効なのは、そのプレイリストを直接・親から・参照から再生したときだけ。同じファイルを別の場所で再生したときはかからない。

## 再生

- 再生順を決めるときに、各曲にかけるまとまり（内側から外側の順）も決める。
- エフェクトのかかる曲は、鳴らす前にエフェクトをかけた音を作る。作っている間は、再生の欄に「準備中…」と出す（一時停止はできない）。作っている間に別の曲へ移ったときは、作り終えた前の曲は鳴らさない。
- 作れなかった曲（読めないなど）は、再生できない曲として飛ばす。

## エフェクトをかけた音の置き場所

- アプリのデータ領域の`effects-cache`フォルダに、WAVで置く。
- 元のファイル（パス・大きさ・更新日時）とエフェクトの設定が同じなら、作り直さずに使い回す。どちらかが変わると、別のファイルとして作る。
- 合計が1GBを超えたら、使った日時の古いものから消す。

## データ

- effect_chains：エフェクトのまとまり（id、名前、作成日時）
- effect_steps：まとまりの中のエフェクト（まとまりid、順番、種類と設定のJSON）
- playlist_items の effect_chain_id：結び付けたまとまり。まとまりを削除すると空になる。
