# エフェクト

音声に音量調整やリバーブなどのエフェクトをかけて再生する。
エフェクトは、いくつかを順に並べた「エフェクトセット」に名前を付けて管理し、プレイリストの項目に結び付ける。また、再生の欄で選んで、再生する曲すべてにかけられる。
元のファイルは変更しない。
エフェクトの種類・設定と処理の方法は`エフェクトの種類と設定.md`を参照。

## エフェクトセット

- 名前を持つ（名前の決まりは`00_全体/画面の構成.md`）。
- 中身は、順番の付いたエフェクトの並び。上から順にかける。同じ種類のエフェクトを何度入れてもよい。

## プレイリストの項目への結び付け

- プレイリストの詳細画面の各項目の fx のプルダウンで、エフェクトセットを1つ選ぶ（「fx なし」で外す）。付いている項目は、プルダウンにその名前を出す。
- チェックした項目の fx を変えると、チェックした項目すべての fx が同じになる。チェックしていない項目の fx を変えると、その項目だけ。
- プルダウンの最後の「新しいfxを作る」と「このfxを編集」（付いている項目だけ）で、管理画面を開く（下を参照）。
- ファイルの項目はそのファイルに、タグの組み合わせ・プレイリストの項目は対象のファイルすべてにかける。
- 項目が入れ子になっているときは、内側（ファイルに近い方）の項目のエフェクトセットから先にかけ、次に外側をかける。
- 有効なのは、そのプレイリストを直接・親から・参照から再生したときだけ。同じファイルを別の場所で再生したときはかからない（再生の欄のエフェクトセットは除く）。

## 再生の欄のエフェクトセット

- 再生の欄の右（音量の左）のプルダウンで、エフェクトセットを1つ選ぶ（最初は「fx なし」）。選んだものはアプリを閉じても覚えておく。
- 選んだエフェクトセットは、再生の欄で鳴らす曲すべて（ファイルの一覧の再生、プレイリストの再生、プレイリストの項目の再生）にかける。
- プレイリストの項目のエフェクトセットがかかる曲では、そちらだけをかけ、再生の欄のエフェクトセットはかけない。その曲を鳴らしている間は、プルダウンをグレーアウトする（マウスを乗せると理由を出す）。グレーアウトしていても選び直せる。
- 曲を鳴らしている間に選び直すと、その曲（プレイリストの項目のエフェクトがかからない曲）を、新しいエフェクトで同じ位置から鳴らし直す。
- 選んでいたエフェクトセットを削除すると「fx なし」になる。
- エフェクトの管理画面の試聴と、プレイリストの書き出しにはかけない。

## 管理画面

- メインの画面に重ねて表示し、「閉じる」かEscキーで戻る。
- 左にエフェクトセットの一覧（名前の順。結び付けている項目の数。マウスを乗せると中身の説明）と、名前を入れて作る欄（「作成」かEnterで、すぐに一覧に加わり選ばれる）。右に選んだエフェクトセットの中身。
- 開き方
  - 「このfxを編集」：そのエフェクトセットを選んだ状態で開く。
  - 「新しいfxを作る」：保存していない空のエフェクトセットを出す。
    - 名前は「新しいエフェクトセット」（その名前がすでにあるときは「新しいエフェクトセット(2)」「(3)」…）。右の名前の欄で変えられる。
    - 保存するまでは一覧に加えない。「保存」で作って一覧に加えて選び、開いた元の項目（チェックした項目で選んだときは、チェックした項目すべて）に付ける。
    - 保存せずに閉じたときは作らず、項目は今のまま。
- 右の上：名前の欄、「名前を変える」、「削除」（確認に、結び付けている項目の数を出す。削除すると、結び付けていた項目からは外れる）。保存していない新しいエフェクトセットでは、「名前を変える」「削除」は出さない。
- 中のエフェクト：種類を選んで「追加」で最後に加える（最初の値で）。各行で設定を変え、↑↓で並べ替え、「✕」で外す。
  - 割合の設定（混ぜる割合など）は%で入れる。範囲の外の値は、保存するときに範囲に収める。
- 「保存」：変えた内容を保存する。保存していない変更があるときは「保存」を目立つ色にする。そのまま閉じたり別のエフェクトセットを選んだりするときは、捨ててよいか確かめる。
- 試聴：試聴のボタン（「▶」と曲の名前）で、開いた元の項目の曲（タグの組み合わせ・プレイリストの項目なら、中の最初の曲）に、いま画面にあるエフェクトの並び（保存する前でもよい）をかけて鳴らす。項目に鳴らせる曲がないときは押せない。
  - 鳴っている間はボタンが「■」になり、押すと止まる。
  - 鳴っている間に値や並びを変えると、0.5秒待ってから、変えた後の内容で鳴らし直す。

## 再生

- 再生順を決めるときに、各曲にかけるエフェクトセット（内側から外側の順）も決める。
- エフェクトのかかる曲は、鳴らす前にエフェクトをかけた音を作る。作っている間は、再生の欄に「準備中…」と出す（一時停止はできない）。作っている間に別の曲へ移ったときは、作り終えた前の曲は鳴らさない。
- 作れなかった曲（読めないなど）は、再生できない曲として飛ばす。

## エフェクトをかけた音の置き場所

- アプリのデータ領域の`effects-cache`フォルダに、WAVで置く。
- 元のファイル（パス・大きさ・更新日時）とエフェクトの設定が同じなら、作り直さずに使い回す。
- 合計が1GBを超えたら、使った日時の古いものから消す。

## データ

- effect_chains：エフェクトセット（id、名前、作成日時）
- effect_steps：エフェクトセットの中のエフェクト（エフェクトセットid、順番、種類と設定のJSON）
- playlist_items の effect_chain_id：結び付けたエフェクトセット。エフェクトセットを削除すると空になる。
