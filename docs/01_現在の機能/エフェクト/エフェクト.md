# エフェクト

音声に音量調整やリバーブなどのエフェクトをかけて再生する。
エフェクトは、いくつかを順に並べた「エフェクトセット」に名前を付けて管理し、プレイリストの項目に結び付ける。
エフェクトはそのプレイリストでの再生だけで有効で、元のファイルは変更しない。
エフェクトの種類・設定と処理の方法は`エフェクトの種類と設定.md`を参照。

## エフェクトセット

- 名前を持つ。名前の決まりはタグと同じ。全体で一意（大文字・小文字は区別しない）。
- 中身は、順番の付いたエフェクトの並び。上から順にかける。同じ種類のエフェクトを何度入れてもよい。

## 管理画面

- プレイリストの詳細画面の、項目の fx のプルダウンから開く。メインの画面に重ねて表示し、「閉じる」かEscキーで戻る。
  - 「新しいfxを作る」：その項目の曲を試聴の対象にして開き、保存していない空のエフェクトセットを出す。
    - 名前は「新しいエフェクトセット」（その名前がすでにあるときは「新しいエフェクトセット(2)」「(3)」…）。右の名前の欄で変えられる（「名前を変える」「削除」は出さない）。
    - 保存するまでは、エフェクトセットの一覧に加えない。「保存」で、エフェクトセットを作って中のエフェクトを保存し、一覧に加えて選ぶ。開いた元の項目に付ける（チェックした項目で選んだときは、チェックした項目すべて）。
    - 保存せずに閉じる・ほかのエフェクトセットを選ぶときは、保存していない変更として確かめる。捨てたら作らず、項目は今のまま。
  - 「このfxを編集」（エフェクトセットが付いている項目だけ）：そのエフェクトセットを選んだ状態で開く。試聴の対象はその項目の曲。
  - タグの組み合わせ・プレイリストの項目から開いたときは、試聴の対象はその項目の中の最初の曲。
- 左にエフェクトセットの一覧（名前の順。結び付けている項目の数。マウスを乗せると中身の説明）、右に選んだエフェクトセットの中身を出す。
- 作成：左の上の欄に名前を入れて「作成」（またはEnter）。すぐに一覧に加わり、選ばれる。同じ名前があるときはエラー（「新しいfxを作る」の保存でも同じ）。
- 名前変更・削除：右の上の欄で行う。削除の確認には、結び付けている項目の数を出す。削除すると、結び付けていた項目からは外れる。
- 中のエフェクト：種類を選んで「追加」で最後に加える（最初の値で）。各行で設定を変え、↑↓で並べ替え、「✕」で外す（↑↓✕は行の右端に寄せる）。
  - 割合の設定（混ぜる割合など）は%で入れる。範囲の外の値は、保存するときに範囲に収める。
  - 変えた内容は「保存」で保存する。保存していない変更があるときは、「保存」を目立つ色にする（マウスを乗せると「保存していない変更があります」）。保存していない変更があるまま、閉じたり別のエフェクトセットを選んだりするときは、捨ててよいか確かめる。
- 試聴：試聴のボタン（「▶」と、試聴の対象の曲の名前）で、その曲に、いま画面にあるエフェクトの並び（保存する前でもよい）をかけて鳴らす。試聴の対象がない（項目に鳴らせる曲がない）ときは押せない。
  - 鳴っている間はボタンが「■」になり、押すと止まる。
  - 鳴っている間にエフェクトの値や並びを変えると、0.5秒待ってから、変えた後の内容で鳴らし直す（入力の途中で何度も作り直さないよう待つ）。

## プレイリストの項目への結び付け

- 詳細画面の各項目の fx のプルダウンで、エフェクトセットを1つ選ぶ（「fx なし」で外す）。エフェクトセットが付いている項目は、プルダウンにその名前を出す（色は変えない）。
- チェックした項目の fx を変えると、チェックした項目すべての fx が同じになる。チェックしていない項目の fx を変えると、その項目だけ。
- ファイルの項目：そのファイルにかける。タグの組み合わせ・プレイリストの項目：対象のファイルすべてにかける。
- 項目が入れ子になっているときは、内側（ファイルに近い方）の項目のエフェクトセットから先にかけ、次に外側をかける。
- 有効なのは、そのプレイリストを直接・親から・参照から再生したときだけ。同じファイルを別の場所で再生したときはかからない。

## 再生

- 再生順を決めるときに、各曲にかけるエフェクトセット（内側から外側の順）も決める。
- エフェクトのかかる曲は、鳴らす前にエフェクトをかけた音を作る。作っている間は、再生の欄に「準備中…」と出す（一時停止はできない）。作っている間に別の曲へ移ったときは、作り終えた前の曲は鳴らさない。
- 作れなかった曲（読めないなど）は、再生できない曲として飛ばす。

## エフェクトをかけた音の置き場所

- アプリのデータ領域の`effects-cache`フォルダに、WAVで置く。
- 元のファイル（パス・大きさ・更新日時）とエフェクトの設定が同じなら、作り直さずに使い回す。どちらかが変わると、別のファイルとして作る。
- 合計が1GBを超えたら、使った日時の古いものから消す。

## データ

- effect_chains：エフェクトセット（id、名前、作成日時）
- effect_steps：エフェクトセットの中のエフェクト（エフェクトセットid、順番、種類と設定のJSON）
- playlist_items の effect_chain_id：結び付けたエフェクトセット。エフェクトセットを削除すると空になる。
