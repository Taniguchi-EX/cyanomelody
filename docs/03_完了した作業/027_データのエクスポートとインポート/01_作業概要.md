# データのエクスポートとインポート

## 目的
ライブラリ・タグ・プレイリストなどのデータを JSON のファイルに書き出し（エクスポート）、別の PC やアプリを入れ直した後に読み込める（インポート）ようにする。

- 使い道：同じ PC でのバックアップと戻し、別の PC・友人への受け渡しの両方。
- 何を入出力するかは、そのたびに選べる。

## 入出力する項目
設定画面に「データ」のタブを加え、そこで操作する。項目は次の4つ（チェックボックスで選ぶ）。

1. ライブラリ：登録したフォルダ。
2. タグ：タグの階層・並び・子のタグの並び順・色と、曲へのタグ付け。
3. プレイリストとエフェクト：プレイリスト（階層・項目・別名・再生方法）と、項目に付けたエフェクトセット。項目に付けていないエフェクトセットも含める。
4. 出典・ライセンスと設定：出典・ライセンスの一覧と曲への設定、新しく作るタグの既定値、画面の設定（音量・再生方法・ライブラリの並び順・欄の幅）。

- 曲の一覧（パス・ハッシュ値・大きさ）は、どの項目を選んでも、曲を見分けるために一緒に書き出す。選んだ項目に関係する曲だけを書き出す（ライブラリを選んだときは、すべての曲）。
- 入れないもの：直近で再生したもの、たたんだタグ・プレイリスト、再生の欄で選んだエフェクトセット、書き出し先などの一時的なもの。ハッシュ値の計算の結果（ハッシュ値は曲を見分けるためにだけ使う）。

## エクスポート
- 項目を選び、「エクスポート」で保存先のファイルを選ぶ（ファイル名の初期値は `cyanomelody-YYYYMMDD.json`）。
- 終わったら、書き出した件数（フォルダ・曲・タグ・プレイリストなど）を出す。

## インポート
1. 「インポート」でファイルを選ぶと、中身の一覧（入っている項目と件数、書き出した日時とアプリの版）と、曲の見つかり方（下の「曲の見分け方」）の見込みを出す。
2. 取り込む項目を選ぶ（ファイルに入っている項目だけ選べる）。
3. 取り込み方を選ぶ：「今あるデータに足す」か「選んだ項目を置き換える」。
4. 「取り込む」で取り込む。「置き換える」のときは、消えるものの件数を出して確かめる。
5. 終わったら結果（加えた件数、見つからなかった曲の数）を出す。

### 曲の見分け方
ファイルの中の曲を、このPCのライブラリの曲に対応させる。上から順に試す。
1. パス：同じフォルダのパスと相対パスの曲（同じ PC での戻し）。
2. ハッシュ値：音声の中身が同じ曲（別の PC。フォルダの場所や名前が違ってもよい）。同じ音声が複数あれば、見つからない印のないもの、パスの近いものを選ぶ。
3. 名前と大きさ：ファイル名と大きさが同じで、1つに決まる曲（ハッシュ値をまだ計算していない曲のため）。

- 見つからなかった曲のタグ付け・出典・ライセンス・プレイリストの項目は、取り込まない（件数を結果に出す）。
- ハッシュ値の計算が終わっていない曲があるときは、インポートの画面にそのことを出す（終わってから取り込むと、見つかる曲が増える）。

### 項目ごとの取り込み方
- ライブラリ
  - 足す：ファイルの中のフォルダのうち、このPCにあって未登録のものを登録してスキャンする。このPCにないフォルダは飛ばす（件数を出す）。
  - 置き換える：さらに、ファイルにない登録済みのフォルダの登録を外す（その中の曲のタグなども消える）。
  - 曲の見分けは、フォルダの登録とスキャンの後に行う。
- タグ
  - 足す：同じ名前のタグは同じタグとみなす（今のタグの階層・並び順・色は変えない）。ない名前のタグは、ファイルの階層のとおりに作る（親が今あるタグなら、その下に入れる）。曲へのタグ付けは加える（外さない）。
  - 置き換える：今のタグをすべて消してから、ファイルのとおりに作る。
- プレイリストとエフェクト
  - 足す：エフェクトセットは、同じ名前で中身も同じなら今のものを使い、違えば「名前(2)」で作る。プレイリストは、同じ名前があれば「名前(2)」で作る（今のプレイリストは変えない）。
  - 置き換える：今のプレイリストとエフェクトセットをすべて消してから作る。
  - 項目の「タグの組み合わせ」は、タグを名前で対応させる（取り込み先にないタグは作る）。
- 出典・ライセンスと設定
  - 足す：同じ名前の出典・ライセンスは同じものとみなす（今の内容は変えない）。ない名前のものは作る。曲への設定は、曲にまだ設定がないときだけ設定する。
  - 置き換える：今の出典・ライセンスをすべて消してから作り、曲への設定をファイルのとおりにする。
  - 設定（新しく作るタグの既定値・画面の設定）は、どちらでもファイルの値にする。
- 取り込みは1つのまとまり（トランザクション）で行い、途中で失敗したら何も変えない（フォルダのスキャンを除く）。

## ファイルの形式
- JSON。先頭に、アプリの名前（"cyanomelody"）・形式の版（1）・アプリの版・書き出した日時・入っている項目を持つ。
- フォルダ・曲・タグなどには、ファイルの中だけで使う番号を振り、つながり（曲のタグ、プレイリストの項目の曲など）はその番号で表す。
- 形式の版が新しすぎるファイル、cyanomelody のものでないファイルは、取り込まずにエラーを出す。

## やらないこと
- 音声ファイルそのもののコピー（データだけを入出力する）。
- 自動のバックアップ（定期的な書き出し）。
- 2つの PC の間で、続けて同期すること（全体ロードマップの「Androidとの同期機能」で扱う）。
