# セルフレビュー

## 仕様との突き合わせ
- 作業概要の範囲（4つの項目の選択、曲の見分け方の3段階、取り込みの見込み、足す・置き換える、置き換えの確認、結果、形式の確かめ）をすべて実装した。

## 見つけて直した問題
- タグだけを置き換えると、プレイリストのタグの組み合わせの項目からもタグが外れる（データベースのつながりで一緒に消える）。置き換えの確認に、そのことを書くようにした（プレイリストも一緒に置き換えるときは書かない）。
- 「ライブラリを取り込むと見つかる曲が増えることがある」の注意を、すべての曲が見つかるときにも出していた。見つからない曲があるときだけにした。
- プレイリストだけを書き出すと、タグの組み合わせの項目のタグが入らず、取り込み先で項目を作れなかった。項目に使うタグとその先祖を書き出すようにした（単体テストで確認）。

## 不具合の確認
- 親子が輪になっているタグ（本来はない）が入ったファイルでも止まらない（輪のものは最上位に作る）。
- 1つのプレイリストを子にできるのは1か所だけなので、ファイルの中で2か所から子にしていても、2つ目は参照として取り込む。
- 並び順・色・再生方法の値がおかしいときは、決まった値に直す（並び順は引き継ぐ、色はなし、再生方法は順に）。
- 書き出したファイルを手で直して壊したときは、取り込まずにエラーを出す。
- ライブラリのフォルダのスキャンはトランザクションの外なので、その後の取り込みで失敗しても、登録したフォルダは残る（作業概要のとおり）。

## 既存の機能への影響
- 設定画面のタブが3つになった（画面テスト S01 を直した）。
- 取り込んだ後は、データをすべて読み直す。

## 確かめていないこと
- 3万件のライブラリの書き出し・取り込みの速さ（曲の対応はハッシュ表で行うので、件数に比例する）。
