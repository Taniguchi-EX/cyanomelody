# 自動タグ付けの区切り文字

## 目的
ファイルの情報からのタグ付け（作業30）で、作曲者などの1つの値に複数の名前が入っているとき（「清水依与吏/back number」「A feat. B」など）に、区切り文字で分けて、それぞれをタグにする。

## 範囲

### 区切り文字の一覧
- 確認のダイアログに、無視する値の一覧と同じ形で、区切り文字の一覧を置く（「以下の値は無視する」の下）。
  - 「以下の文字で区切る」のチェックボックス（開くたびに ON から始める）と、その下に区切り文字の一覧（1行に1つ、薄い文字）。
  - 編集の仕方は無視する値と同じ：各行の「✎」（編集）・「−」（削除）、最後の「＋」（追加）。空・一覧にもうある値（大文字・小文字は区別しない）は入れられない。変えるとすぐに保存し、次に開いたときも同じ一覧を出す。
  - 初期値：`,`　`/`　`／`　`feat.`　`with`（`・` はカタカナの外国の名前を分けてしまうので入れない）
  - 区切り文字の前後の空白は、そのまま区切り文字に含めない（一覧には前後の空白を除いて保存し、分けた後の値の前後の空白も除く）。
- 一覧はデータベースの設定に保存する（key "meta_separators"）。データのエクスポート・インポートの「出典・ライセンスと設定」にも含める。

### 分け方
- 対象の項目：アーティスト・作曲者だけ（アルバム名・ジャンルは分けない。アルバム名は「・」「/」を含むことが多いため）。
- チェックボックスが ON のときは、値を一覧のどの区切り文字でも分ける。大文字・小文字は区別しない（「Feat.」「WITH」も区切る）。
- 英字で始まる・終わる区切り文字（`feat.`・`with` など）は、単語としてだけ区切る：前後が英数字でないとき（空白・記号・値の端）だけ区切る。「Smith」の「with」や「Withered」では区切らない。
- 分けた後の値は前後の空白を除き、空になったものは使わない。分けた値ごとに、無視する値の確認・タグを付ける（親のタグはその項目のもの）。同じ値が2回出てきても、タグは1つ。
- 一括操作の結果の「作ったタグ」などの数は、分けた後のタグで数える。

## やらないこと
- 区切り文字を正規表現で書けるようにすること。
- 項目ごとに別の区切り文字を持つこと。

## データ
- settings の key "meta_separators" に、区切り文字の一覧を JSON で持つ（まだ決めていなければ初期値）。

## 未決事項
- なし（区切るのはアーティスト・作曲者だけ、`・` は初期値に入れない、「以下の文字で区切る」のチェックボックスを置く）。
