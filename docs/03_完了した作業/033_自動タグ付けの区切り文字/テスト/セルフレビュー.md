# セルフレビュー

## 仕様との突き合わせ
- 作業概要のとおり、確認のダイアログに「以下の文字で区切る（アーティスト・作曲者）」と区切り文字の一覧（初期値 `,` `/` `／` `feat.` `with`）を加え、アーティスト・作曲者だけを分ける。

## 見つけて直した問題
- 無視する値の一覧の編集の部分を、そのまま2つ目に写すと重なる。編集できる一覧（EditableList）を1つの部品にして、無視する値と区切り文字の両方で使うようにした。保存の仕方（設定への保存、空・重なる値の確かめ）も Rust で1つの関数にまとめた。
- 2つの一覧があるので、加えるボタン・入力欄の名前を「無視する値を加える」「区切り文字を加える」「加える無視する値」「加える区切り文字」のように分けた（画面テストの指定も直した）。
- 一覧のどちらかを編集している間に「タグを付ける」を押すと、入力中の値が保存されないまま始まってしまう。どちらかを編集している間は押せないようにした。

## 不具合の確認
- 英字の区切り文字は単語としてだけ区切る（「Smith」「Withered」「Starwith」では区切らない。単体テストで確認）。
- 長い区切り文字を先に試すので、「feat.」と「.」の両方があっても「feat.」で区切る。
- 区切り文字の一覧が空、またはチェックボックスが OFF のときは、今までどおり値をそのまま使う。
- 分けた後の値が「Unknown」などのときは、無視する値として除く（単体テストで確認）。

## 既存の機能への影響
- 区切るのはアーティスト・作曲者だけなので、アルバム名・ジャンルのタグの付き方は変わらない。
- 自動タグ付けを今までどおりに使うと（チェックボックスが ON のまま）、「A/B」のような値は分けて付くようになる。前に付けた「A/B」のタグは残る（タグは付けるだけで外さない）。
