# ロードマップ

## 1. 内部の処理（Rust）
- [x] ファイルの中の情報を読む：アーティスト（空ならアルバムアーティスト）・アルバム・ジャンル・作曲者。文字コードの読み直し（MP3 の ISO-8859-1、WAV の INFO を直接読む）、ジャンルの番号の書き方（「(17)」）をジャンル名に
- [x] タグを付ける：親のタグ（なければ作る）、同じ名前は今のタグ、なければ親の下に作る。意味のない値を無視する
- [x] 意味のない値の一覧の保存（設定。初期値）と、データのエクスポート・インポートへの追加
- [x] ファイル1件に付ける処理（付けたタグを返す）
- [x] たくさんのファイルに付ける処理（裏で行う、進み具合、中止。ハッシュ値の計算と同じ形）
- [x] 単体テスト（形式ごとの読み取り、文字コード、ジャンルの番号、親のタグ、同じ名前、意味のない値、何度行っても同じ）
