# セルフレビュー

## 確かめたこと
- 行のドラッグは、ボタン（開閉の印・✎・🗑・▶・✕）、入力欄（名前の変更）、プルダウン、チェックボックスの上からは始めない。押しただけ（動かす距離が小さい）なら、今までどおり行を押したことになる。
- ドラッグの後に同じ行の上で離したときに出る click は、行を押したことにしない（G07 で確かめた）。別の行の上で離したときは、click は行に届かない。
- ドラッグの開始を pointerdown の既定の動作の取り消しではなく、行の文字を選べなくすること（user-select）で扱った。名前の入力欄を開いているときに別の行を押すと、今までどおり入力欄が閉じる。
- 動かしている間のイベントは window で受ける（行の外に出ても続く）。終わったら必ず外す。
- プレイリストの項目は、左の欄へ落とすドラッグと並べ替えを1つのドラッグにまとめた。項目の行の上なら並べ替え（件数の表示を隠す）、左の欄の行の上なら今までどおり。処理中は並べ替えをしない。
- ミュートの解除で戻す音量は、アプリを閉じると忘れる（音量そのものは保存する）。0のまま起動して解除すると100%。作業概要のとおり。
- ダブルクリックの1回目の click で右の欄に出し、2回目の後に再生する。鳴らしている行では、止めずに最初から鳴らし直す（▶ の「止める」とは別の動き）。
- 歯車とスピーカーの絵は自作の SVG（ライセンスの一覧に足すものはない）。色は文字の色に合わせ、暗い配色でも見える。
