# 細かいUIの改善

## 目的
再生の欄のアイコン、ファイルの行の操作、並べ替えのドラッグを、わかりやすく使いやすくする。

## 範囲

### 1. 設定の歯車
- 再生の欄の右端の「⚙」（文字）を、はっきり歯車とわかる絵（SVG）に替え、大きくする。

### 2. 音量のアイコン
- 音量の左のスピーカーの記号（🔈）を、絵（SVG）に替える。
- 音量が0のときは、スピーカーに「×」の付いたアイコンにする。

### 3. スピーカーを押してミュート
- スピーカーのアイコンをボタンにし、押すとミュートとミュートの解除を切り替える。
- ミュート：音量を0にする（つまみも0になる）。直前の音量を覚えておく。
- 解除：覚えておいた音量に戻す。覚えていなければ（音量0のまま起動したときなど）100%にする。
- つまみを動かして0にしたときも、ミュートと同じ表示になる。0から押すと解除になる。

### 4. 行のダブルクリックで再生
- ライブラリのファイルの行をダブルクリックすると、そのファイルから再生する（▶を押したときと同じ）。鳴らしている行をダブルクリックしたときは、止めずに最初から鳴らし直す。
- プレイリストの詳細画面の項目の行も、ダブルクリックで再生する（項目の▶と同じ）。
- 行の中のボタン・チェックボックス・プルダウンのダブルクリックは、それぞれの操作だけにする。

### 5. 行のドラッグで並べ替え
- 並べ替えの取っ手（≡）をなくし、行そのものをつかんでドラッグして並べ替える。
- 対象：左の欄のタグ・プレイリスト・出典・ライセンス、プレイリストの詳細画面の項目。
- 少し動かしてからドラッグになる（ただ押しただけなら、今までどおり行を押したことになる）。ドラッグした後は、行を押したことにしない。
- 行の中のボタン（開く・たたむ、✎、🗑 など）と名前の入力欄からは、ドラッグを始めない。
- 落とす場所の決め方（前・後ろ・子）と表示は今のまま。
- プレイリストの詳細画面の項目は、今も行をつかんで左の欄のタグなどへ落とせる。同じドラッグで、落とした先によって動きを変える。
  - 項目の行の上で離す：並べ替え（つかんだ項目だけを移す）。
  - 左の欄のタグ・プレイリスト・出典・ライセンスの行で離す：今までどおり（チェックした項目をつかんだときは、チェックしたものすべて）。
- 取っ手のぶん空けていた件数の位置は、取っ手なしでそろえる。

### 6. 鳴らしている行の停止ボタン
- ライブラリの一覧で、鳴らしているファイルの行の停止ボタン（■）を青くする（アクセントの色）。

## やらないこと
- 複数の項目をまとめて並べ替えること。
- プレイリストの項目の停止ボタンの色（ライブラリの一覧だけ）。
