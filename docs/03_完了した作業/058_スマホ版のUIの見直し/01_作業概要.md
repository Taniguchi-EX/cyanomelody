# スマホ版の UI の見直し

状態：完了（2026-11-12）。

## 目的
Android 版で使いにくい所を2つ直す（ユーザーの指示）。

## 直すこと

### タグの入力欄の候補が、入力欄にかぶる
- ファイルの詳細でタグを付けるときなどに、候補の一覧が入力欄の上に重なって出て、文字を入れにくい。端末の標準の候補の一覧（`datalist`）は、出す位置をアプリで決められない。
- Android では `datalist` を使わず、入力欄のすぐ下に候補の一覧を並べる（画面の中の普通の行として出し、下の欄を押し下げる）。
  - 文字を入れると、名前かシノニムにその文字を含むタグを出す（名前がその文字で始まるものを先に）。シノニムは名前の横に出す。
  - 候補を押すとすぐ付ける（今の「候補の一覧から選ぶと、すぐに付ける」と同じ）。付けた後も入力欄から指を離さず（キーボードを閉じず）、続けて入れられる。
  - 入力欄を押したら、入力欄が画面の上の方に来るようにスクロールする（下に候補を出す場所を空ける）。
- キーボードが出ている間は、アプリの画面をキーボードの上の範囲に収め、再生エリア（小）を隠す（実機で分かったこと：WebView はキーボードが出ても画面の高さが変わらず、入力欄を上へ寄せると、見出しの行ごと画面の外へずれた）。入力欄を寄せるときは、中身の欄だけをスクロールする。
- 同じ部品（`TagInput`）を使う、一括操作のタグの入力欄と、プレイリストの編集の「タグの組み合わせ」の入力欄も同じになる。
- Windows は今のまま（`datalist`）。

### 全画面の再生で曲名を押したら、その曲の詳細を出す
- 今は、Windows と同じく、鳴らしている曲の行（一覧の行か、プレイリストの編集の項目）へ飛ぶ。
- Android では、全画面の再生の曲名を押すと、鳴らしている曲のファイルの詳細を開く。戻ると全画面の再生に戻る。
  - 一覧に出ている曲なら、その行を選んだのと同じ（一覧から鳴らしているならその行）。
  - 今の絞り込みで一覧に出ていない曲でも、詳細を出す（ライブラリから読む）。
- Windows の再生の欄の曲名は今のまま。

## やらないこと
- プレイリストを選ぶプルダウン（端末の選び肢の画面で出る）の作りの変更。
