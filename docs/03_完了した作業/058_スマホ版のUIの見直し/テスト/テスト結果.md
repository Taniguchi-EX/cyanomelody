## 実機（Android、デバッグ版）
確かめるため、デバッグ版のデータを控え、見本のフォルダを読み直して確かめた後、控えから元に戻した（フォルダとタグが前と同じであることを確かめた）。

- タグの入力欄
  - 入力欄を押すとキーボードが出て、アプリの画面がキーボードの上に収まり、再生エリアが隠れる。見出しの行（「← ファイルの詳細」）は残る。
  - 入力欄が中身の一番上に寄り、文字（「から」）を入れると、その下に候補（「前からある」「後から作った」）が並ぶ。入力欄には重ならない。
  - 候補を指と同じ操作で押すと、すぐにタグが付き、入力欄が空になる。キーボードは開いたまま、入力欄も選ばれたまま。
  - キーボードを閉じると、画面が元の大きさに戻り、再生エリアが出る。
- 全画面の再生の曲名
  - 一覧から鳴らした曲：曲名を押すと、その曲のファイルの詳細が開き、戻ると全画面の再生に戻る。
  - 検索で一覧に出ていない（1件だけの絞り込み）曲：曲名を押すと、その曲の詳細が出る。その詳細でタグを付けると、すぐに詳細にも出る（読み直しが効く）。

## 気づいたこと（今回の作業の外）
- 開発版のライブラリは、前の作業で使ったフォルダ（今はない・中身が変わった）を指していて、どの曲も読めず、再生ボタンを押すと一瞬で全曲が終わる。曲を読めないときに次々飛ばしてしまい、何も知らせないのは、利用者にも分かりにくい。
