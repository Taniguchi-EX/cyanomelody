# セルフレビュー

- Windows の動きは変えていない：タグの入力欄は Android のときだけ候補を自前で出す。再生の欄の曲名の動き（行へ飛ぶ）はそのまま。一覧に出ていないファイルの詳細は、Android の全画面の再生から開いたときだけ使う。
- 一覧に出ていないファイルの詳細は、行を選ぶ・すべて解除する・鳴らしている行へ飛ぶ、のどれでもやめる（`focusRow`）。一覧を読み直すたびにそのファイルも読み直し、ライブラリから外れていれば詳細から消える。読み直しの途中で別の行を選んだときは、古い結果で上書きしない。
- キーボードの判定は、見える範囲が画面より 120px 以上小さいとき。端末を回したときなども見える範囲に合わせるだけなので、困ることはない。
- 文書：`Androidの画面.md`（キーボードの間・詳細の開き方・全画面の再生・タグの入力欄）、`音声のタグ管理.md`、`再生.md` を直した。
