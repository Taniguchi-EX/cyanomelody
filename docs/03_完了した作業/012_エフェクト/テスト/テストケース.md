# テストケース

## 単体テスト（Rust）

`effects.rs`
- 音量調整、音量調整（自動）のピーク・平均（0dBFSを超えない）、無音は変えない
- 速度を変えると長さが変わり音程は変わらない（2倍・0.5倍）
- 音程を変えると音程が変わり長さは変わらない（+12・−12半音）。両方を変える
- リバーブ・エコーで残響の分だけ長くなり、元の音の後にも音がある
- フェードイン・フェードアウト。音より長いフェードでも壊れない
- 5つの形式を読める。WAVに書き出して読み戻せる。ないファイルはエラー
- 設定を範囲に収める
- 速さ（`effect_speed`、手動で実行）

`effect_cache.rs`
- 同じファイル・同じ設定なら同じ音を使い回し、設定が変わると別の音を作る
- 合計が上限を超えたら古いものから消す

`chains.rs`
- まとまりの作成・名前の一意・名前変更・中のエフェクトの保存（範囲に収める、並べ替え）・削除で項目から外れる・項目への結び付け

`playlists.rs`
- 入れ子のとき、内側の項目のまとまりから外側の順にかける。タグの組み合わせの曲にもかかる。直接再生したときは外側の項目のまとまりはかからない

## 画面テスト（Playwright、`app/e2e/effects.mjs`）
- E01：準備
- E02：まとまりを作ると選ばれ、エフェクトを加え・並べ替え・設定・保存できる。一覧の説明に中身が出る
- E03：同じ名前のまとまりは作れない
- E04：保存していない変更があるとき、閉じる前に確かめる（キャンセルで残る。捨てると元に戻る）
- E05：右の欄のファイルにかけて試聴できる
- E06：項目に結び付けると、その項目だけエフェクトのかかった音で再生される
- E07：まとまりの設定を変えると、別の音を作る
- E08：まとまりを削除すると、結び付けていた項目から外れる（確認に件数）
