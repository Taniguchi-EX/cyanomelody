# セルフレビュー

## 作業概要との突き合わせ

作業概要の仕様の項目ごとに確かめ、すべて実装されていた。
- 7つのエフェクトと設定（範囲の外の値は収めて保存する）
- エフェクトのまとまり：名前（一意）、中のエフェクトの追加・並べ替え・設定・削除（画面で並びを作り「保存」でまとめて保存）、削除（確認に結び付けている項目の数）
- 管理画面は左の欄のプレイリストの欄（「エフェクト」）から開く。右の欄のファイルで試聴できる（保存する前の並びで鳴らせる）
- 項目へのまとまりの結び付け（1つまで）。ファイル・タグの組み合わせ・プレイリストの項目のどれにも結び付けられる
- 入れ子のときは内側から外側の順にかける。そのプレイリスト（直接・親・参照）での再生だけで有効
- 再生：エフェクトのかかる曲は音を作ってから鳴らす（作っている間は「準備中…」）。作った音は使い回し、合計1GBを超えたら古いものから消す

## 見つけて直した問題

1. リバーブの処理に、意味のない書き方（`buf[i - 0]`）が残っていた。`buf[i]`に直した。
2. 管理画面でまとまりを作っても選ばれず、続けてエフェクトを加えるのに一手間かかった。作ったまとまりを選ぶようにした。
3. 保存していない変更があるまま、管理画面を閉じたり別のまとまりを選んだりすると、黙って捨てていた。捨ててよいか確かめるようにした。
4. 試作で使った`Audio::seconds`が、テストでしか使われていなかった（コンパイルの警告）。テスト用にした。

## 確かめて問題がなかった点

- エフェクトの処理は、データベースの錠を持たずに行う（設定を読んだら錠を外す）ので、処理中もほかの操作が止まらない。
- 作った音は、別の名前で書いてから名前を変えるので、書きかけのファイルを鳴らさない。
- 置き場所のファイル名は、元のファイルのパス・大きさ・更新日時と、エフェクトの設定から決めるので、元のファイルか設定が変わると作り直す。
- 再生の途中で別の曲に移ったときは、用意が終わった前の曲を鳴らさない。

## 気づいたが直さなかった点

- 管理画面を開いている間は、右の欄のファイルを選び直せない（重ねて表示しているため）。試聴するファイルは、管理画面を開く前にクリックしておく。「UIの改善」で扱う。
