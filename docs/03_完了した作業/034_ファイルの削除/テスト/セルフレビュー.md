# セルフレビュー

## 確かめたこと
- 完全に消す選択肢は、ごみ箱に移せなかったときの2つ目の確認でだけ出る。最初のダイアログからは完全に消せない。
- 削除のダイアログは、最初に「やめる」を選んでいる。Enter・Esc ではどちらも削除しない。
- ライブラリから外すのは、実際のファイルを消せた（または既に無かった）ファイルだけ。消せなかったファイルはライブラリに残り、タグなども消えない。
- リンク切れのファイルは対象にしない（ファイルの詳細ではボタンを押せず、一括操作の欄では除く）。
- 鳴らしているファイルを削除するときは、先に再生を止める（ファイルをつかんだままだと、ごみ箱に移せないため）。
- 画面テスト用の CYANOMELODY_TRASH_DIR と `_notrash` は、環境変数がないとき（普段のアプリ）は働かない。

## 気づいた問題と対応
- 作業の途中で、`e2e/run.sh` に環境変数を足す編集が失敗していたのに気づかず画面テストを流し、テスト用の音声ファイル4つ（d1.wav・d2.mp3・d3.flac・d4_notrash.wav。テストデータのチャイムのコピー）が、使っている PC の本物のごみ箱に移った。編集をやり直し、テストのファイルがごみ箱の代わりのフォルダに移ることを確かめた。ごみ箱の4つは消してよい。
  - 今後の対策：ごみ箱の代わりのフォルダは run.sh が渡すので、run.sh を通さずにアプリを起動して delete.mjs を流すと、同じことが起きる。delete.mjs の先頭のコメントに書いてある。
- 削除はファイルごとに順に行い、途中で失敗しても残りを続ける（失敗したものだけ2つ目の確認に回す）。

## 残したこと
- 削除の取り消し（ごみ箱から戻しても、タグなどは戻らない）。作業概要の「やらないこと」のとおり。
