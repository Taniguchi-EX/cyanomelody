# セルフレビュー

## 確かめたこと
- 再生の欄：右の列を「中身が収まる幅以上、かつ左と同じ割合（1fr）」にした。広いときは左右が同じ幅になり中央が真ん中、狭いときは右が中身の幅を保ったまま左が縮み、中央が左へずれる。1280・1000・860・760px で、「■」が右側に隠れないことを画面テストで確かめた。
- エフェクトセットの管理画面：横のスクロールバーの原因は、右の列（1fr）が、試聴のボタンの曲の名前（折り返さない文字）の長さまで広がることだった。列の最小幅を0にして、ボタンの中で「…」で省くようにした。幅も 900px から 1200px に広げた。
- ファイルの行のタグ：チップを折り返す箱に入れて高さを1行に固定し、2行目以降に回ったチップの数を「+N tags」に出す。箱の大きさが変わるたび（ウィンドウ・欄の幅の変更、「+N tags」が出て箱が縮んだとき）に数え直す。数え直しで「+N」の幅が変わっても、数が落ち着くまで繰り返すだけで、行の高さは変わらない。
- 一覧は見えている行だけを描画するので、大きさの監視は見えている行の数（数十）だけ。
- たたんだタグの一覧は position: fixed で出す（一覧のスクロールの枠で切れないように）。マウスのイベントを受けないので、行の操作（クリック・ドラッグ）を邪魔しない。
- 「+N tags」の文字は依頼の例のとおり英語にした。

## 気づいた問題と対応
- タグの欄の上限を行の幅の6割にしたところ、狭いときにファイル名が「chim…」までしか出なかった。半分に下げた。
- 画面テストで、上限を下げたらタグが広いときから1つしか出ず、狭めたときの違いを確かめられなくなった。タグの名前を短くした。また、1つのステップが失敗すると画面の大きさが戻らず次のステップも失敗したので、各ステップの最初に元の大きさに戻すようにした。
