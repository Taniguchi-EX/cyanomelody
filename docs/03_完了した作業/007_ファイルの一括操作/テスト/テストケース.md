# テストケース

## 単体テスト（Rust、`files.rs`）

- idでの絞り込み：指定したidのファイルだけになる（ないidは無視）。空の一覧なら0件。ほかの条件とはAND。4万件のidでも使える（SQLの引数の数の上限にかからない）
- チェックしたファイルの内訳：ライブラリにあるidだけを返す。見つからないファイルの数、タグごとの数（タグの一覧の順）、出典・ライセンスごとの数（「なし」を含む）。空なら空

## 画面テスト（Playwright、`app/e2e/bulk.mjs`）

- B01：チェックの件数は0件でも常に出て、一括操作の欄は出ない
- B02：行のクリックは1件の詳細の表示だけ。Ctrl・Shiftを押しながらクリックしても複数選択にならない
- B03：チェックボックスを押しても右の欄は変わらない。チェックすると一括操作の欄が出る
- B04：チェックは絞り込みの条件を変えても外れない（タグAで絞り込んでチェックし、タグBで絞り込んでチェックすると、両方残る）。表示中のうちの件数も出る
- B05：「チェックしたファイルだけ」はほかの条件とAND。「絞り込みを解除」で外れ、チェックは残る
- B06：見出しのチェックボックス。一部チェックのときは「－」の表示。押すと表示中をすべてチェックし、もう一度押すとすべて外す
- B07：Ctrl+Aで表示中をすべてチェックし、「チェックをすべて外す」で外れる。一括操作の欄も消える
- B08：表示していないファイルも含めて、チェックしたファイルすべてに一括でライセンスを設定する。確認に件数が出る
- B09：操作の後もチェックは残る。「タグを外す」の欄に、タグごとの件数（1/2など）が出る
- B10：確認で「キャンセル」を選ぶと、一括操作は行われない
- B11：見つからないファイルをチェックすると、一括操作の欄に件数と「ライブラリから外す」が出る。外したファイルはチェックからも外れる
- B12：移動したファイル（見つからないファイル）を、一括操作の欄からひも付け直せる。ひも付け直した元の記録はチェックからも外れる

## 回帰テスト

- `tag-management.mjs`、`tag-admin.mjs`、`hash-features.mjs`、`credits.mjs`、`tag-tree.mjs`を実行し、壊れていないことを確かめる。
- 複数選択（Ctrl・Shiftのクリック）を使っていたテストは、チェックと一括操作を使う形に直す（「テスト結果」を参照）。
