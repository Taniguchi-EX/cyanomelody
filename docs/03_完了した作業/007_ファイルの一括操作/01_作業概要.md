# ファイルの一括操作

## 目的

絞り込みの条件を変えながら、対象のファイルを少しずつ集め、まとめて操作できるようにする。
例：タグAで絞り込んで何件かチェックし、続けてタグBで絞り込んでさらにチェックし、チェックしたファイル全部にライセンスを設定する。

## 範囲

### やること
- ファイルの一覧の各行にチェックボックスを付ける
- チェックは、絞り込みの条件を変えても外れない
- チェックしたファイルをまとめて操作するボタン
- チェックしたファイルだけを表示する絞り込み
- 行のクリックを「1件の詳細を表示する」だけにし、Ctrl・Shiftでの複数選択をやめる（複数のファイルはチェックで扱う）

### やらないこと
- チェックの状態を、アプリを閉じた後まで覚えておくこと
- チェックしたファイルを、ファイルとしてコピー・移動・削除すること（元のファイルは変更しない方針のため）
- チェックしたファイルの一覧を書き出すこと

## 仕様

### チェックボックス
- ファイルの一覧の各行の右端にチェックボックスを付ける。
- チェックは、絞り込みの条件を変えても外れない。一覧に見えていないファイルのチェックも残る。
- 一覧の上に見出しの行を置き、右端（各行のチェックボックスと同じ列）に、表示中のファイルをすべてチェックするチェックボックスを置く。すべてチェック済みなら、押すと表示中のファイルのチェックを外す。
- 一覧にフォーカスがあるときにCtrl+Aを押すと、表示中のファイルをすべてチェックする（これまでの「すべて選ぶ」の代わり）。
- Shiftを押しながらチェックボックスを押すと、前に押したチェックボックスとの間をまとめて同じ状態にする。
- ライブラリから消えたファイル（フォルダの登録解除、見つからないファイルを外す、ひも付け直し）は、チェックからも外れる。

### チェックしている件数の表示
- チェックしている件数を、常にツールバーの件数の隣に出す。0件のときも「チェック 0件」と出す。
- 表示中のうちの件数も出す（例：「チェック 12件（表示中 5件）」）。
- 件数の隣に「チェックをすべて外す」ボタンを置く。
- ツールバーは一覧の上に固定されているので、一覧をスクロールしても見える。

### チェックしたファイルだけを表示
- ツールバーに「チェックしたファイルだけ」を置く。ほかの絞り込みの条件と組み合わせられる（AND）。
- 「絞り込みを解除」で外れる。チェック自体は外れない。

### 一括操作
- チェックしているファイルがあるとき、一覧の上に一括操作の欄を出す。
- 操作の対象は、チェックしたファイルすべて（表示中かどうかによらない）。
- 以下の操作ができる。
  - タグを付ける：タグの名前を入力して付ける（まだない名前なら作る。右の欄と同じ）
  - タグを外す：チェックしたファイルに付いているタグの中から選んで外す
  - 出典を設定・外す
  - ライセンスを設定・外す
  - ひも付け直す（チェックしたうちの見つからないファイルが対象。「ハッシュ値を使った機能」と同じ）
  - ライブラリから外す（チェックしたうちの見つからないファイルが対象）
- ひも付け直す・ライブラリから外すは、チェックしたファイルに見つからないファイルが含まれるときだけ出す（見つからないファイルの件数も出す）。
- 表示中でないファイルも対象になるので、操作の前に件数（「チェックした12件にタグ「雨」を付けますか？」）を出して確認する。
- 操作の後もチェックは外さない（続けて別の操作ができるように）。

### 行のクリック（詳細の表示）
- 行（チェックボックスと再生ボタン以外の部分）をクリックすると、そのファイル1件を右の欄に表示する。Ctrl・Shiftを押しながらのクリックも、同じく1件の表示になる（複数選択はしない）。
- 右の欄は、表示中の1件について、これまでどおり以下を表示・操作する。
  - パス、ハッシュ値、同じ音声のファイルを探す
  - タグの付け外し、出典・ライセンスの設定・解除
  - 見つからないファイルのときは、ひも付け直す・ライブラリから外す
- 右の欄で操作するのは、表示中の1件だけ。チェックしたファイルには影響しない。
- 右の欄に表示しているファイルが絞り込みで一覧から消えたときは、右の欄の表示も消える（これまでどおり）。
- チェックボックスを押しても、右の欄に表示するファイルは変わらない。
- 複数のファイルを対象にしていた右の欄の表示（タグが付いたファイルの数、出典・ライセンスの「（ばらばら）」）は、一括操作の欄に移す。

## データ

- データベースの変更はない。チェックの状態は画面の中だけで持つ。

## 試作で確かめること

- 特になし。数万件をすべてチェックしたときの操作の速さは、テストで確かめる。

## 仮決定した事項

- 一覧にフォーカスがあるときのCtrl+Aは、表示中のファイルをすべてチェックする操作にする。
- 一括操作の欄の「タグを外す」では、チェックしたファイルに付いているタグを、付いているファイルの数と一緒に出す。出典・ライセンスは、設定の内訳（「（ばらばら）」と件数）を出す。
- チェックの状態は、アプリを閉じると消える。
- 一括操作は、表示していないファイルも対象になるため、毎回件数を出して確認する。
- 操作の後もチェックは外さない。
- 一括操作の内容は、タグの付け外し、出典・ライセンスの設定・解除、見つからないファイルのひも付け直し・ライブラリから外す、にする（これまで複数選択でできた操作をすべて引き継ぐ）。
