# セルフレビュー

## 作業概要との突き合わせ

作業概要の仕様の項目ごとに確かめ、すべて実装されていた。
- 各項目（ファイル、タグの組み合わせ、プレイリスト）に別名を1つまで。前後の空白を除き、制御文字は不可、空にすると外れる
- 編集画面：別名を太字で出し、元の内容を小さく添える。「別名」ボタンで入力欄を出し、Enterで決定、Escでやめる
- 別名は項目に付くので、親・参照から再生しても使う。別のプレイリストの同じファイルには付かない
- タグの組み合わせ・プレイリストの項目の別名は表示名だけ（中のファイルには付かない）
- 再生の欄：ファイルの項目の別名を主に出し、ファイル名を添える
- ひも付け直しでは、項目のファイルだけが付け替わり、別名は残る（ファイルのidを書き換えるだけなので）

## 決めたこと

- 別名の入力欄からフォーカスが外れたときは、入力をやめる（決定しない）。決定はEnterだけ。
- 再生順の曲（展開の途中）を、ファイルのidだけでなく別名を持てる形（`Track`）にした。次の「エフェクト」の作業で、かけるエフェクトもここに持たせる。
