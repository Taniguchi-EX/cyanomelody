# テストケース

## 単体テスト（Rust、`playlists.rs`）
- 別名を付ける（前後の空白を除く）・制御文字はエラー・ない項目はエラー・空にすると外れる
- 親から再生しても別名が付く。タグの組み合わせから選ばれた曲には付かない。別のプレイリストの同じファイルには付かない

## 画面テスト（Playwright、`app/e2e/playlists.mjs`）
- P19：「別名」ボタンで入力し、Escでやめると変わらない。Enterで決定すると「別名（元の名前）」と出る。再生の欄にも「別名（ファイル名）」と出る。空にして決定すると外れる

## 回帰テスト
- すべての画面テストを実行する。
