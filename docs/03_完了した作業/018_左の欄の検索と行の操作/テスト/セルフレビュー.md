# セルフレビュー

## 仕様との食い違い
- なし。作業の前に確認した7点（あてはまらない行を隠す、ファイルの一覧は左の検索で絞り込まない、薄い親は押せる、親があてはまっても子は隠す、出典・ライセンスの並べ替え、詳細画面の✎🗑をなくす、行の並び）のとおり。登録したフォルダの並べ替えは、回答がなかったので行っていない（やらないことに書いた）。

## 不具合・境界値
- 検索の文字は、前後の空白を除き、小文字にしてから比べる。空白だけなら検索していない扱い。
- あてはまる行の祖先は、たどる途中で、すでに出すと決まった節に着いたら止める（あてはまる節は、それぞれ自分の祖先をたどるので、抜けはない）。
- 検索している間は開閉の印を出さないので、印を押して覚えている開閉の状態を変えてしまうことはない。検索の文字を消すと、元の開閉の状態で出る。
- 検索している間も、取っ手での並べ替え・ファイルの行のドラッグ・「✎」「🗑」はそのまま使える。
- 出典・ライセンスの並べ替えは、前・後ろ・最後だけ。Rust でも、子（Child）への移動と、ない id の前後への移動はエラーにする。自分自身の前後には落とせない。
- 出典・ライセンスを新しく作るとき（フォーム、右の欄で名前を入れたとき）は、最後に入る。今あるものは、移行で名前の順の番号を付けた。
- ファイルの行のドラッグ（タグ・出典・ライセンスを付ける）は、行にだけ落ちる。新しく足した「一覧の下の空いた所」には落ちない。
- プレイリストの名前の入力欄の中を押しても、行を押したこと（詳細画面を開く）にはならない。

## 既存の機能への影響
- ファイル名の検索は、左の欄から、ファイルの一覧の見出しの行に移った。条件のチップの名前のない「✕」で消えるのは今までどおり。
- 出典・ライセンスの並びが、名前の順から作った順（並べ替えた順）になった。右の欄の出典・ライセンスのプルダウンの並びも、左の欄と同じになる。
- 詳細画面から、名前の変更と削除がなくなった（左の欄の行で行う）。

## 書き方
- 検索欄は部品 `SearchBox`、木の検索は `tree.ts` の `searchNodes`、「なし」の行の件数をそろえる空きは `HandleSpace` にした。
- 並べ替えは、タグ・プレイリストと同じ `useTreeDrag` に「階層のない一覧」（flat）を足して使う。
