# セルフレビュー

## 仕様との突き合わせ
- 作業概要のとおり、チェックしたファイルがすべてリンク切れのときだけ、チェックの操作の行の右端に「⚠ リンク切れ N件」と3つのボタンを出す。

## 見つけて直した問題
- 「指定フォルダから自動で探す」を1件ずつ呼ぶと、そのたびにフォルダの中のファイルのハッシュ値を計算し直す。まとめて探す処理を加え、フォルダの中は1回だけ計算する（すべて見つかったら止める）ようにした。
- リンク切れの数を数え終える前にチェックが変わったとき、前のチェックの結果で出してしまわないよう、数えたときのチェックと今のチェックが同じときだけ出す。

## 不具合の確認
- 表示していないファイルも含めて判断する（数えるのはデータベースで行う）。
- 同じ音声の見つからないファイルが複数あるときは、どれも同じファイルにひも付ける（タグなどはまとめて移る）。
- ひも付けた・外したファイルはライブラリから消えるので、チェックからも外れる（残ったものだけで、また判断する）。
- 途中のひも付けで失敗したときは、それまでのひも付けは残り、エラーを出す。

## 見た目
- ウィンドウの幅が狭い（1280px で左右の欄があるとき）と、行に入りきらず、折り返した行の右端に出る。
