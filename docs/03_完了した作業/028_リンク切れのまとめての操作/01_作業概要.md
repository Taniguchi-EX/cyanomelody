# リンク切れのまとめての操作

## 目的
見つからない（リンク切れの）ファイルを、1件ずつでなく、チェックしたものをまとめて操作できるようにする。

## 範囲
- チェックしたファイルがすべてリンク切れのとき（1件以上）、ファイルの一覧の上のチェックの操作の行（「全てチェック」のある行）の右端に、リンク切れの操作のボタンを出す。
  - 表示していないファイルも含めて、チェックしたファイルすべてで判断する。リンク切れでないファイルが1件でも入っていれば出さない。
  - 先頭に「⚠ リンク切れ N件」と出す。
- ボタン（右の欄の1件の操作と同じ名前・動き。対象はチェックしたファイルすべて）
  - ひも付け直す：ライブラリの中から同じ音声のファイルを探して、タグなどを移す。結果（ひも付け直した件数、同じ音声がない・候補が複数・ハッシュ値がない件数）を出す。
  - 指定フォルダから自動で探す：フォルダを1回選び、その中から、それぞれと同じ音声のファイルを探してひも付ける（ライブラリの外なら、そのフォルダを登録する）。フォルダの中のファイルのハッシュ値は1回だけ計算する（すべて見つかったら、そこで止める）。結果（ひも付けた件数、見つからなかった件数、ハッシュ値がない件数）を出す。
  - ライブラリから外す：確かめてから、チェックしたファイルをライブラリから外す（付けたタグなども消える）。
- 「ファイルを紐づける」（1件のファイルを選ぶ）は、1件ずつの操作なので右の欄だけに置く。

## やらないこと
- リンク切れでないファイルが混ざっているときに、リンク切れのものだけを操作すること。
