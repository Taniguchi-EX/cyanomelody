# 選んだファイルの情報の書き出し

状態：完了（2026-11-10）

## 目的
一括操作の対象（チェックしたファイル）のメタデータを、ファイルに書き出せるようにする（ユーザーの依頼。小さな作業）。

## 範囲
- 一括操作の欄に「情報を書き出す…」を置く。保存先を選ぶと書き出す。
- 形式は、データのエクスポートと同じ JSON にする（設定画面の「データ」で取り込め、タグ付けのスキル cyanomelody-tagging でもそのまま使えるように）。
  - 項目は「タグ」と「出典・ライセンス」。曲は対象のファイルだけで、タグ付け・出典・ライセンスはその分だけ。タグ・出典・ライセンスの定義はすべて入れる。
  - プレイリスト・エフェクト・設定は入れない。
  - 見るための情報として、曲名・長さ・リリース年・見つからない印を曲に足す（取り込みでは使わない）。

## 決めたこと（ユーザーに確認せずに決めた所）
- 形式は JSON（データのエクスポートと同じ形）。CSV は作らない。
- 中身は上のとおり。足りないもの（アーティスト・アルバムなど、ファイルの中の情報）があれば、後で足す。
