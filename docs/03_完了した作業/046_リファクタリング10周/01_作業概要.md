# リファクタリング10周

状態：完了（2026-11-10）

## 目的
機能を変えずに、コードの分け方・整合性・保守性・性能・共通化・不要なコード・コメントを良くする（ユーザーの依頼）。

## 進め方
- スキル `refactor-loops`（`~/.claude/skills/refactor-loops/SKILL.md`）の手順で、10周回す。
- 各周は「レビュー → 実装 → テスト」の順。周ごとに違う観点を選ぶ。
- 機能（画面の動き・データの形・保存する値）は変えない。変わってしまうものは見送り、記録する。
- 周ごとに `テスト/リファクタリングの記録.md` に書き、コミットする。最後に check.sh all と perf を流す。
