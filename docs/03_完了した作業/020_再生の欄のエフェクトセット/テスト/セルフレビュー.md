# セルフレビュー

## 仕様との対応
- 再生の欄のプルダウン、アプリを閉じても覚える、再生する曲すべてにかける、項目のエフェクトがある曲ではそちらだけ・グレーアウト：実装済み（画面テスト E12）。
- 鳴らしている間に選び直すと、同じ位置から鳴らし直す：実装済み（setBaseChain → playAt に位置を渡す）。

## 確かめたこと
- 曲にかけるエフェクトセットは、曲を鳴らし始めるとき（playAt）に決める。エフェクトをかけている間（準備中）に選び直したときは、最初から鳴らし直す（位置がまだないため）。
- 鳴らし直しでは「直近で再生したもの」に二重に記録しない（onPlayed は新しい曲のときだけ）。
- 選んでいたエフェクトセットを削除したとき：今あるエフェクトセットに含まれないidは選んでいないことにする（覚えている値は消さないが、同じidが作り直されることはない）。エフェクトセットの一覧を読む前に曲を鳴らしたときも、選んでいないことになる。
- エフェクトの管理画面の試聴（previewPath）と、プレイリストの書き出しには影響しない。
- 項目のエフェクトがかかる曲でも、プルダウンは選び直せる（グレーアウトは見た目だけ）。選び直しても、その曲は鳴らし直さない。

## 残したこと
- 一時停止中に選び直すと、鳴らし直して再生が始まる。選び直すのは聞きながらのことが多いので、このままにする。
