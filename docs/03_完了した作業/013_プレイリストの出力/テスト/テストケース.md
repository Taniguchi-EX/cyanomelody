# テストケース

## 単体テスト（Rust）

`playlists.rs`
- 書き出す内容：別名、見つからないファイルの項目（入れておく）、「順に再生」の子のプレイリストは中の階層をフォルダに、外側の項目のまとまりが中のファイルすべてにかかる、シャッフルの項目は中の階層を開いて並べる

`export.rs`
- 名前の置き換え（使えない文字、末尾の空白と「.」、空）、順番の数字（3桁、1000件以上で桁を増やす）、同じ名前のフォルダに「 (2)」「 (3)」
- 書き出し：プレイリストの名前のフォルダ、別名と順番の数字、子のプレイリストのフォルダ。エフェクトのない曲はそのままコピー（中身が同じ）、ある曲はWAV（読み直せる）。もう一度書き出すと別のフォルダ。書き出し先がないとエラー

## 画面テスト（Playwright、`app/e2e/export.mjs`）
- X01：準備（別名、子のプレイリスト、子の項目に結び付けたエフェクト）
- X02：書き出すと、階層がフォルダになり、別名と順番の数字が名前に付く。エフェクトのない曲はそのままコピー、ある曲はWAV。終わったら件数と書き出し先が出る
- X03：同じ場所にもう一度書き出すと、別のフォルダを作る
- X04：書き出し先のフォルダがないときは、エラーを出して始めない

## 回帰テスト
- すべての画面テストを実行する。
