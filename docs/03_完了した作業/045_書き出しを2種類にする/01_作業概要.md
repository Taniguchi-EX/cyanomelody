# 書き出しを2種類にする

状態：完了（2026-11-10）

## 目的
一括操作とプレイリストの書出に、「ファイルをまとめて書出」と「メタデータを書き出し」の2種類を用意する（ユーザーの依頼）。

## 範囲
- 一括操作の欄の「書き出し」
  - 「ファイルをまとめて書出…」（新しく作る）：フォルダを選ぶと、その中に `cyanomelody-files-YYYYMMDD` のフォルダを作り、対象のファイルをそのままコピーする。名前は元のまま、重なるときは「名前 (2).wav」。見つからないファイルは「書き出せなかった」に数える。進み具合・中止・結果の出し方は、プレイリストの書出と同じ（同時に1つだけ）。
  - 「メタデータを書き出し…」（作業43の「情報を書き出す…」の名前を変えた）
- プレイリストの編集画面の一番下の行
  - 「ファイルをまとめて書出」（今の「書出」の名前を変えた）
  - 「メタデータを書き出し…」（新しく作る）：中央の一覧に出ている曲（同じ曲は1回）のメタデータを、作業43と同じ形の JSON に書き出す。保存先の名前の初期値はプレイリストの名前。

## 決めたこと（ユーザーに確認せずに決めた所）
- 一括操作の「ファイルをまとめて書出」は、エフェクトをかけず、フォルダも分けない（フラットにコピー）。
- 作るフォルダの名前は `cyanomelody-files-YYYYMMDD`。
