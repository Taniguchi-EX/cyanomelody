# テストケース

## 単体テスト（Rust）

`app/src-tauri`で`cargo test`を実行する。

- db：マイグレーションを2回実行しても壊れない
- library
  - 対象の拡張子を、大文字・小文字を区別せずに判定する
  - 登録済みのフォルダ自体・その中のフォルダ・その親フォルダは登録できない
  - 名前の先頭が同じだけの隣のフォルダ（`se`と`se2`）は登録できる
  - 存在しないフォルダは登録できない
  - スキャンで追加・印付け・印外しができ、2回目のスキャンでは何も変わらない
  - 登録したフォルダ自体がないときはエラーにし、中のファイルに印を付けない
  - 登録を解除するとファイルの情報が消え、実際のファイルは残る
  - 3万ファイルのスキャン時間（`--ignored`を付けたときだけ実行）
- files
  - 一覧は相対パスの順に並び、絶対パスが正しい
  - ファイル名の絞り込みは大文字・小文字を区別せず、`%`と`_`を普通の文字として扱う
  - タグの付け外し、件数、AND・タグなしでの絞り込み、大文字・小文字の違いは同じタグ
  - 空や制御文字を含むタグ名は付けられない
  - 見つからないファイルはタグを残したまま一覧に出て、ライブラリから外せる。印のないファイルは外れない

## 画面テスト（Playwright）

`app/e2e/tag-management.mjs`で自動実行する。手順はスクリプトの先頭を参照。

- T01：フォルダを登録すると、スキャンして5つの形式のファイルが取り込まれる
- T02：登録済みのフォルダの中のフォルダは登録できない
- T03：存在しないフォルダは登録できない
- T04：5つの形式（FLAC、MP3、OGG、WAV、M4A）を試聴・停止できる
- T05：複数のファイルを選んでタグを付けられる（新しいタグを作る）
- T06：大文字・小文字が違うだけのタグ名は同じタグになる
- T07：複数のタグで絞り込むと、すべてのタグが付いたファイルだけになる（AND）
- T08：タグなしのファイルだけに絞り込める
- T09：ファイル名の一部で絞り込める（大文字・小文字を区別しない）
- T10：選んだファイルからタグを外せる
- T11：Shiftで範囲選択できる
- T12：見つからなくなったファイルに印が付き、タグは残り、再生できない
- T13：見つからないファイルだけに絞り込める
- T14：同じ場所に戻すと印が外れる
- T15：見つからないファイルをライブラリから外せる
- T16：3万ファイルのフォルダを登録・表示・スクロール・絞り込みできる
- T17：3万件を全選択（Ctrl+A）してタグを付けられる
- T18：フォルダの登録を解除すると、ファイルとタグの情報が消え、実際のファイルは残る
- T19：空のタグ名では付けられない
