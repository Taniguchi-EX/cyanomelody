# 表示と書き出しの改善

状態：完了（2026-11-10）

## 目的
画面を見ながらユーザーが出した、表示と操作の細かい改善の依頼をまとめて行う（v1.2.0 で公開）。

## 範囲
- 中央の一覧
  - 見せ方の切り替えを1つのボタンに（一覧の絵・グリッドの絵）
  - グリッド：上に曲名、真ん中にジャケット（ないときはタグ）、下の段に再生ボタン・来た項目・fx・印とチェック。横の数は設定で決め、間は欄の幅に合わせる
  - 来た項目のアイコンを枠にちょうど収める
  - プレイリストを選んでいるとき、エフェクトがかかる行に「fx」のアイコン（説明にエフェクトセットの名前、押すと編集画面のその行の fx のプルダウンを開く）。来た項目のない行は左に詰める
  - 行のタグ：幅を測って入る分だけ出し、「+N tags」との間に余白を残さない（出すかどうかの判定も、幅を測って決める）
  - 見出しの行が狭いときは、並び順 → ファイル名の検索 → 見出しの順に縮める
- 配置：条件のチップを左の欄の一番下に、チェックの操作の行を一覧の下に移す。作業44の「押した行の位置を保つ」はいらなくなったので外した
- 設定画面
  - 「表示」タブ：文字の大きさ、フォント（インストールされているフォントから）、グリッドの横の数、拡張子を省く
  - 「一般」タブ：戻す・進める秒数
- 再生の欄：一定秒数戻す・進めるボタン（シークバーの左端の上）
- プレイリストの編集画面
  - 書き出しの名前を「ファイル」「メタデータ」に。「ファイル」は押すとすぐフォルダを選ぶダイアログ（一括操作と同じ。書き出し先の入力欄はなくした）
  - 書き出しの対象を、チェックした項目（なければすべて）にし、🎲・🔀の項目は書き出すときに抽選し直す
  - 別名を付けた項目の横に、本来の名前を薄く小さく出す
  - 「まとめて外す」を「プレイリストから外す」に
- 一括操作の欄の書き出しの名前も「ファイル」「メタデータ」に

## 決めたこと（ユーザーに確認せずに決めた所）
- fx のアイコンを押したときに開くのは、その曲が来た直下の項目の fx のプルダウン（中のプレイリストにだけ fx があるときも、直下の項目のもの）。
- メタデータの書き出しも、ファイルの書き出しと同じ対象（チェックした項目）にし、そのときに抽選し直す。
- 戻す・進める秒数は1〜600秒（最初は10秒）。画面の設定として持つ（データのエクスポートの画面の設定に入る）。
- タグが1つも入らないほど狭いときは、最初のタグを「…」で省いて出す。
