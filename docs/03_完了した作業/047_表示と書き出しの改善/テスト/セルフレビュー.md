# セルフレビュー

- 書き出しの抽選し直しは、中央の一覧の抽選した並び（temp.draw_rows）を変えない。`draw_items` は展開だけを行い、一時テーブルに書かない。
- `plan_rows`（中央の一覧の行から書き出す内容を作る）はテストだけで使うので `#[cfg(test)]` にし、本体は `plan_tracks` に寄せた。
- 行のタグは、行（親の要素）の幅の変化だけを見て測り直す（タグの欄そのものを見ると、出すタグで幅が変わって測り直しが続くため）。測るときはすべてのタグを縮めずに並べ、「+N tags」の幅は React が中身を持たない測る用のチップで測る。
- 画面テストのダイアログの差し替え（window.__dialogReply）は、テストにつないだアプリにだけ効く。確認でテスト版につないだ後は、つながずに起動し直す（つないだままだとダイアログがキャンセル扱いになる）。
