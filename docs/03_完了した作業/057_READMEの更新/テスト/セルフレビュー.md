# セルフレビュー

## 観点と結果
- 作業概要のとおりか：古くなった記述（プレイリスト・再生の欄・エフェクト）を直し、加える機能（グリッド・一括操作・ファイルの情報からのタグ付け・シノニム・長さとリリース年・削除・設定画面・エクスポートとインポート）を各1〜3行で加えた。導入方法を Windows 版と Android 版に分け、Android のインストール・アップデート・アンインストールを移した。
- 今の画面・文書との食い違い：次を見つけて直した。
  - README で、条件のチップを「左の欄の上」と書いていた。今の画面は左の欄の一番下（写真でも一番下）なので直した。`音声のタグ管理.md` にも「検索の欄の下」と古い記述が残っていたので、あわせて直した。
  - インポートの操作を「インポート…」と書いていた。今の画面は「ファイルを選ぶ…」→「取り込む」なので直した。
  - `アプリの概要.md` の「Android は配布していない」、`Androidの画面.md` の「自動アップデートの確認もしない」は、今の状態に合わないので直した。
- 写真の個人の情報：Windows の写真のパスは見本の場所（`E:\tmp\見本`）だけ。Android の写真は、ステータスバー（通知のアイコン・時刻）を切り抜いた。
- 太字の書式を使っていないこと、位置づけ（大まかな使い方）を超える細かい決まりを書いていないことを確かめた。
