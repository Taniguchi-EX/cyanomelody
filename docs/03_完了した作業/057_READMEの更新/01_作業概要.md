# README の更新

状態：完了（2026-11-11）。

## 目的
利用者向けの README（リポジトリの一番上の `README.md`）は v1.0.0 のときに書いたもので、その後に加わった機能や変わった操作が入っていない。スクリーンショットも v1.0.0 の画面のまま。今の版（v1.3.1）に合わせて書き直し、スクリーンショットを撮り直す。

## 位置づけ（変えないこと）
- 利用者が、入れ方と大まかな使い方を知るための文書。細かい決まりは書かない（細かいことは `docs/01_現在の機能/` にある）。
- 章立て（特徴・動作環境・導入方法・Android 版・大まかな操作方法・データの保存場所・ライセンス）は今のままにする。
- ただし「導入方法」は Windows 版と Android 版（スマホ）に分け、今「Android 版」の章にあるインストール・アップデート・アンインストールを「導入方法」の Android 版へ移す（ユーザーの指示）。「Android 版」の章には、Windows のデータの写し方と、Windows 版との違い・画面の大まかな使い方を残す。

## 直すこと

### 古くなった記述
- プレイリスト
  - 左の欄でプレイリストを押すと、抽選した曲の並びが中央の一覧に出ること（「抽選」「選び直すと抽選し直す」）。
  - 編集画面の操作（タグの入力欄でタグを並べて「タグの組み合わせを追加」、「プレイリストを追加」、「▶ 再生」）。
  - 書き出し：編集画面の一番下の「ファイル」と「メタデータ」（今の README は「ファイルをまとめて書出」）。
- 再生の欄：「戻す」「進める」のボタン、再生方法の記号（① ⇒ 🔀 🎲）、右端の歯車で設定画面を開くこと。
- エフェクト：再生の欄のプルダウンからもエフェクトセットを作れること（「新しいfxを作る」「このfxを編集」）。

### 加える機能（各1〜3行）
- 一覧の見せ方（一覧・グリッド。グリッドでは曲の中の画像をジャケットとして出す）。
- チェックしたファイルへの一括操作（右の欄の「一括操作」でタグの付け外しなど）。
- ファイルの中の情報（アーティスト・アルバム・ジャンル・作曲者）からのタグ付け。
- タグのシノニム（別の名前でも探せる）。
- 長さ・リリース年での絞り込み。
- ファイルの削除（Windows のごみ箱へ移す）。
- 設定画面（文字の大きさ・フォント、グリッドの横の数、データのエクスポート・インポート、使っているライブラリのライセンス）。
- データのバックアップ・別の PC への移し替え（エクスポート・インポート）。

### スクリーンショット
- 撮り直すもの（Windows、今の撮影の仕組み `app/e2e/readme-shots.sh` で撮る）
  - ライブラリの画面（タグで絞り込み、1曲を選んで再生中）。
  - プレイリストの画面：プレイリストを選んで、中央の一覧に抽選した並び（来た項目と fx のアイコン）が出ている所。編集画面を重ねると中央の一覧が隠れるので、編集画面はエフェクトの画面の後ろに写す。
  - エフェクトの画面（エフェクトセットの管理画面）。
- 加えるもの（ユーザーの確認済み）
  - Android 版の画面を1枚（ファイルの一覧と再生エリア）。デバッグ版に見本の効果音を入れて撮り、ステータスバー（通知・時刻など）は切り抜く。撮る手順は自動にはせず、手で撮る（見本の作り方だけ `readme-shots.sh` と同じにする）。
