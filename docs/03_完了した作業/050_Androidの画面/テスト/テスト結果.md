  - 絞り込み → プレイリストの「⋮」→「編集」→ プレイリストの編集 → 戻る ×2 → 一覧（1回の戻る操作で1つずつ戻る）。
  - 一覧で長押し → チェック → 「一括操作」→ 一括操作 → 戻る → チェックしている一覧 → 戻る → 一覧（チェックは外れる）。
  - 再生エリア（小）を押す → 全画面の再生 → 戻る・下へのスワイプで閉じる。
  - 設定を開く → 戻る操作でも「閉じる」でも閉じ、その後の戻る操作も1つずつ戻る。
  - 一覧で戻る操作 → アプリが閉じる。
- 指での操作
