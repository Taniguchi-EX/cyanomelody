# 画面のレイアウト

`01-01_画面遷移.md` で決めた画面ごとの、中身の並び。配置図は縦向きのスマートフォン（画面の幅は約 410 の CSS ピクセル）を想定した目安。
決めたことは、最後の「決めたこと」にまとめる。

## 共通の決まり

- 押す所の大きさ：指で押しやすいよう、ボタン・行の高さは 44 ピクセル以上にする（Windows より大きい）。
- セーフエリア：端末のステータスバー（上）とナビゲーションバー（下）の分を空ける。
- 文字の大きさ・フォント・拡張子を省くかは、設定画面の「表示」のとおり（Windows と同じ設定）。
- 配色：Windows と同じ（端末がダークモードなら暗い配色）。
- 見出しの行：画面の一番上。スクロールしても残す。高さは1行。
- マウスを乗せたときに出していた説明（title）は、指では見られないので、要る説明は画面に出すか、長押しで出す。
- Android で使えない操作（ファイルの削除・エクスプローラーで見せる・ファイルを1つ選んでのひも付け・自動アップデート・データの入出力・フォントの一覧）は出さない。

## ファイルの一覧（アプリを開いたとき）

```
┌──────────────────────────────────┐
│ ライブラリ              [🔍] [⏷²]│ ← 見出し、ファイル名の検索、切り替え（漏斗。条件の数）
├──────────────────────────────────┤
│ 並び：パス順 ▾          [▦]      │ ← 並び順と、見せ方（一覧・グリッド）
├──────────────────────────────────┤
│ ▶ 雨_土砂降り.mp3                 │ ← 行は1段：名前だけ（タグはファイルの詳細で見る）
├──────────────────────────────────┤
│ ▶ 📃 fx 足音_砂利.wav             │ ← プレイリストを選んでいるときは、来た項目と fx のアイコン
├──────────────────────────────────┤
│ ……                               │
├──────────────────────────────────┤
│ 再生エリア（小）                   │
└──────────────────────────────────┘
```

- 見出し：ライブラリかプレイリストの名前（長ければ「…」）。
- ファイル名の検索：「🔍」を押すと、見出しの行が検索の欄に変わる（「×」で閉じると、見出しに戻り、検索の文字を消す）。
- 切り替えのボタン（漏斗）：右端。選んでいる条件があれば、その数を添える。
- 並び順と見せ方：見出しの下の行。一覧ではこの行もスクロールで隠れる（見出しの行だけ残す）。
- 行（一覧）：1段で、名前だけを出す（狭いので、タグは出さない。タグはファイルの詳細で見る）。
  - 再生ボタン、（プレイリストを選んでいるとき）来た項目・fx のアイコン、見つからない印、名前。
  - 行を押すと、ファイルの詳細へ。行の再生ボタンで、その行から再生する。
  - 行を長押しすると、チェックを始める（チェックの操作の形へ）。
- グリッド：横に並べる数は、画面の幅に合わせて2〜3（設定の「グリッドの横の数」は使わない）。タイルの中は Windows と同じ。

### チェックしているとき

```
┌──────────────────────────────────┐
│ ✕  3件をチェック        [全て]   │ ← チェックをやめる、件数、表示中をすべてチェック
├──────────────────────────────────┤
│ ☑ 雨_土砂降り.mp3                 │ ← 再生ボタンの代わりにチェックボックス
│ ☐ 足音_砂利.wav                   │    行を押すと、チェックを付け外し
│ ……                               │
├──────────────────────────────────┤
│ [チェックしたものだけ] [一括操作] │ ← チェックの操作の行（Windows と同じ並び）
├──────────────────────────────────┤
│ 再生エリア（小）                   │
└──────────────────────────────────┘
```

- 長押しで始め、見出しの行の「✕」か、端末の戻る操作で終わる（チェックはすべて外れる）。
- 「一括操作」で、一括操作の画面へ。

## 絞り込み

```
┌──────────────────────────────────┐
│ 絞り込み            [⚙] [☰124]  │ ← 設定、切り替え（一覧の絵。今の条件の件数）
├──────────────────────────────────┤
│ [ 検索（タグ・プレイリスト…）   ] │
├──────────────────────────────────┤
│ ▼ ライブラリ                  ＋  │
│   Music/効果音          44  ⟳ ✕  │
│ ▼ タグ                        ＋  │
│   ▼ 雨                   12   ⋮  │ ← 「⋮」で ✎（詳細）・🗑（削除）。長押しでドラッグ
│       屋外                3   ⋮  │
│ ▼ プレイリスト                ＋  │
│   森の探索シーン          8   ⋮  │ ← ⋮ で ✎（編集の画面）・🗑
│ ▶ 出典                        ＋  │
│ ▶ ライセンス                  ＋  │
│ ▼ その他                         │
│   ⧉ 重複しているファイル      0   │
│   ……                             │
├──────────────────────────────────┤
│ 📃森の探索シーン ✕  🏷雨 ✕   ✕   │ ← 選んでいる条件のチップ（一番下に残す。Windows と同じ）
├──────────────────────────────────┤
│ 再生エリア（小）                   │
└──────────────────────────────────┘
```

- 中身と並びは、Windows の左の欄と同じ（欄をたためる、件数、グレーアウト、チップ）。
- 各行の「✎」「🗑」（Windows ではマウスを乗せたときだけ出す）は、行の右端の「⋮」（押すと「詳細・編集」「削除」の選び肢）にまとめる。
- 名前を押すと絞り込む。プレイリストを押したときだけ、選んで（抽選して）一覧へ移る。
- 行の並べ替え・親の変更は、行を長押ししてからドラッグする（落とす位置の決まりは Windows と同じ）。

## ファイルの詳細

```
┌──────────────────────────────────┐
│ ←  ファイルの詳細                 │
├──────────────────────────────────┤
│ 土砂降り                          │ ← 曲名（なければ拡張子を除いたファイル名）
│ Music/効果音/雨_土砂降り.mp3      │ ← 場所（押せない）
│ [▶ 再生]                          │
├──────────────────────────────────┤
│ ▼ タグ                        2   │
│   [ タグを入力              ]      │
│   🏷雨 ✕  🏷屋外 ✕                 │
│   [ファイルの情報からタグを付ける] │
│ ▼ プレイリスト                1   │
│   📃森の探索シーン ✕               │
│   [ プレイリストに追加 ▾     ]     │
│ ▼ 出典 / ライセンス               │
│ ▼ ハッシュ値                      │
│   [同じ音声のファイルを探す]       │
├──────────────────────────────────┤
│ 再生エリア（小）                   │
└──────────────────────────────────┘
```

- 中身と並びは、Windows の右の欄（ファイルの詳細）と同じ。ただし、Android で使えない操作（エクスプローラーで見せる・ファイルを紐づける・ファイルを削除する）は出さない。
- 見つからないファイルでは、Windows と同じく「⚠ 見つからないファイル」の欄（ひも付け直す・ライブラリから外す・フォルダから探す）を出す。
- 「▶ 再生」を加える（一覧に戻らずに聞けるように）。

## 一括操作

```
┌──────────────────────────────────┐
│ ←  一括操作（3件）                │
├──────────────────────────────────┤
│ ▼ タグ                            │
│   [ 付けるタグ              ]      │
│   🏷雨 3 ✕  🏷屋外 1 ✕             │
│   [ファイルの情報からタグを付ける] │
│ ▼ プレイリスト                    │
│ ▼ 出典 / ライセンス               │
│ ⚠ リンク切れ 1件（あるときだけ）   │
├──────────────────────────────────┤
│ 再生エリア（小）                   │
└──────────────────────────────────┘
```

- 中身と並びは、Windows の一括操作の欄と同じ。Android で使えない操作（書き出し・ファイルを削除する）は出さない。
- 戻ると、チェックしている一覧へ戻る（チェックは残す）。

## プレイリストの編集

```
┌──────────────────────────────────┐
│ ←  森の探索シーン           [✎]  │ ← 名前と、名前を変える
├──────────────────────────────────┤
│ [▶ 再生]                          │
├──────────────────────────────────┤
│ ♪ 環境音/森の朝.flac        ⋮ ☐ │ ← 1段目：種類の記号（押すと再生）、内容、⋮、チェック
│   fx：新しいエフェクトセット ▾    │ ← 2段目：（再生方法と件数）、fx
├──────────────────────────────────┤
│ ↪ 足音集                      ⋮  │
│   🔀シャッフル ▾ 2件  fx：なし ▾  │
├──────────────────────────────────┤
│ ……                               │
│ [ タグの組み合わせを追加 ]         │ ← 項目を加える（Windows と同じ）
│ [ プレイリストを追加 ▾ ]           │
├──────────────────────────────────┤
│ 再生エリア（小）                   │
└──────────────────────────────────┘
```

- 項目の行は2段にする（1段目：種類の記号・内容（別名と本来の名前）・「⋮」、2段目：再生方法と件数・fx のプルダウン）。
- 「⋮」の選び肢：プレイリスト上での名前を付ける、外す。
- 並べ替えは、行を長押ししてからドラッグする。
- チェックは、行の右端のチェックボックスで行う（Windows と同じ。長押しはドラッグに使うため）。チェックしているときは、チェックの件数と「全てチェック」「プレイリストから外す」を出す。
- 書き出し（ファイル・メタデータ）は出さない（Android で使えない）。

## 再生エリア（小）

```
├──────────────────────────────────┤
│▔▔▔▔▔▔▔▔▔▔▔▔▔                     │ ← 進み具合（細い線）
│ 土砂降り                 [▶] [⏭] │ ← 曲の名前（2行目に再生しているもの）、再生・次へ
│ 森の探索シーン 3/12               │
└──────────────────────────────────┘
```

- 何も再生していないときも出す。「▶」で、表示中の一覧を再生する（Windows と同じ）。
- ボタンのない所を押すと、全画面の再生を開く。

## 全画面の再生

```
┌──────────────────────────────────┐
│ ↓                                 │ ← 閉じる（下へのスワイプ・戻るでも閉じる）
│                                   │
│        ┌────────────┐            │
│        │ ジャケット │            │ ← ジャケット（ないときは出さない）
│        └────────────┘            │
│ 土砂降り                          │ ← 曲の名前（押すと、鳴らしている曲へ）
│ 環境音/雨_土砂降り.mp3            │
│ 森の探索シーン 3/12               │
│ ━━━━━━━━●──────────────          │ ← シークバー
│ 0:41                         2:10 │
│   ↺      ⏮     ▶     ⏭      ↻    │ ← 戻す、前へ、再生、次へ、進める
│   ⇒                          ■    │ ← 再生方法、停止
│ fx：[なし ▾]                      │
│ 🔊 ━━━━━━━━━━━●                   │ ← 音量
└──────────────────────────────────┘
```

- 中身は、Windows の再生の欄の全部（設定の歯車を除く）。ボタンは大きくする。
- ジャケットを出す（グリッドと同じく、ファイルの中の画像）。

## 重ねて出す画面

- タグの詳細、出典・ライセンスの編集、エフェクトセットの管理、設定、確認のダイアログは、Windows と同じ中身を、画面いっぱいに広げて出す（左右の余白を小さくする）。
- 設定画面のタブは、狭いので横にスクロールできるようにする。「データ」のタブは出さない（データの入出力は Android で使えない）。

## 決めたこと

- 一覧の行は1段で、名前だけを出す（タグはファイルの詳細で見る）。
- ファイル名の検索は、「🔍」を押すと見出しの行が検索の欄に変わる形にする。
- 行の操作（✎・🗑・別名・外す）は、行の右端の「⋮」の選び肢にまとめる。
- 並べ替え（絞り込みのタグ・プレイリスト・出典・ライセンスの行、プレイリストの編集の項目）は、行を長押ししてからドラッグする。
  - そのため、プレイリストの編集のチェックは、長押しではなく行の右端のチェックボックスで行う。ファイルの一覧は並べ替えがないので、長押しでチェックを始める。
- ファイルの詳細に「▶ 再生」を加える。
- 全画面の再生に、ジャケットを出す（ないときは出さない）。
- 再生エリア（小）のボタンは「▶」「⏭」の2つ。
