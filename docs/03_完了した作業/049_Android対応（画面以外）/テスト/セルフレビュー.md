# セルフレビュー

- 仕様との突き合わせ：作業概要の「範囲」の 1〜3 をすべて実装した。データの入出力・SAF への書き込み・画面は、作業概要のとおり行っていない。
- 見つけて直したもの
  - Android のフォルダの登録で、登録済みのフォルダとの重なり（同じ・中・外側）を確かめていなかった（同じファイルを二重に取り込めた）。フォルダの場所の名前（「primary:Music/効果音」）で比べるようにし、単体テストを足した。
  - 「フォルダから探す」（Android）で、ライブラリ全体から同じ音声のファイルを探していた（同じ音声のファイルが他にあると「候補が複数」になる）。Windows と同じく、選んだフォルダの中だけを候補にした（`hashing::relink_in`）。
  - 一覧の SQL に列（uri）を足したとき、列の番号が1つずれたままの所があった（単体テストで見つけた）。
- 既存の機能への影響：Windows のパスのフォルダは、場所の種類が `path`（既定）で、これまでと同じ処理を通る。ファイルを読む処理は、パスでも `FileSource` として同じに動く（単体テスト 133件）。
- 気を付けること（本実装の続き・同期の作業で扱う）
  - データのエクスポートは、Android のフォルダのファイルのパスを正しく書けない（フォルダの URI と相対パスをつないだものになる）。データの入出力は「Androidとの同期機能」で決める。
  - Android のフォルダのスキャンは、データベースを使ったままフォルダの中をたどる（Windows と同じ）。とても大きなフォルダや、クラウドのフォルダでは時間がかかるおそれがある。
  - デバッグ版の APK は約450MB（デバッグ情報を含む）。配布用の版では外す。
