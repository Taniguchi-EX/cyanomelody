# スマホ版のUIの手直し

状態：完了（2026-11-10）。

## 目的
作業50で作った Android の画面の、見た目の気になる所を直す。

## 範囲
- 再生エリア（小）の再生・一時停止・次へのボタンが文字（絵文字のように見える）なので、図形の絵にする。
- 全画面の再生で、中身を画面の下に詰める（閉じる「↓」は左上に残す）。中央の「▶／⏸」の絵を丸の大きさに合わせる。
- ファイルの詳細の見出しの行の「▶ 再生」をなくす。
- 見せ方（一覧・グリッド）の切り替えのボタンの枠と絵の大きさを合わせる。
- ホーム画面のアイコンが Tauri の絵のままなので、アプリの絵にする。

## 作り方
- 再生・一時停止・次への絵は `components/Icons.tsx` にまとめ、Windows の再生の欄（`PlayerBar`）も同じ部品を使う（絵は今までと同じなので、Windows の見た目は変わらない）。
- 全画面の再生・切り替えのボタン・中央の絵の大きさは、`mobile/mobile.css` だけで直す。
- アイコンは `npx tauri icon` で作った Android 用の画像を `gen/android` の `res` に写す。アダプティブアイコンは丸に切り抜かれて絵がはみ出したので、前景の周りを 20% 空ける。

## やらないこと
- Windows の画面の変更。全画面の再生の ⏮⏭■ は Windows と共通の文字のまま（絵文字ではなく、形も整っている）。
