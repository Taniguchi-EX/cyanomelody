# セルフレビュー

- Windows の画面：`PlayerBar` の「▶／⏸」は、同じ形の絵を `Icons.tsx` から使うようにしただけで、大きさ（14px）も変えていない。⏮⏭ には手を入れていない。CSS の変更は `.m-app`・`.m-full`・`.m-toolbar` の中だけ。
- ファイルの詳細の「▶ 再生」をなくしたので、使わなくなった `focusedFile` を `MobileApp` から外した。テストの中で `m-detail-play` を使っている所はない。
- 全画面の再生：「↓」を絶対位置にしたので、中身が少ない端末でも「↓」は左上に残り、中身は下に詰まる。中身が画面より長いときは、今までどおりスクロールでき、下へのスワイプで閉じる処理（一番上までスクロールしているとき）も変わらない。
- アイコン：前景の絵は余白なしで作られるので、`inset` で 20% 空けた。Android 8 より前（アダプティブアイコンがない）は `mipmap-*/ic_launcher.png` を使う。
