# デバッグ版の名前とアイコン

状態：完了（2026-11-11）。

## 目的
同じ端末に入れた配布する版（`dev.cyanomelody.app`）と開発用のデバッグ版（`dev.cyanomelody.app.debug`）は、名前もアイコンも同じで見分けられなかった（作業55の試験の後、配布する版のつもりでデバッグ版を開いてしまった）。デバッグ版だけ、名前とアイコンを変える。

## 範囲（ユーザーの指示）
- 名前：「cyanomelody 開発版」。
- アイコン：ユーザーが用意した絵（オレンジの羽根。`app/android/icon-debug.png`）。
- 作り：Android のビルドの仕組みで、`app/src-tauri/gen/android/app/src/debug/res` に置いた名前（`values/strings.xml`）とアイコン（`mipmap-*`）が、デバッグ版にだけ上書きされる。配布する版（`src/main/res`）は変えない。アイコンの作りは配布する版と同じ（透明な前景と、白い背景のアダプティブアイコン）。

## やらないこと
- Windows のデバッグ版の名前とアイコン。
