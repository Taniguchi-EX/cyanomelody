# セルフレビュー

テストの前に、実装を作業概要と突き合わせ、コードを見直した。

## 作業概要との突き合わせ

作業概要の仕様の項目ごとに確かめ、すべて実装されていた。
- 出典・ライセンスの共通の項目（名前・URL・メモ）と、名前の決まり
- ライセンスの種類（9つと「独自」）と、5つの条項（可・不可・不明の3つのボタン、最初は不明）
- 種類を選んだときの条項の自動設定とグレーアウト、「独自」に戻したときの条項の引き継ぎ、名前が空のときの種類の名前の入力
- 種類が「独自」以外の条項を、保存した値ではなく定義から決めること
- 右の欄での設定・解除、「（ばらばら）」と件数の表示、URL・メモ・種類・条項の表示、URLをブラウザで開くこと
- 右の欄で作ったライセンスが「独自」・条項はすべて不明になること
- 左の欄の3つの欄のたたみ、たたんだ状態の記憶、選んでいる条件の数の表示、最初はすべて開いた状態
- 絞り込み（出典どうし・ライセンスどうしはOR、「なし」とは同時に選べない、ほかの条件とはAND、「絞り込みを解除」で外れる）
- 管理画面の一覧・作成・編集・削除、同じ名前のエラー、削除で絞り込みの条件を外すこと
- ひも付け直しで出典・ライセンスを移すこと（移す先の設定を優先）

## 見つけて直した問題

1. 管理画面で編集中の出典・ライセンスを削除すると、フォームが編集中のまま残り、「保存」で「見つかりません」のエラーになる。
   - 編集中のものを、idから一覧を引いて決めるようにした。一覧から消えたら、編集をやめた扱い（作成のフォーム）になる。
2. フォルダの登録解除と、見つからないファイルを外すときの確認の文言が、タグが消えることしか書いていなかった。
   - 「付けたタグ・出典・ライセンスの設定」が消えると書くようにした。

## 実装中に直した点（画面の確認で見つけたもの）

- 左の欄の見出しに選んでいる数を「1件を選択中」と出すと、見出しが2行に折り返した。数だけの表示（マウスを乗せると「1件を選択中」）にし、管理のボタンを「管理」に短くした（読み上げ用の名前は「タグを管理」などのまま）。
- 右の欄の「出典」の見出しが、上の「付いているタグ」に詰まって見えた。余白を加えた。

## 確かめて問題がなかった点

- 既存のデータベースへの変更（migration 3）は、列の追加とテーブルの作成だけで、既存のデータを書き換えない。
- 出典・ライセンスを削除すると、ファイルの設定は外部キーの`ON DELETE SET NULL`で「なし」になる（単体テストで確認）。
- フォルダの登録解除や見つからないファイルを外す処理は、ファイルの行を消すので、設定も一緒に消える。出典・ライセンス自体は残る。
- 「タグを管理」のボタンの表示を「管理」に変えたが、読み上げ用の名前は変えていないので、既存の画面テストはそのまま使える。
- 名前の決まりは、タグと同じ関数（`normalize_name`）を使っている。

## 気づいたが直さなかった点

- 右の欄の入力欄は、選ぶファイルを変えても入力中の文字が残る。タグの入力欄と同じ動きなので、そろえてそのままにした。
- URLの形式は確かめない。`http://`か`https://`で始まるときだけリンクにし、それ以外は文字として表示する。
