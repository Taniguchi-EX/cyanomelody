# テストケース

## 単体テスト（Rust）

`credits.rs`
- 一般的なライセンスの種類の条項に「不明」がない
- 出典の作成：前後の空白を除く。大文字・小文字の違いだけの同じ名前や空の名前は作れない。出典に種類・条項を渡しても無視する。出典とライセンスは同じ名前でも別のもの
- ライセンスの条項：種類を選んだときは種類の条項、「独自」のときは入力した条項になる。不明な種類はエラー。「独自」に戻すと入力した条項になる
- 種類が「独自」以外のときは、保存した条項を書き換えても定義の条項が返る
- 編集：別の既存の名前にはできない。自分の大文字・小文字だけの変更はできる。存在しないものの編集はエラー
- ファイルへの設定：まだない名前なら「独自」・条項はすべて不明で作る。既存の名前（大文字・小文字は区別しない）なら作らずに設定する。設定済みなら置き換える。外せる。空の名前はエラー
- 削除：設定されていたファイルは「なし」になり、ファイル自体は残る

`files.rs`
- 出典での絞り込み（1つ、複数でOR）、「出典なし」、ライセンスとの組み合わせ（AND）、「ライセンスなし」
- ファイルの一覧に出典・ライセンスのidが入る

`hashing.rs`
- ひも付け直しで、移す先に設定がない出典・ライセンスは移り、設定がある出典は移す先のものが残る

## 画面テスト（Playwright、`app/e2e/credits.mjs`）

- C01：準備。左の欄に「タグ」「出典」「ライセンス」の3つの欄が開いた状態で並び、「（出典なし）」「（ライセンスなし）」がある
- C02：出典を作成できる（名前・URL・メモ）。出典には種類の欄がない。左の欄にも出る
- C03：同じ名前（大文字・小文字の違いを含む）の出典は作れない
- C04：ライセンスの作成フォームは、最初は種類が「独自」、条項はすべて「不明」で、選べる
- C05：種類を選ぶと条項が自動で設定されてグレーアウトし、空の名前に種類の名前が入る。名前が入っていれば種類を変えても名前は変わらない。一覧に種類と短い条項が出る
- C06：種類が「独自」のライセンスは、条項を自由に選べる。選ばなかった条項は不明（「？」）
- C07：編集で種類を「独自」に戻すと、条項はそのままで選べるようになる。名前と条項の変更を保存できる
- C08：編集で別の既存の名前にはできない
- C09：選んだファイル（複数）に出典を設定できる（既存の名前は大文字・小文字を区別しない）。URL・メモが出る。左の欄の件数が増える
- C10：まだない名前のライセンスを設定すると、種類は「独自」、条項はすべて不明で作られる
- C11：設定が違うファイルを選ぶと「（ばらばら）」と設定ごとの件数が出て、URLなどの詳細は出ない
- C12：設定済みのファイルに設定すると置き換わる
- C13：絞り込み。出典どうしはOR、「（出典なし）」を選ぶと出典の選択が外れる、ライセンスとはAND
- C14：見出しを押すと欄がたたまれ、選んでいる条件の数が見出しに出る。たたんだ状態は再読み込み後も残る
- C15：「絞り込みを解除」で出典・ライセンスの条件も外れる
- C16：「外す」で選んだファイルの出典がすべて外れる。ライセンスは外れない
- C17：ライセンスを削除すると、設定されていたファイルは「なし」になり、絞り込みの条件からも外れる
- C18：管理画面で編集中のライセンスを削除すると、フォームが作成に戻る
- C19：右の欄のURLを押すとブラウザで開き、エラーが出ない
