# 簡易オフボーカル

## 目的
エフェクトに「簡易オフボーカル」を加え、曲の真ん中から聞こえるボーカルを、処理の軽い方法で弱める（カラオケのような音にする）。

## 範囲

### エフェクト
- 名前：簡易オフボーカル（kind：offVocal）。エフェクトの管理画面の「追加するエフェクト」に加える。
- 設定
  | 設定 | 範囲 | 最初の値 |
  |---|---|---|
  | 消す強さ | 0〜100% | 100% |
  | 下の周波数 | 50〜500 Hz | 120 Hz |
  | 上の周波数 | 2,000〜16,000 Hz | 9,000 Hz |
- 一覧での短い表示：「簡易オフボーカル 100% 120Hz〜9000Hz」。

### 処理（左右の差と、ボーカルの音域の抑制）
1. 左右の音を、真ん中（M = (L+R)/2）と左右の差（S = (L−R)/2）に分ける。
2. M を、Linkwitz-Riley（4次）のクロスオーバーで、下の周波数より低い音・下〜上の周波数の音（ボーカルの音域）・上の周波数より高い音に分ける。
3. 真ん中のボーカルの音域だけを、消す強さの分だけ弱める：M′ = 低い音 + 高い音 + (1 − 強さ) × ボーカルの音域。
4. S にも同じクロスオーバーをかけて足し戻す（位相をそろえて、ステレオの広がりを崩さない）。
5. 左右に戻す：L = M′ + S′、R = M′ − S′。
- 1標本ずつのフィルターだけで行う（重い分析や AI は使わない）。
- 音域の上下が逆（下の周波数 ≧ 上の周波数）にならないよう、範囲で収める。

### モノラルの音
- 左右が1つ（モノラル）の音では、ボーカルだけを選べないので、何もしない（そのまま通す）。
- 管理画面のエフェクトの行に、「モノラルの音にはかかりません」と出す（マウスを乗せたときの説明）。
- 左右が3つ以上の音は、最初の2つを左右として扱い、残りはそのまま。

### 限界（「01_現在の機能」に書く）
- 真ん中にある楽器（スネア、ベースの倍音、ギターのソロなど）も、ボーカルの音域の分は一緒に弱まる。
- 左右に広げたボーカル・ハモり・ボーカルのリバーブは残る。
- 強く圧縮された MP3 などでは、うっすら残ることがある。

## やらないこと
- 音を分析してボーカルだけを取り出す方法（AI による音源の分離など）。
- ボーカルだけを残す（オンボーカル）こと。

## 未決事項
- なし（名前、設定の3つ、モノラルでは何もしない、で確認をもらった）。
