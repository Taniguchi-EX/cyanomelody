# セルフレビュー

## 仕様との突き合わせ
- 作業概要のとおり、簡易オフボーカル（消す強さ・下の周波数・上の周波数）を加えた。モノラルの音にはかけず、エフェクトの名前の説明にそのことを出す。

## 見つけて直した問題
- 最初の作りは、M と S をそれぞれ3つの帯域（低い音には上の分け目の位相のずれも付ける）に分けて足し戻していて、2次のフィルタを24回通していた。5分の曲で約2.5秒かかり、リバーブより重かった。
  - 3つに分けて足し戻したものは、2つの分け目の全域通過フィルタを続けてかけたものと同じになる（Linkwitz-Riley の性質）。そこで M′ = 全域通過(M) − 強さ × ボーカルの音域、S′ = 全域通過(S) とし、フィルタを8回に減らした。
  - 途中の配列を作らずに1標本ずつ処理するようにした。5分の曲で約0.2秒（12倍速く）になった。単体テストの結果は変わらない。
- 上の周波数が標本化周波数に近いと、フィルタが崩れる。ナイキスト周波数の 0.45 倍までに収めた（22.05kHz の音などのため）。

## 不具合の確認
- 強さ 0% では大きさが変わらない（位相だけずれる）。真ん中の 1kHz は 5% 未満に弱まり、左右の差の音・真ん中の 60Hz・14kHz は残る（単体テストで確認）。
- 長さは変わらない。無音や長さ0の音でも壊れない（長さ0はそのまま返す）。
- 範囲の外の設定は収める（下の周波数 50〜500Hz、上の周波数 2,000〜16,000Hz なので、下が上を超えることはない）。

## 既存の機能への影響
- エフェクトの種類が1つ増えただけで、ほかのエフェクトの処理は変えていない。データベースの形も変わらない（エフェクトは JSON で持つ）。
