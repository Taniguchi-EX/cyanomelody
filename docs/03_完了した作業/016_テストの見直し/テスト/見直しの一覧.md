# 画面テストの見直しの一覧

画面テストを1件ずつ見て、次のどれかに決めた。
- 残す：画面にしかない動き（ドラッグ、表示の切り替え、入力欄・ダイアログ、記号、グレーアウト、再生の欄など）か、機能の主な流れ
- まとめる：同じ画面の流れを細切れに確かめているもの。「→ どこへ」に書いた1件にまとめる
- 消す：同じことを単体テストで確かめていて、画面は結果を出すだけのもの。（）に、その単体テストを書く
- 性能：3万件のフォルダを使うもの。新しい `perf.mjs` に移し、普段は流さない

## perf（性能、新しく作る）

- T16・T17・P17・H10 を移す。3万件のフォルダを1回だけ登録し、表示・スクロール、すべてチェックしてタグ、タグの組み合わせの再生、ハッシュ値の計算の中止と続き、を測る。
- 一覧・スキャン・絞り込み・ハッシュ値の計算・プレイリストの展開を変えたときだけ流す。
