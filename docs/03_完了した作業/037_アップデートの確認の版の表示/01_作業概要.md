# アップデートの確認の版の表示

## 目的
アップデートの確認で、今の版と新しい版を見比べられるようにし、それぞれの変更点（リリースノート）をすぐ見られるようにする。

## 範囲
- アップデートの確認のダイアログの「新たなバージョンが公開されました。アプリをアップデートしますか？」の下に、次の2行を出す（番号はその時の版）。
  - 現在：1.1.2
  - 最新：1.1.6
- 版の番号は、GitHub のその版の Release のページ（リリースノート。`https://github.com/Taniguchi-EX/cyanomelody/releases/tag/v1.1.6` など）へのリンクにする。押すとブラウザで開く。
- これまで出していた「v1.1.6」の行は、上の2行に置き換える。

## 画面テストのための仕組み
- アップデートの確認は開発用のビルドでは行わないため、画面テストでダイアログを出せない。
- 開発用のビルドでだけ、環境変数 CYANOMELODY_FAKE_UPDATE に版（例：9.9.9）があれば、その版が見つかったことにする（「はい」で入れることはできない）。
- run.sh は、画面テスト update.mjs のときだけ、この環境変数を渡す。
