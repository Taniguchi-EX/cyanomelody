# セルフレビュー

## 仕様と食い違うところ
- 作業概要の範囲（名前の表示・「内側 → 外側」・「…」で省く・説明に理由と名前・かからない曲で元に戻る・選び直せる）は、すべて実装した。

## 不具合がないか
- 項目のエフェクトセットがすべて削除されていたとき（id はあるが一覧にない）：名前が空になる。→ 「項目の fx」と出すように直した。実際には、削除すると項目の fx は外れるので、鳴らし始めた後に削除したときだけ起きる。
- 表示用の選び肢を選んだ状態で、ほかの選び肢を選んだとき：`onChange` は表示用の値を無視し、ほかは今どおり動く。今「選んでいる」エフェクトセットを選び直したときも `onBaseChain` が呼ばれるが、項目のエフェクトがかかる曲では鳴らし直さない（`setBaseChain` が項目の fx を見て戻る）ので、影響はない。
- 表示用の選び肢は `disabled hidden` なので、開いた一覧には出ず、キーボードでも選べない。
- 「準備中…」の間も、鳴らす曲（`queue[index]`）は決まっているので、同じ表示になる。
- エフェクトの管理画面の試聴（`previewFile`）は、再生の順番の曲ではないので、表示は変わらない（今どおり）。

## 既存の機能を壊していないか
- 項目のエフェクトがかからないときは、選び肢も `value` も今と同じ。E12・E13 の選び肢の並びの確かめも通る。

## 書き方
- 管理画面を開く選び肢（`NEW_FX`・`EDIT_FX`）と同じ形で、`ITEM_FX` を定数にした。
