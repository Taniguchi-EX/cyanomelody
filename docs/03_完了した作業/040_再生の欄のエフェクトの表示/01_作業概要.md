# 再生の欄のエフェクトの表示

状態：完了（2026-11-10）

## 目的
今は、プレイリストの項目のエフェクトセットがかかる曲を鳴らしているとき、再生の欄のエフェクトセットのプルダウンがグレーアウトするだけで、何がかかっているかが見えない。かかっているエフェクトセットを再生の欄に出す。

## 範囲
- プレイリストの項目のエフェクトセットがかかる曲を鳴らしている間は、再生の欄のエフェクトセットのプルダウンをグレーアウトしたまま、表示を項目で設定したエフェクトセットの名前に変える。
  - 入れ子で複数かかるときは、内側から外側の順に「洞窟の響き → 全体を小さく」と並べる。
  - 幅に収まらないときは「…」で省く。省いていても、マウスを乗せたときの説明には全部の名前を出す。
- マウスを乗せると、理由を出す（今の「この曲には、プレイリストの項目のエフェクトをかけています」に、かけているエフェクトセットの名前を足す）。
- 項目のエフェクトがかからない曲のときは、今までどおり再生の欄で選んだものを出す。
- グレーアウトしていても押して選び直せる、という今の動きは変えない。開いた一覧では、今までどおり再生の欄で選んでいるものに印が付く。選び直したものは、項目のエフェクトがかからない曲から効く（今と同じ）。

## 作り方の想定
- 再生の順番の各曲は、かけるエフェクトセットの id を内側から外側の順に持っている（`PlayEntry.chains`）。名前はエフェクトセットの一覧から引く。
- プルダウン（`select`）の見た目のまま名前を差し替える方法として、項目のエフェクトがかかっている間だけ、先頭に表示用の選び肢（項目のエフェクトセットの名前。選べない）を足して、それを選んだ状態に見せる。選び直したときの動きは今と同じにする。
- 「準備中…」の間（エフェクトをかけた音を作っている間）も、同じ表示にする。

## やらないこと
- ファイルの一覧の行に、エフェクトがかかることを示す印を付けること
- 再生の欄で選んだエフェクトセットと、項目のエフェクトセットを重ねてかけること（今の決まりのまま、項目の方だけをかける）

## テスト
- effects の画面テストに、項目のエフェクトがかかる曲を鳴らしている間のプルダウンの表示（名前・グレーアウト・説明）と、かからない曲に移ったときに元に戻ることを加える。
- 表示のための選び肢を足しても、選び直し（別のエフェクトセット・「fx なし」・「新しいfxを作る」・「このfxを編集」）が今どおり効くことも確かめる。
- 資料「エフェクト」の「再生の欄のエフェクトセット」に反映する。
