# リリース年での絞り込み

## 目的
ファイルの中の情報のリリース年を読み、「その他」の「長さ」と同じように、年の範囲でファイルの一覧を絞り込めるようにする。

## 範囲

### リリース年を調べる
- ファイルの中の情報の年を読む。項目は、日付（MP3 の TYER・TDRC、Vorbis コメントの DATE・YEAR、WAV の INFO の ICRD など）→ リリース日（TDRL）→ 元のリリース日（TDOR・TORY）の順に、最初に年が読めたもの。
- 値から年を取り出す：「2006」「2026-04-14」「20160219」「2016/02/19」のように、先頭の4桁の数字を年とする（1000〜2999 のときだけ）。読めなければ「年なし」。
- 長さと同じく、ハッシュ値の計算と一緒に裏で調べて保存する。ファイルが変わったとき（サイズか更新日時）は調べ直す。
  - この版に上げた後は、ライブラリを一度スキャン（⟳）するまで年が入らない（長さを加えたときと同じ。ハッシュ値も計算し直すが、値は変わらない）。

### 絞り込み
- 「その他」の「長さ」の行の下に、「リリース年」の行を置く。年の入力欄（4桁の数字。最初は空）と「以上」「以下」のボタン（その年を含む）。
  - 入力欄が4桁の年（1000〜2999）でないときは、ボタンを押せない（入力欄の枠を赤くする）。
  - 「以上」を押すと「その年以上（その年を含む）」、「以下」を押すと「その年以下（その年を含む）」の条件を加える。それぞれ1つまでで、押し直すと置き換わる。両方を加えると「その間」。押した後も入力欄の値は残す。
- 条件は、ほかの条件とANDで組み合わせる。年を調べていないファイル・年のないファイルは、年の条件があるときは出さない。
- 条件のチップ：「📅 2010年以上」「📅 2019年以下」のように出し、「✕」でその条件を外す。すべての条件を外す「✕」でも外れる。
- 「その他」の見出しの選んでいる数に、年の条件の数も入れる。ほかの項目の件数（選んだときの件数）にも効く。

## やらないこと
- ファイルの一覧や右の欄に年を出すこと。年の順に並べること。
- 年をタグにすること。

## データ
- audio_files に release_year（年。読めなければ NULL）と release_year_done（調べたら1）を加える（マイグレーション13）。

## 未決事項
- なし（ボタンは、その年を含むことが分かるよう「以上」「以下」。読む項目は日付 → リリース日 → 元のリリース日の順）。
