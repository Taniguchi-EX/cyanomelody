## Android（実機）
- 公開用の鍵で署名したリリース版（約30MB）を手元の Docker で作り、`apksigner` で証明書が公開用の鍵のものであることを確かめた。実機に入れて起動できた。最新の Release（v1.2.0）には APK がないので、更新のダイアログは出ない（正しい）。
- 試作（使い捨ての鍵のリリース版）で、cyanomelody 用のフォルダの設定・取り込み・再生がリリース版でも動くことを確かめた（`03_試作の結果.md`）。
- アプリの中からのダウンロードとインストールの画面は、試作（デバッグ版）で確かめた（`03_試作の結果.md`）。本実装の、GitHub の Release を読む所は、APK の付いた次の版を公開したときに確かめる。

## GitHub Actions
- 最初の実行では、Android の段階が SDK を入れる手順（android-actions/setup-android）で失敗した。手元の Docker の環境と同じやり方（コマンドラインツールを落として sdkmanager で入れる）に変えた。
- 直したワークフローを、タグ v1.3.0 を指定した手動実行で流し、build-windows と build-android がどちらも成功した（約14分）。
  - 失敗した実行の「Re-run」は、タグの時点のワークフロー（直す前）で動くので使えない。手動実行（Run workflow）は main のワークフローで、タグのコードをビルドする。
- 公開した v1.3.0 の Release に、インストーラ・署名・`latest.json`・`cyanomelody_1.3.0_android-arm64.apk`（約30MB）が付いていることを、GitHub の API で確かめた。`latest.json` は 1.3.0 のインストーラを指している。
- Release の APK を実機に入れられた（ユーザーが確かめた）。

## 公開した後の確認（v1.3.1）
- v1.3.1 を公開した後、実機の配布する版（1.3.0）を開くと新しい版のお知らせが出て、アプリの中からのダウンロードとインストールで 1.3.1 に更新できた（ユーザーが確かめた。2026-11-11）。GitHub の最新の Release から APK を見つける所も、本番で動いた。
