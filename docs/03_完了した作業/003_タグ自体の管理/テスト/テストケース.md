# テストケース

## 単体テスト（Rust、`tags.rs`）

- 作成：前後の空白を除いて作る。大文字・小文字の違いだけを含む同じ名前や、空の名前は作れない
- 名前変更：新しい名前や、大文字・小文字だけの変更ができる。付いているファイルは変わらない
- 統合：既存のタグと同じ名前にすると、統合を指定したときだけ統合する。両方付いていたファイルは統合先が1つ付く
- 存在しないタグの名前変更・削除はエラーになる
- 削除：ファイルから外れ、ファイル自体は残る
- 使われていないタグの一括削除：見つからないファイルに付いているタグは消さない

## 画面テスト（Playwright、`app/e2e/tag-admin.mjs`）

- A01：準備（フォルダを登録し、タグを付ける）
- A02：「タグを管理」で管理画面が開き、タグとファイル数が出る
- A03：ファイルに付けずにタグを作れる
- A04：同じ名前（大文字・小文字の違いだけを含む）のタグは作れない
- A05：タグの名前を変えられる
- A06：大文字・小文字だけを変える名前変更ができ、一覧のタグ表示にも反映される
- A07：既存のタグと同じ名前にすると統合でき、絞り込みの条件も統合先に置き換わる
- A08：タグを削除すると、ファイルから外れ、絞り込みの条件からも外れる
- A09：使われていないタグをまとめて削除できる
- A10：空の名前には変えられない
