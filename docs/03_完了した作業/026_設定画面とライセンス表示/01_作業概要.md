# 設定画面とライセンス表示

## 目的
- アプリの設定画面を作る。まずは「一般」（新しく作るタグの既定値）と「バージョンとライセンス」の2つのタブ。
- アプリに組み込んでいるライブラリのライセンスを、アプリの中で見られるようにする（MIT・Apache-2.0 などが求める著作権とライセンスの表示、MPL-2.0 が求めるソースコードの入手先の表示）。

## 範囲

### 設定画面
- 再生の欄の右端（音量のバーの右）に歯車（⚙）のボタンを置き、押すと設定画面を開く（左端は曲名を出すので、右端にした）。
- 設定画面は、メインの画面に重ねて出すダイアログ。上にタブ（「一般」「バージョンとライセンス」）を並べ、押したタブの中身を出す。最初は「一般」で、次に開くときは前に開いていたタブを出す。
- 「閉じる」か Esc で閉じる。

### 一般タブ
- 「新しく作るタグ」の既定値を決める。タグの詳細画面で決めるものと同じ。
  - 子のタグの並び順（親の設定を引き継ぐ・ドラッグで決めた順・登録順・ファイル数順・ローマ字順）と昇順・降順。最初は「親の設定を引き継ぐ」（今と同じ）。
  - 背景色・文字色（「色を付ける」のチェックと色。付けなければ親の色を引き継ぐ）。最初は付けない（今と同じ）。
- 変えるとすぐに保存する（保存のボタンは置かない）。
- 既定値は、どこでタグを作ったとき（左の欄の「＋」、右の欄やチェックの操作で、まだない名前を入れたとき）にも使う。今あるタグは変わらない。
- 既定値は、データベースに保存する（タグを作るのはアプリの内部の処理なので）。

### バージョンとライセンス
- アプリの名前と版（v1.0.0 など）、アプリ自体のライセンス（MIT）と、GitHub のリポジトリへのリンクを出す。
- 使っているライブラリの一覧を出す。
  - 対象：配布するアプリに組み込まれるもの。Rust のライブラリ（Windows 向けのビルドで使うもの）と、画面の JavaScript のライブラリ。開発やテストにだけ使うものは除く。
  - 各ライブラリ：名前、版、ライセンスの種類（SPDX の表記）、配布元（リポジトリの URL）。押すと、ライセンスの文章（そのライブラリに入っている LICENSE・COPYING・NOTICE などのファイル）を開いて見られる。
  - MPL-2.0 を含むものは、「ソースコードは配布元から入手できます」と配布元を出す（改変はしていない）。
  - ライブラリ名で絞り込める検索の欄を置く（300件ほどあるため）。
  - SQLite（パブリックドメイン）のように、ライブラリの中に別に組み込まれているものは、そのライブラリのライセンスの文章に含まれる範囲で出す。
- 一覧は、ビルドするたびに自動で作り直す（依存が変わっても、作り忘れないように）。
  - Rust は `cargo metadata` で、Windows 向けのビルドで実際に使うライブラリをたどり、各ライブラリのフォルダにあるライセンスのファイルを読む。
  - JavaScript は `npm ls --omit=dev` で、配布に入るライブラリをたどる。
  - 同じ文章のライセンス（Apache-2.0 の本文など）は1つにまとめて、大きさを抑える。
  - ライセンスのファイルが見つからないライブラリは、ライセンスの種類と配布元だけを出す。

## やらないこと
- 一般タブの、タグの既定値のほかの設定（後で加える）。
- インストーラーへのライセンスの一覧の同梱（アプリの中で見られるので）。

## データ
- settings テーブル（key・value）を加える（マイグレーション12）。新しいタグの既定値は key "new_tag" に JSON で持つ。
