# テスト結果

`bash check.sh all`（単体テスト・型チェック・lint・性能以外の画面テスト）：1件失敗（F12）。テストの期待値の誤り（テストデータの m4a は「サブフォルダ/チャイム.m4a」で、ファイル名順では最後になる）だったので期待値を直し、facets を流し直して成功。その後、タグの詳細画面の昇順・降順の表示を直し、tags を流し直して成功。`bash check.sh perf`：すべて成功。

## 単体テスト
- 100件成功
- 追加：tags の child_sort_inherits_from_ancestors（引き継ぎ、昇順・降順も引き継ぐ、自分で決めればそちら）、files の sort_orders（各並び順、長さのないファイルは最後、ファイル名はフォルダを除く、直近で再生したものでは使わない）
- 直した：tags の child_sort_orders_only_direct_children（孫の親を「ドラッグで決めた順」にしてから確かめる）

## 画面テスト
- tag-management 15件、tags 16件、hash-features 9件、credits 12件、bulk 10件、facets 8件、playlists 26件、effects 11件、export 4件
- 追加
  - T03：作ったタグは「親の設定を引き継ぐ」、親の順（降順も）で並ぶ、今の順を横に出す、昇順・降順は選べない
  - F12：並び順のプルダウンの位置、各並び順、再読み込み後も残る、すべての条件を外しても戻らない
  - E13：再生の欄から「新しいfxを作る」で作ると再生の欄で選ばれる、「このfxを編集」、試聴は鳴らしている曲
  - P33：曲名からプレイリストの項目の行・ライブラリの行へ飛ぶ、絞り込みで出ていないときは知らせる、鳴らしていないときは押せない、直近で再生したものでは並び順を選べない
- 直した：F11（1つの入力欄。最初は 00:00:00、「分:秒」「秒」、全角、形の違う文字）、E12（プルダウンの選び肢）
