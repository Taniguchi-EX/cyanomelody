# UIの調整

## 目的
再生の欄・タグの詳細画面・「その他」の長さ・ライブラリの一覧を、使いやすく調整する。

## 範囲

### 1. 再生の欄のエフェクトセットから管理画面を開く
- 再生の欄のエフェクトセットのプルダウンに、プレイリストの項目の fx と同じく「新しいfxを作る」「このfxを編集」（エフェクトセットを選んでいるときだけ）を加える。
- 「新しいfxを作る」：管理画面を、保存していない新しいエフェクトセットで開く。作ったエフェクトセットは、再生の欄のエフェクトセットに選ぶ。
- 「このfxを編集」：管理画面を、選んでいるエフェクトセットで開く。
- 管理画面の試聴は、鳴らしている曲（試聴中のファイルを含む）でする。何も鳴らしていなければ試聴できない。

### 2. 再生の欄の曲名から、鳴らしている曲へ飛ぶ
- 再生の欄の曲名を押すと、鳴らしている曲を中央の欄に出す。何も鳴らしていないときは押せない。
- プレイリストを再生しているとき：そのプレイリストを中央に開き、鳴らしている曲を出している項目の行までスクロールして、その行を右の欄に出す（項目を押したときと同じ）。
- ライブラリの一覧から再生しているとき・試聴のとき：ライブラリを中央に出し、そのファイルの行までスクロールして右の欄に出す。
  - 今の絞り込みでそのファイルが一覧に出ていないときは、そのことを下の行に出す（絞り込みは変えない）。
- プレイリストが削除されていたら、ライブラリの一覧の方で探す。

### 3. タグの並び順「親の設定を引き継ぐ」
- 子のタグの並び順の選び肢に「親の設定を引き継ぐ」を加え、一番上に置く。
- 引き継ぐタグは、親のタグの並び順（親も引き継ぐなら、さらにその親）で自分の子を並べる。昇順・降順も引き継ぐ。最上位のタグまでたどって決まっていなければ、ドラッグで決めた順。
- 新しく作ったタグは「親の設定を引き継ぐ」にする。
- 今あるタグのうち、並び順を決めていない（今「ドラッグで決めた順」の）タグも「親の設定を引き継ぐ」にする。
  - 並び順を決めたタグはまだ少なく、決めていないタグはその親が並び順を決めていない限り今の並びのまま変わらないため。
- 引き継ぐときは、昇順・降順を選べないようにし（引き継いだ値を出す）、引き継いだ結果（例：「今はローマ字順・昇順」）を横に出す。

### 4. 長さの入力欄をまとめる
- 時・分・秒の3つの入力欄を、1つの入力欄にまとめる。最初は「00:00:00」を入れておく。
- 入れられる形：「時:分:秒」「分:秒」「秒」。区切りは半角・全角のコロン。分・秒は60以上でもよい（足し合わせる）。
- 形が正しくないとき・0秒のときは、「以上」「以下」を押せない。
- そのほか（条件の加え方、チップ、入力欄の値が残ること）は今のまま。

### 5. ライブラリの並び順
- ライブラリの「ファイル名で検索」の右に、一覧の並び順のプルダウンを置く。
- 選び肢：
  - パス順（今の並び。最初の値）
  - ファイル名順（フォルダを除いた名前。大文字・小文字は区別しない）
  - 追加した順（新しい順）・追加した順（古い順）
  - 更新日時順（新しい順）
  - 長さ順（短い順）・長さ順（長い順）。長さのないファイルは最後
- 同じ値どうしはパス順にする。
- 選んだ並び順はアプリを閉じても覚えておく。「すべての条件を外す」では戻さない。
- 「直近で再生したもの」で絞り込んでいるときは再生した順に並べるので、プルダウンを選べないようにする。重複の一覧では、同じハッシュ値どうしをまとめたうえで、その中を選んだ順に並べる。
- 一覧を再生するときの順番も、この並びになる（今と同じく、表示中の一覧の順）。

## やらないこと
- プレイリストの項目の行や右の欄に、長さ・追加した日時などを出すこと。
- プレイリストの中の並び順を変えること。

## データ
- tags.child_sort に "manual"（ドラッグで決めた順）を加え、NULL を「親の設定を引き継ぐ」にする。マイグレーションは要らない（今の NULL がそのまま「引き継ぐ」になる）。
