# タグの詳細設定

## 目的
左の欄のタグの「✎」で、名前だけでなく、子のタグの並び順と表示の色を設定できるようにする。

## 範囲

### 詳細画面
- 左の欄のタグの行の「✎」（言葉は「詳細を設定する」）を押すと、タグの詳細画面（ダイアログ）を出す。行の中の名前の入力欄はなくす。
- 設定する項目
  - タグ名：今の名前変更と同じ決まり（別の既存のタグと同じ名前なら統合を確認する）
  - 子のタグの並び順：「ドラッグで決めた順」（今までどおり。最初はこれ）・「登録順」・「ファイル数順」・「ローマ字順」と、「昇順」「降順」
  - 背景色・文字色：それぞれ「色を付ける」のチェックと色の選択。付けないときは親の色を引き継ぐ
- 見本のチップで、設定した色（引き継いだ色を含む）を見せる。
- 「保存」で保存して閉じる。「やめる」・Escで何もせず閉じる。

### 子のタグの並び順
- そのタグの直下の子だけに効く（孫の並びは、子のタグの設定による）。
- 登録順：タグを作った順。ファイル数順：左の欄に出す総数（子孫を含む、絞り込みに関係しない数）。ローマ字順：名前をローマ字にした文字列の順。
- 同じ値どうしは、ドラッグで決めた順に並べる。
- 並び順を決めたタグの子も、ドラッグで前・後ろに落とせるが、並びは決めた順のまま（親を変える操作として使える）。ドラッグで決めた順は内部では覚えていて、「ドラッグで決めた順」に戻すとその順になる。
- 左の欄だけでなく、ファイルの行のタグの並びなど、タグの順を使うところすべてに効く。

### 色
- ライブラリのファイルの行のタグと、右の欄のファイルの詳細の「付いているタグ」のチップに、背景色・文字色を付ける。
- 色のないタグは、親（親にもなければその親…）の色を引き継ぐ。背景色と文字色は別々に引き継ぐ。親子両方に色があれば子の色を使う。

## やらないこと
- 最上位のタグの並び順の設定（設定を持つ親がないため）。
- 漢字の読みの変換。ローマ字順は、ひらがな・カタカナをローマ字にし、英数字はそのまま（大文字・小文字は区別しない）、漢字などはその後ろに文字コードの順で並べる（漢字の読みには大きな辞書が要るため）。
- 左の欄の行や、チェックの操作の行のタグ、プレイリストのタグの組み合わせへの色付け。
- 全体ロードマップの「タグとプレイリストへのイメージカラーとジャケット設定機能」のジャケット（画像）。

## データ
- tags に、child_sort（NULL・created・files・romaji）、child_sort_desc（0・1）、bg_color・fg_color（`#rrggbb` か NULL）を加える。
