# テストケース

## 単体テスト（Rust、`facets.rs`）

- 条件なし：親のタグは子孫を含めて数える。「タグなし」の件数
- タグで絞り込んだとき：ほかのタグは、その結果のうちの件数。「タグなし」はタグの条件を外して数える
- 出典で絞り込んだとき：別の出典も、出典の条件を外して数える（OR）
- 次の条件のそれぞれで、すべての項目について、「選んだときの件数」が、実際にその項目を選んで絞り込んだ件数と一致する
  - 条件なし、タグ、親のタグ、タグなし、出典、出典なしとファイル名、チェックしたファイル、タグと出典、タグなしとライセンスなし、タグ2つと存在しないライセンス
- 速さ（`facet_speed`、手動で実行）：3万ファイル・310タグで、条件ごとの計算時間（`試作結果.md`を参照）

## 画面テスト（Playwright、`app/e2e/facets.mjs`）

- F01：条件がないときは総数を出し、どのファイルにも付いていないタグはグレーアウトする。親のタグは子孫を含めて数える
- F02：タグで絞り込むと、各タグの件数は「その結果のうち、そのタグが付いた数」になり、0件はグレーアウトする。「（タグなし）」はタグの条件を外して数える
- F03：グレーアウトした項目は押しても選べない
- F04：条件を足していくと件数が変わる（タグはAND）
- F05：選んでいる項目は、0件になってもグレーアウトせず、押して選択を外せる
- F06：出典どうしはORなので、出典を選んでも別の出典は数える。タグの条件では0件の出典がグレーアウトし、「（出典なし）」も数える
- F07：「チェックしたファイルだけ」やファイル名の条件も件数に入る
- F08：タグを付けるなどデータが変わると、件数を求め直す
- F09：グレーアウトしていても、取っ手で並べ替えはできる
