# 開発ロードマップ

MVP（`機能仕様.md`）を作り上げるまでの作業の順番。各作業は `01_進行中のタスク/` にフォルダを作り、その中の概要にミニロードマップ（実装、レビュー、テスト、コミットとプッシュ）を書いて進める。終わったら `02_完了したタスク/` に連番を付けて移す。

## 進め方

- 下から上へ作る：OSに依存しない中核を先に作り、単体テストで確かめてから、画面とOS連携をつなぐ
- 実機での確認（Android、Ubuntu、Windowsの耳での確認）は、開発者の手が空いたときにまとめて行う。それまでは、Dockerでのビルドと、開発PCでの自動テストまでを確かめる
- 開発者の決定が必要な点は仮決めで進め、まとめて確認してもらう（2026-10-27 の分は `02_完了したタスク/0012_仮決め事項の確認/`。すべて了承済み）
