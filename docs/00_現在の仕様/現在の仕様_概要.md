# 現在の仕様

## 概要

cyanomelodyは、Google Driveとローカルの音楽ファイルから曲を集め、ソースを区別せずにまとめたプレイリストで再生できる音楽再生アプリ。

- 動作環境：Windows、Linux、Android
- 利用者：開発者本人のみ
- 現在の範囲：最初のバージョン（MVP）

このフォルダの内容は、常に現時点の正しい仕様に保つ。仕様を決めた経緯は `02_完了したタスク/` の各タスクを参照。

## 資料マップ

- `現在の仕様_概要.md`：このファイル。仕様の概要と資料の一覧
- `機能仕様.md`：音楽ソース、プレイリスト、再生、同期、キャッシュ、動作環境などの仕様
- `技術仕様.md`：アプリの構成と使う技術
- `開発ロードマップ.md`：MVP を作り上げるまでの作業の順番
