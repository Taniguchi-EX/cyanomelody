## 結果

- `app/` に Tauri 2 ＋ React ＋ TypeScript ＋ Vite のアプリを作った。Rust のワークスペースで、中核のクレート `cyanomelody-core`（`app/crates/core`）と Tauri のアプリ `cyanomelody`（`app/src-tauri`）に分けた
- 画面は、中核のバージョンを表示するだけの最小限のもの。画面 → Tauri のコマンド → 中核の呼び出しがつながることを確かめるため
- 検査のスクリプト `app/scripts/check.sh`：`cargo fmt --check`、`cargo clippy -D warnings`、`cargo test`、`tsc --noEmit`
- Android 向けのプロジェクト（`app/src-tauri/gen/android`）は Docker の中で生成して取り込んだ。最低、対象ともに API 37、アプリの ID は `dev.cyanomelody.app`
- スキル `cyanomelody-android-test` のビルドスクリプトを直した。Windows の `node_modules` をコンテナに持ち込まず、Linux 用を入れるようにした。ワークスペース直下の `target` もコピーの対象から外した

### レビュー

- 差分を読み直し、仕様との食い違い、不要なファイルがないことを確かめた
- 検査のスクリプトに実行の権限が付いていなかったため、Git 上で付けた

### テスト

- 検査のスクリプト：すべて通った（中核の単体テスト 1 件）
- Windows：デバッグ版をビルドして起動し、「中核のバージョン: 0.1.0」と表示されることを画面の撮影で確かめた
- Android：Docker で Android 17 向けの APK（`dev.cyanomelody.app`、arm64）をビルドできた。所要時間は初回で約 3 分。実機での確認は後でまとめて行う
