# 初期要件の策定

## 概要

cyanomelodyの開発を始めるにあたり、最初に作るものの範囲と要件を決める。

- アプリで実現したいことを洗い出す
- 最初のバージョン（MVP）に含める範囲を決める
- 決まった内容を `00_現在の仕様/` に反映する

### 検討事項

- 対応する音楽ソース（Google Drive以外に何を対象にするか、最初はどれに絞るか）
- プレイリストの機能（作成、編集、ソースをまたいだ曲の混在）
- 再生機能（再生・一時停止、シャッフル、リピートなど）
- 動作環境（Web、スマホ、デスクトップなど）
- 利用者（自分だけか、他の人にも使ってもらうか）

### 決定事項

- 対応する音楽ソース：Google Drive、ローカルの音楽ファイル
- プレイリスト：ソースを区別せずに作成、編集、削除できる
- 再生機能：再生、一時停止、前の曲、次の曲、音量、シークバー、シャッフル、リピート
- 動作環境：Windows、Linux、Android
- 利用者：開発者本人のみ
- 端末間の同期：プレイリストと設定はGoogle Driveに保存して全端末で共有する
- Google Driveの曲：ストリーミングで再生し、直近に再生した曲を容量の上限までキャッシュする
- Androidのバックグラウンド再生：対応する。通知領域とロック画面に操作ボタンを出す
- オフライン時：Google Driveの曲はキャッシュ済みのものだけ再生でき、プレイリストは編集できない
- 動作環境の詳細：Android 17以上、Linuxの動作確認はUbuntu、配布はせず自分の端末に直接インストールする

詳細は `MVP要件.md` を参照。
