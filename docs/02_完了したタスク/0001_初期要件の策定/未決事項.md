# 未決事項

`MVP要件.md` で決めた内容のうち、開発ロードマップを引くにはまだ決まっていない点。決まったら `MVP要件.md` に反映し、ここから消す。

## 技術選定のタスクで確認すること

要件としては決まっているが、技術選定の際に実現方法を確かめる必要がある点。技術選定のタスクに引き継ぐ。

- Google Driveのアクセス許可：個人のGoogleアカウントで、審査を受けないアプリを「テスト中」の状態で使うと、ログインの有効期限が7日ほどで切れ、定期的にログインし直す必要がある。回避の方法を確認する
- Google Driveの権限の範囲：指定フォルダの曲を読む権限と、プレイリストや設定を書き込む権限の両方が必要になる
- ストリーミング再生中のシーク（ファイルの途中から読み込めるか）
- Windows、Linux、Androidで、同じ仕組みでバックグラウンド再生と音声の再生ができるか
- Android 17に対応した開発環境とライブラリがそろっているか
- 端末の識別方法：設定ファイルの端末ごとの値と、「ローカルの曲を追加した端末」の判定に使う。端末名が重複したり変わったりしても困らない方法にする（アプリが初回起動時に端末IDを発行する、など）
